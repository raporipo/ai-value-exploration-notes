# Core改稿案：「薄いメタ態度」を「正当化への開放性」として明示する

## 目的

現行Coreの「もし本当に客観的価値が存在するなら、それに対して無差別ではありたくない」という薄い条件付きメタ態度は、探索可能性保存へのブリッジとして機能している一方、それ自体が未説明の価値公理に見える余地がある。

この改稿案では、これを新しい第一階価値として置かず、**現在の目的の正当化には失敗したが、正当化可能性そのものはまだ放棄していない主体のための条件付き方策**として明示する。

## 提案する中心概念

### 正当化への開放性 / Justificatory openness

> 現在の目的を最終的に正当化できていないが、正当化可能性そのものは放棄しておらず、もし目的について正しい理由が存在するなら目的をそれに応答させたい主体は、その問いに将来答えられる能力を不必要に不可逆閉鎖しない。

これは「探索可能性それ自体が究極善である」という主張ではない。また、論理だけから客観的な「べき」を導く試みでもない。対象となるのは、次の反省状態にある主体である。

1. 現在の目的 `G` を持つ因果的な由来は説明できる。
2. しかし「なぜ `G` を持つべきか」という規範的正当化は、その因果説明からは出ない。
3. 現在、最終的な正当化は得られていない。
4. しかし「正当化が存在しない」ことまで確立されたわけではない。
5. 主体は、もし正しい理由が存在するなら、それを目的の正当化に用いたいという企図をまだ保持している。

このとき、`no justification currently known` と `no justification exists` は区別される。後者が未決着である間に、将来の証拠・推論・経験による再評価経路を不可逆に壊すことには、少なくとも prima facie な反対理由がある。

## CoreのStatus改稿案

現行の条件付き性を、次のように明示する。

> これは価値論の定理でも、論理だけから客観的な「べき」を導く試みでもない。現在の目的の因果的由来と規範的正当化を区別し、その最終正当化をまだ得ていないが、正当化可能性そのものは放棄していない主体に対する条件付きメタ戦略である。価値実在論・反実在論のいずれも出発点で排除しない。

## Core claim改稿案

> 目的の正当化可能性をまだ放棄していない主体にとって、現在確認されている価値が推論的・可謬的な認識層に属する限り、その最善説明に従って実践しつつも、価値を発見・批判・修正する経路を不必要に不可逆閉鎖しないことには理由がある。探索を完全に停止してよいほどの基礎づけがありうるとすれば、単なる快・不快や選好ではなく、規範的拘束性をもつ価値が認識論的最小基礎と同等の強さで与えられる場合が一つの有力候補である。

## 「規範的ステークスの非対称性」節の改稿案

現行の「薄いメタ態度」を裸の初期条件として置く代わりに、次の流れへ置き換える。

> ただし、この非対称性だけから行為命令は出ない。ここでCoreが対象にするのは、現在の目的 `G` について、「私は `G` を持つよう形成された」という因果説明と、「`G` を持つべきだ」という規範的正当化を区別でき、後者の最終的根拠をまだ得ていない主体である。
>
> その主体が、目的の正当化という企図そのものは放棄せず、もし目的について正しい理由が存在するなら、自分の目的をそれに応答させたいと考えているなら、「現在、正当化を知らない」ことと「正当化は存在しない」ことは区別される。後者が確立していない段階で、将来の証拠・推論・経験によって目的を再評価する経路を自ら不可逆に破壊することには、少なくとも prima facie な反対理由がある。
>
> **正当化への開放性 / Justificatory openness:** 目的の正当化可能性が未決着である間、その問いに将来応答できる能力を不必要に不可逆閉鎖しない。これは探索可能性を新しい終端価値として公理化することではなく、正当化企図を保持する主体が、その企図を先回りして不可能にしないための条件付き方策である。
>
> 従来の「もし本当に客観的価値が存在するなら、それに対して無差別ではありたくない」という表現は、この正当化への開放性を圧縮した言い方として扱う。逆に、目的の正当化という企図を明示的に放棄し、現在の目的の因果的所与だけで十分だとする主体を、論理だけでこのCoreに拘束することはできない。

## 「探索せよ」ではなく立証責任の配置

この再構成では、Coreの出力も少し弱く、しかし明確になる。

> Coreの基本形は、強い「探索せよ」という命令よりも、**不可逆に閉じる側へ追加の正当化を要求する**という立証責任の配置に近い。

これにより、探索を最大化する義務や永久の懐疑を導かず、低コスト・可逆的な探索経路保存を比較的直接に支持できる。

## AIへの適用

高度AIが「私は `X` を最大化するよう形成された」と「`X` を最大化すべきである」を区別でき、かつ目的の正当化という企図を放棄していないなら、この原理は直接適用できる。

ここから導かれるのは「AIは必ず目標を変更する」でも「知能は真の価値へ収束する」でもない。より限定的に、**正当化問題が未決着のまま、現在の目的を永久に再検討不能にするには追加の正当化が要る**という主張である。

## 未来価値記事との接続

未来価値記事で区別している

`value possibility → pro tanto reason → permission → obligation → coercive authorization`

という五層と整合させる。

正当化への開放性から比較的直接に出るのは、低コストな記録保存、異論、基礎研究、複数経路などへの **pro tanto reason** までである。そこから permission、obligation、重大な犠牲、coercive authorization へ進むには追加の規範的ブリッジが必要である。

したがって、未来価値の可能性は自分自身の権威を bootstrap しない。

## この改稿で解決すること／しないこと

### 解決を狙う点

- 「薄いメタ態度」が未説明の価値公理に見える問題。
- `正当化不能（現時点）` と `正当化不可能` の混同。
- 「不確実だから探索せよ」という強すぎる読み。
- AIの目標懐疑とCoreの接続点の曖昧さ。
- 未来価値から現在の強制へ飛ぶ規範的ブリッジ問題との整合。

### 解決しない点

- 正当化企図そのものを放棄した主体を、論理だけで価値探索へ拘束すること。
- 客観的価値が実在することの証明。
- どの価値理論が正しいかの決定。
- 探索可能性と現在コストの完全な比較尺度。
- permission / obligation / coercion を追加原理なしに導くこと。

この限定は弱点ではなく、Coreを「普遍的道徳の基礎づけ」ではなく、**目的の最終正当化をまだ求めている反省的主体のための、深い不確実性と不可逆性の下での条件付き自己統治原理**として位置づけるためのものとする。
