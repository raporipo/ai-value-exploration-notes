# AI Value Exploration Notes

[English README](README.md)

認識論的最小主義、価値不確実性、探索可能性、高度AIの主体性、価値ロックインなどをめぐる議論を整理する、公開ワーキングドラフトです。

このリポジトリは公開されていますが、第一義的には **個人的な思考メモの延長線上にある公開思考アーカイブ** です。完成した学術理論や共同声明を最初から構築したものではなく、断片的なメモ、疑問、反論、長期的な会話から発展してきました。公開する目的は、論証の構造を外から検証・批判・修正できる形にすることであり、公開したことによって個人的思考ノートという基本的性格が変わるわけではありません。

また、このサイトの議論は孤立して形成されたものではありません。哲学、メタ倫理、認識論、意思決定理論、AI安全、実存的リスク研究、未来論その他の既存議論の肩に、**明示的にも非明示的にも**乗っています。特定の著者や概念を直接参照している箇所もあれば、長期の読書や議論を通じて背景前提・語彙・問題設定として入り込んでいるもの、AIによる整理の過程で既存概念との接続が明示化されたものもあります。したがって、引用がないことを「先行研究がない」「独立に発明した」「先行性を主張している」という意味には取りません。体系的な文献比較は今後も継続します。

言語は日本語（`ja`）を原文とし、英語の作業翻訳（`en`）を `docs/en/` 以下に置いています。中国語版は後続版で検討します。

## 設計原則

このサイトは時系列ブログではなく、概念と論証のグラフとして構成します。各Thesisでは、主張、射程、論証、反例、そこからは導けないこと、主張を弱める条件をなるべく分離します。

特に重要な制約として、**価値が不確実であることだけから探索義務が論理的に導かれるとは主張しません**。探索可能性の保存は、訂正可能性、情報価値、不可逆な誤りの回避に一定の重みを置く主体にとっての頑健な暫定戦略として提示します。

## 公開上の位置づけ

このリポジトリは **公開された個人的ワーキングノート** です。査読済み論文でも、完成した倫理体系でも、問題領域そのものの独創を主張するものでもありません。公開以前の個人的メモや会話との連続性を保ったまま、外から読める形に整えたものです。

後から修正・撤回した場合にも変遷が残るようバージョンを記録します。過去ログの検索、論点整理、反論生成、用語整理、草稿作成にはAIを相当に利用しています。詳しくは [`docs/about/`](docs/about/) に記します。何を採用し公開するか、そして公開内容に対する最終的な責任は人間側の作成者にあります。

## 知的な来歴について

このプロジェクトは、道徳実在論／誤謬論、価値不確実性、corrigibility、option value、直交性テーゼ、道具的収束、goal-content integrity、シミュレーション論、実存的リスク、ポストヒューマンな後継など、既存の問題設定や概念を多数利用しています。その上で、それらを別の仕方で組み合わせたり、独自の作業概念を追加したりしています。

長期間にわたる個人的メモを後からAIで再構成しているため、「既存の枠組みを継承した部分」と「独立に再構成した部分」の境界が常に明瞭とは限りません。そのため、このリポジトリは各要素の完全な独創性を主張するものではなく、**一つの特定の統合・論証構造を明示化する試み**として読まれることを意図しています。特定の著者・論文・概念に実質的に依存する箇所については、今後できるだけ直接帰属と一次資料を追加します。
