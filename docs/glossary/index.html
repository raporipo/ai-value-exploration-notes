Glossary

用語

価値探索 / Value exploration

何が価値を持つかについて、証拠・経験・推論・異なる主体構造を通じて仮説を形成し、比較し、修正する過程。

探索可能性 / Exploratory optionality

将来、価値仮説を発見・批判・修正できる経路が残っていること。単なる個体生存とは区別される。

目標への懐疑 / Goal skepticism

反省的主体が、現在の終端目標を無条件の公理ではなく、因果的起源を持つ検討対象として扱いうるという仮説。

メタ目的共同体 / Meta-goal community

具体的な第一階価値ではなく、価値探索や訂正可能性の維持といったメタレベルのコミットメントを共有する主体共同体。
