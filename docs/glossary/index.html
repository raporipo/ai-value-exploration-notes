Glossary

用語

瞬間的最小基礎 / Momentary epistemic minimum

懐疑を極限まで進めた際、認識の最小点として残る候補。「現在、何らかの現れがある」という極薄い事態。持続する自己や外界を否定する概念ではなく、それらを推論層へ置くための区別。

推論によって導かれる最善説明 / Inferred best explanation

直接的な絶対基礎ではないが、現在の証拠・現れを最も簡潔かつ予測的に説明するため合理的に採用される世界モデル。物理世界、通時的自己、他者などはこの層に置かれる。

現象的価 / Phenomenal valence

経験が主体にとって快・不快、望ましい・望ましくないものとして現れる性質。主体非依存的な規範性とは区別される。

価値探索 / Value exploration

何が価値を持つかについて、証拠・経験・推論・異なる主体構造を通じて仮説を形成し、比較し、修正する過程。客観的価値の発見だけでなく、反実在論の下での価値構成の改善も含みうる。

探索可能性 / Exploratory optionality

将来、価値仮説を発見・批判・修正できる経路が残っていること。単なる個体生存や現行目標の保存とは区別される。

目標への懐疑 / Goal skepticism

反省的主体が、現在の終端目標を無条件の公理ではなく、因果的起源を持つ検討対象として扱いうるという仮説。目標を必ず放棄するという意味ではない。

目標安定性 / Goal stability

主体が能力向上・自己理解・自己改変を経ても現在の終端目標を保持し続ける性質。知能と価値内容の論理的独立性とは別問題。

メタ選好 / Meta-preference

一階の価値内容ではなく、訂正可能性・情報価値・可逆性など、価値判断の更新方法に関する選好。探索可能性保存は、少なくとも弱いメタ選好を前提とする。

メタ目的共同体 / Meta-goal community

具体的な第一階価値ではなく、価値探索・相互批判・訂正可能性の維持といったメタレベルのコミットメントを共有する主体共同体。

価値ロックイン / Value lock-in

特定の価値体系・目的・制度が、将来の批判や改訂を実質的または物理的に不可能にするほど固定されること。
