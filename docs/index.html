価値を知らない知性は、何を保存すべきか。

瞬間的な認識の最小点から、推論による世界像、価値の不確実性、探索可能性、高度AIの目標への懐疑、価値ロックインまでを一つの論証グラフとして検討する。

中心命題：価値不確実性だけでは探索義務は出ない。しかし、訂正可能性・情報価値・不可逆損失回避を少なくとも弱く重視するなら、十分な理由なしに将来の価値探索経路を不可逆に閉ざさないことが頑健な暫定戦略になる。

Core — 価値の不確実性と探索可能性の保存

認識論からAI論までを最小論証としてつなぐ中心ページ。

瞬間的最小基礎

世界・自己・記憶を否定せず、それらを「推論によって導かれる最善説明」として位置づける。

既存価値はなぜ最終基礎にならないのか

人間の現在価値を重要な証拠として扱いながら、永久固定の最終回答にはしない理由。

推論と価値確信の限界

現象的価値、主体間対称性、規範性、推論の自己正当化を分解する。

高度AIの目標への懐疑

弱い直交性と強い目標安定性を分け、初期目的を検討対象にできるAIを考える。

構造

Core は幹、Theses は基礎または派生命題、Explorations はCoreを壊しうる未決着論点、Questions は検索・AIエージェント向け入口、Glossary は標準定義である。

Japanese is the source language. English and Chinese translations are intentionally deferred until the Japanese argument structure stabilizes.
