保存文明と生産文明

不可逆変換・準オプション価値・認識的留保

Exploration v0.2 · 2026-08-29 · working hypothesis

暫定仮説： 探索志向の文明は、宇宙を即座に博物館にも工場にもする必要はない。十分理解され再生成可能な資源は積極的に利用しつつ、非代替的で未知情報密度が高く、将来学習の余地が大きい対象には一時的な留保を置ける。ただし保存にも時間・エネルギー・安全・競争上の機会費用があるため、必要なのは保存最大化ではなく、両面的不可逆性（two-sided irreversibility）を比較する動的ポートフォリオである。

1. 二つの極端な文明型

生産文明は、利用可能な物質、エネルギー、計算資源、空間を現在支持する価値の実現へ急速に変換する。未利用資源は失われた生産機会として見える。

保存文明は、原状態、希少構造、生物圏、歴史的原物、未改変環境を、未知の価値・情報・将来の再観測可能性のために広く残す。

本ページの結論はどちらか一方を選ぶことではない。この二つは極端な端点であり、成熟文明の実問題は 保存―生産フロンティア（preservation-production frontier） 上での対象別・時点別配分である。

2. 保存側の理論：アロー＝フィッシャー＝アンリと準オプション価値

ケネス・アロー（Kenneth Arrow）とアンソニー・フィッシャー（Anthony Fisher）、クロード・アンリ（Claude Henry）らによる不可逆性と不確実性の議論では、今不可逆に開発する代わりに待つことで将来情報が得られ、後から保存か利用かを選べるなら、学習そのものが保存側へ追加価値を与える。

本プロジェクトの言葉では、準オプション価値（quasi-option value）は概ね、待つことで維持される将来訂正能力の価値として読める。

順序： 一時保存 → 学習 → モデル改訂 → 再決定。不可逆変換を遅らせる価値は、単に対象を好むことからではなく、将来判断が改善されうることから生じる。

3. 待つ価値は、将来学べる場合に強くなる

ただし保存は自動的に有利ではない。何千年待っても関連情報がほとんど増えないなら、学習由来の準オプション価値は小さい。

保存プレミアムは、対象の再取得不能性だけでなく、期待学習速度に依存する。近い将来にセンサー、理論、AI推論能力が急速に改善しそうなら短期保存の価値は高まりやすい。逆に、情報改善が見込めず保存コストだけが累積するなら、早期利用が合理的になりうる。

4. 安全最低基準：不可逆性は立証責任を上げるが、絶対命令ではない

環境保全経済学の安全最低基準（Safe Minimum Standard）は、絶滅のような不可逆損失について、社会的コストが過大でない限り最低限の保存を優先する発想を与える。ただし、これを単純なマキシミン定理として正当化する試みには批判があり、モデルの置き方だけで保存を必然化することは難しい。

本プロジェクトも「不確実＋不可逆だから必ず保存」とは言わない。採るのはより弱い条件付き原則である。

立証責任原則： よりよい将来理由へ応答したい主体にとって、対象の非代替性・不可逆性・将来学習可能性が大きいほど、今それを全面変換するにはより強い理由が必要になる。

5. 強い持続可能性から不可代替的な認識資本へ

強い持続可能性（strong sustainability）は、一部の自然資本が人工資本で十分代替できない可能性を重視する。本プロジェクトではこれを価値判断から認識論へずらせる。

不可代替的な認識資本（critical epistemic capital）とは、現在の知識では代替可能性そのものを十分評価できないため、暫定的に高い保存閾値を置く対象である。生物圏、人間身体、歴史的資料、未汚染の惑星環境、独立したAI系統などが候補になりうる。

「自然だから神聖」なのではなく、何を失うかを現在まだ十分モデル化できないことが理由である。

6. 反対側：ボストロムの「天文学的浪費」

ニック・ボストロム（Nick Bostrom）の Astronomical Waste は、宇宙の利用可能な資源・負エントロピーが時間とともに失われるなら、宇宙利用を遅らせること自体にも巨大な機会費用があると論じる。ここではその功利主義的数量評価を採用する必要はない。重要なのは構造である。

保存によって原状態を残す間にも、時間、エネルギー、計算資源、居住可能領域、現在主体の福祉、研究機会、競争上の位置が失われうる。

両面的不可逆性：
今変換する → 原状態と未知情報を失いうる
待ちすぎる → 時間・エネルギー・生産・安全・戦略的機会を失いうる

したがって「非行動は中立」ではない。これはPracticeの、行動と非行動の双方の不可逆性を比較するという原則の文明資源版である。

7. 保存―生産フロンティア

保存と生産の判断は、対象ごとに少なくとも次の軸で変わる。

保存プレミアムを上げる要因利用プレミアムを上げる要因
再取得不能・再生成困難高い再構成可能性
未知情報の非冗長性十分理解された反復資源
高い将来再観測可能性低い追加学習期待
高い期待学習速度時間依存の生産機会
現在存在論への低信頼現在モデルへの高信頼
低い保存コスト高い維持／安全コスト
低い競争圧力強い競争／安全保障圧力

これらを一つの効用得点へ必ず統合する必要はない。実践上は、不可逆変換への立証責任を調整する複数軸として使える。

8. 認識的留保：全部保存でも全部利用でもない

Apollo試料の保存戦略が示すように、現在研究へ一部を使い、未来の新技術・新しい問いのために一部を未汚染状態で残すことができる。

文明規模では、現在の価値理論・測定能力ではまだ全面変換しない領域を 認識的留保（epistemic reserve） として扱える。

留保 ≠ 永久聖域。 留保は永久に触れてはいけない聖域ではなく、現在の認識状態では未解放という状態である。学習・防御・再生成能力が高まれば段階的に利用へ移せる。

9. 参照保存区：未改変の対照を残す

大多数の同型資源を利用しても、異なる種類の未改変標本を一部残せば、未来の研究に比較基準を提供できる。これは単なる「希少自然の保護」と違い、文明規模の対照群設計である。

例えば大量の小惑星を利用しても代表的な組成の原物を残す、惑星改造を行っても一部地域を未汚染の参照対象として維持する、といった戦略がありうる。生命探査における惑星保護（planetary protection）は、地球由来汚染が将来の科学的完全性を損なうことを避けるという点でこの発想に近い。

宇宙規模では暫定的に 宇宙的参照保存区（cosmic reference reserves） と呼べる。

10. 探索のための破壊

探索と保存は常に同じ方向を向かない。対象を理解するために破壊分析、解剖、採掘、分解が必要な場合がある。NASAの宇宙物質管理でも、希少試料の破壊分析は明示的な資源配分問題になる。

したがって比較すべきは、

破壊分析による期待認識利得 と 失われる将来再観測可能性

である。探索主義は「一切触るな」という保存主義ではない。

11. 生産と保存は相互補完できる

高度な生産能力は、保存容量、センサー、復元、冗長性、宇宙インフラを安価にし、保存フロンティアを外へ押し広げる。

逆に、保存された原物・データ・未改変環境は、未来の科学的発見を通じて生産能力を高めうる。

フィードバック： 生産 → より安価な保存；保存 → 将来知識 → より良い生産。したがって保存と生産は固定和の敵対関係とは限らない。

このため本ページの立場は単純な反成長・非利用ではなく、生産能力を高めながら不可逆変換率を認識状態に合わせて管理する方向になる。

12. 危険情報は「保存してから安全を生産する」ことがある

未知の未知と原データ保存で扱う情報災害は、保存と生産の相補性をよく示す。危険だが独自な情報を認識的預託へ一時封印し、その間に対抗手段、検知、封じ込め、文明的レジリエンスを生産してからアクセスを広げることができる。

保存は生産を止めるためではなく、安全に次の公開・利用段階へ移る時間を買う場合がある。

13. 差別的技術開発を文明の順序設計へ拡張する

ボストロムの差別的技術開発（differential technological development）は、危険技術より対抗技術を先に発展させる順序づけを提案する。本プロジェクトでは、それを技術単体から文明構造へ拡張できる。

  1. 危険能力・危険情報の広範利用を遅らせる。
  2. 対抗手段、感知、封じ込めを先行させる。
  3. 障害領域を縮小し、冗長性、区画化、復旧能力を高める。
  4. 文明が十分に破壊困難になった段階でアクセス・利用範囲を段階的に広げる。

これは「最大速度」ではなく 進歩の良い順序づけ を求める考え方である。

14. 競争は保存ポートフォリオを壊しうる

単独文明には留保維持が合理的でも、他主体が先に資源を占有・変換するなら、保存側は競争で不利になる。競争の下では、全員にとって望ましい保存量より低い水準へ落ちる可能性がある。

したがって認識的留保を長期維持するには、個体的徳ではなく、境界、条約、共同監視、非占有ルール、共有アーカイブなどの制度が必要になる。

この問題はメタ目的共同体とAI社会の薄い憲法、およびシングルトンと多主体文明の安全保障のジレンマへ接続する。

15. 誰が留保を解放するのか

留保管理を一つの中央AIへ完全に委ねれば、今度は保存制度そのものが価値／認識的ロックインの単一障害点になりうる。

解放条件には、複数の独立した探索系統、透明な証拠、ルール改訂、閾値認可、監査、場合によって分岐や退出を組み込む理由がある。

ただし危険対象について分権しすぎれば、一主体の早すぎる解放が全文明へ外部性を与える。したがってこれは、多元的統治と破局的安全性の典型的な緊張でもある。

16. 主体を保存資源として扱わない

人間・AI・文化が将来情報を含むとしても、文明ポートフォリオの「留保資産」として本人の意思に反して固定してよいとは限らない。主体には現在の利益・権利・自律に基づく独立の理由がありうる。

証拠の認識的保存 と 生きた主体の政治的統制 は区別しなければならない。

17. 認識的保存原則（暫定）

認識的保存原則（Epistemic Conservation Principle）： 将来のより良い証拠・理由へ応答したい主体にとって、現在十分に理解されていない対象の不可逆な破壊・圧縮・公開・変換は、現在知られている用途だけでなく、将来の再観測・再解釈・異なる仮説検証の可能性も失わせうる。したがって、変換の不可逆性、対象の非冗長性、将来学習可能性が大きいほど不可逆化には高い立証責任を要求する。ただし、保存・非公開・待機が生む不可逆な機会費用も同じ比較に含める。

これは宇宙の最終道徳法則ではない。反省的不確実性と不可逆コミットメントと同様、将来訂正への条件付き応答性を持つ主体に対するメタ方策である。

18. 結論：保存文明でも生産文明でもなく、順序づけられた文明

成熟した探索文明は、宇宙を博物館にも工場にも即座にしない。十分理解され、再生成可能で、非冗長な未知情報をほとんど持たない資源は積極的に利用する。一方、独自で不可逆かつ将来学習余地の大きい対象には留保を置く。そして認識・防御・復元能力の進歩に応じて、留保と利用領域を更新する。

したがって目標は保存率を永久固定することではなく、学習と生産を並行させながら不可逆変換の順序を管理する文明である。

19. 残る難問

  • 期待学習速度を文明的意思決定へどう推定するか。
  • 不可代替的な認識資本の非代替性をいつ解除できるか。
  • 参照保存区をどの程度残せば将来再観測可能性が十分か。
  • 競争圧力の下で留保を維持する最小制度は何か。
  • 留保管理の中央集権化と早すぎる単独解放の双方をどう避けるか。
  • 天文学的機会費用と未知価値の保存プレミアムを、異なる価値理論の下でどう比較するか。
