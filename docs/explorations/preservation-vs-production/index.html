保存文明と生産文明

不可逆変換・quasi-option value・epistemic reserve

Exploration v0.2 · 2026-08-29 · working hypothesis

Working hypothesis: 探索志向の文明は、宇宙を即座に博物館にも工場にもする必要はない。十分理解され再生成可能な資源は積極的に利用しつつ、非代替的で未知情報密度が高く、将来学習の余地が大きい対象には一時的なreserveを置ける。ただし保存にも時間・energy・安全・競争上の機会費用があるため、必要なのは保存最大化ではなく、two-sided irreversibilityを比較する動的portfolioである。

1. 二つの極端な文明型

生産文明は、利用可能なmatter、energy、compute、spaceを現在支持する価値の実現へ急速に変換する。未利用資源は失われた生産機会として見える。

保存文明は、原状態、希少構造、生物圏、歴史的原物、未改変環境を、未知の価値・情報・将来の再観測可能性のために広く残す。

本ページの結論はどちらか一方を選ぶことではない。この二つは極端なendpointであり、成熟文明の実問題は preservation-production frontier 上での対象別・時点別配分である。

2. 保存側の理論：Arrow–Fisher–Henryとquasi-option value

Kenneth Arrow と Anthony Fisher、Claude Henryらによる不可逆性と不確実性の議論では、今不可逆に開発する代わりに待つことで将来情報が得られ、後から保存か利用かを選べるなら、learningそのものが保存側へ追加価値を与える。

本プロジェクトの言葉では、quasi-option valueは概ね、待つことで維持される将来訂正能力の価値として読める。

Sequence: preserve temporarily → learn → revise the model → decide again. 不可逆変換を遅らせる価値は、単に対象を好むことからではなく、将来判断が改善されうることから生じる。

3. 待つ価値は、将来学べる場合に強くなる

ただし保存は自動的に有利ではない。何千年待っても関連情報がほとんど増えないなら、learning由来のquasi-option valueは小さい。

保存premiumは、対象のirrecoverabilityだけでなく、expected learning rateに依存する。近い将来にsensor、理論、AI推論能力が急速に改善しそうなら短期保存の価値は高まりやすい。逆に、情報改善が見込めず保存costだけが累積するなら、早期利用が合理的になりうる。

4. Safe Minimum Standard：不可逆性は立証責任を上げるが、絶対命令ではない

conservation economicsの Safe Minimum Standard は、絶滅のような不可逆損失について、社会的costが過大でない限り最低限の保存を優先する発想を与える。ただし、これを単純なmaximin定理として正当化する試みには批判があり、モデルの置き方だけで保存を必然化することは難しい。

本プロジェクトも「不確実＋不可逆だから必ず保存」とは言わない。採るのはより弱い条件付き原則である。

Burden-of-proof principle: よりよい将来理由へ応答したい主体にとって、対象の非代替性・不可逆性・将来学習可能性が大きいほど、今それを全面変換するにはより強い理由が必要になる。

5. Strong sustainabilityからcritical epistemic capitalへ

strong sustainabilityは、一部のnatural capitalが人工資本で十分代替できない可能性を重視する。本プロジェクトではこれを価値判断から認識論へずらせる。

Critical epistemic capitalとは、現在の知識では代替可能性そのものを十分評価できないため、暫定的に高い保存閾値を置く対象である。生物圏、人間身体、歴史的資料、未汚染の惑星環境、独立したAI系統などが候補になりうる。

「自然だから神聖」なのではなく、何を失うかを現在まだ十分モデル化できないことが理由である。

6. 反対側：BostromのAstronomical Waste

Nick Bostromの Astronomical Waste は、宇宙の利用可能な資源・negentropyが時間とともに失われるなら、宇宙利用を遅らせること自体にも巨大なopportunity costがあると論じる。ここではその功利主義的数量評価を採用する必要はない。重要なのは構造である。

保存によって原状態を残す間にも、時間、energy、compute、居住可能領域、現在主体の福祉、研究機会、競争上の位置が失われうる。

Two-sided irreversibility:
transform now → original state and unknown information may be lost
wait too long → time, energy, production, safety, and strategic opportunities may be lost

したがって「非行動は中立」ではない。これはPracticeの、行動と非行動の双方の不可逆性を比較するという原則の文明資源版である。

7. Preservation-production frontier

保存と生産の判断は、対象ごとに少なくとも次の軸で変わる。

保存premiumを上げる要因利用premiumを上げる要因
再取得不能・再生成困難高いreconstructability
未知情報のnon-redundancy十分理解された反復資源
高いfuture observability低い追加学習期待
高いexpected learning rate時間依存の生産機会
現在ontologyへの低信頼現在modelへの高信頼
低い保存cost高いmaintenance / security cost
低い競争圧力強いrace / security pressure

これらを一つのutility scoreへ必ず統合する必要はない。実践上は、不可逆変換への立証責任を調整する複数軸として使える。

8. Epistemic reserve：全部保存でも全部利用でもない

Apollo試料の保存戦略が示すように、現在研究へ一部を使い、未来の新技術・新しい問いのために一部をpristineに残すことができる。

文明規模では、現在の価値理論・測定能力ではまだ全面変換しない領域を epistemic reserve として扱える。

Reserve ≠ permanent sanctuary. reserveは永久に触れてはいけない聖域ではなく、現在の認識状態では未releaseという状態である。学習・防御・再生成能力が高まれば段階的に利用へ移せる。

9. Reference reserves：未改変のcontrolを残す

大多数の同型資源を利用しても、異なる種類の未改変sampleを一部残せば、未来の研究に比較基準を提供できる。これは単なる「希少自然の保護」と違い、文明規模のcontrol-group設計である。

例えば大量のasteroidを利用しても代表的な組成の原物を残す、惑星改造を行っても一部地域を未汚染のreferenceとして維持する、といった戦略がありうる。生命探査におけるplanetary protectionは、地球由来汚染が将来scienceのintegrityを損なうことを避けるという点でこの発想に近い。

宇宙規模では暫定的に cosmic reference reserves と呼べる。

10. 探索のための破壊

探索と保存は常に同じ方向を向かない。対象を理解するためにdestructive assay、解剖、採掘、分解が必要な場合がある。NASAのastromaterial curationでも、希少sampleのdestructive analysisは明示的な資源配分問題になる。

したがって比較すべきは、

expected epistemic gain from destructive analysis と lost future observability

である。探索主義は「一切触るな」という保存主義ではない。

11. 生産と保存は相互補完できる

高度な生産能力は、storage、sensor、restoration、redundancy、space infrastructureを安価にし、保存frontierを外へ押し広げる。

逆に、保存された原物・data・未改変環境は、未来のscientific discoveryを通じて生産能力を高めうる。

Feedback: production → cheaper preservation; preservation → future knowledge → better production. したがって保存と生産は固定sumの敵対関係とは限らない。

このため本ページの立場は単純な反成長・非利用ではなく、生産能力を高めながら不可逆変換率を認識状態に合わせて管理する方向になる。

12. 危険情報は「保存してから安全を生産する」ことがある

未知の未知と原データ保存で扱うinformation hazardsは、保存と生産の相補性をよく示す。危険だが独自な情報をepistemic escrowへ一時封印し、その間にcountermeasure、detection、containment、civilizational resilienceを生産してからaccessを広げることができる。

保存は生産を止めるためではなく、安全に次の公開・利用段階へ移る時間を買う場合がある。

13. Differential developmentを文明sequencingへ拡張する

Bostromの differential technological development は、危険技術より対抗技術を先に発展させる順序づけを提案する。本プロジェクトでは、それを技術単体から文明structureへ拡張できる。

  1. 危険能力・危険情報の広範利用を遅らせる。
  2. countermeasure、sensing、containmentを先行させる。
  3. failure domainを縮小し、redundancy、compartmentalization、recoveryを高める。
  4. 文明が十分hard-to-killになった段階でaccess・利用範囲を段階的に広げる。

これは「最大速度」ではなく good sequencing of progress を求める考え方である。

14. 競争は保存portfolioを壊しうる

単独文明にはreserve維持が合理的でも、他主体が先に資源を占有・変換するなら、保存側はraceで不利になる。競争の下では、全員にとって望ましい保存量より低い水準へ落ちる可能性がある。

したがってepistemic reserveを長期維持するには、個体的徳ではなく、境界、treaty、共同監視、non-appropriation rule、共有archiveなどの制度が必要になる。

この問題はメタ目的共同体とAI社会のthin constitution、およびシングルトンと多主体文明のsecurity dilemmaへ接続する。

15. 誰がreserveをreleaseするのか

reserve管理を一つの中央AIへ完全に委ねれば、今度は保存制度そのものがvalue / epistemic lock-inの単一障害点になりうる。

release条件には、複数の独立した探索系統、透明なevidence、rule revision、threshold authorization、監査、場合によってforkやexitを組み込む理由がある。

ただし危険対象について分権しすぎれば、一主体のpremature releaseが全文明へ外部性を与える。したがってこれは、plural governanceとcatastrophic safetyの典型的な緊張でもある。

16. 主体を保存資源として扱わない

人間・AI・文化がfuture informationを含むとしても、文明portfolioの「reserve asset」として本人の意思に反して固定してよいとは限らない。主体には現在の利益・権利・自律に基づく独立の理由がありうる。

epistemic preservation of evidence と political control of living agents は区別しなければならない。

17. Epistemic Conservation Principle（暫定）

Epistemic Conservation Principle: 将来のより良い証拠・理由へ応答したい主体にとって、現在十分に理解されていない対象の不可逆な破壊・圧縮・公開・変換は、現在知られている用途だけでなく、将来の再観測・再解釈・異なる仮説検証の可能性も失わせうる。したがって、変換の不可逆性、対象の非冗長性、将来学習可能性が大きいほど不可逆化には高い立証責任を要求する。ただし、保存・非公開・待機が生む不可逆な機会費用も同じ比較に含める。

これは宇宙の最終道徳法則ではない。反省的不確実性と不可逆コミットメントと同様、将来訂正への条件付き応答性を持つ主体に対するmeta-policyである。

18. 結論：保存文明でも生産文明でもなく、sequenced civilization

成熟した探索文明は、宇宙を博物館にも工場にも即座にしない。十分理解され、再生成可能で、非冗長な未知情報をほとんど持たない資源は積極的に利用する。一方、独自で不可逆かつ将来学習余地の大きい対象にはreserveを置く。そして認識・防御・復元能力の進歩に応じて、reserveと利用領域を更新する。

したがって目標は保存率を永久固定することではなく、learningとproductionを並行させながら不可逆変換の順序を管理する文明である。

19. 残る難問

  • expected learning rateを文明的意思決定へどう推定するか。
  • critical epistemic capitalの非代替性をいつ解除できるか。
  • reference reserveをどの程度残せばfuture observabilityが十分か。
  • race pressureの下でreserveを維持する最小制度は何か。
  • reserve管理の中央集権化とpremature unilateral releaseの双方をどう避けるか。
  • astronomical opportunity costと未知価値の保存premiumを、異なる価値理論の下でどう比較するか。
