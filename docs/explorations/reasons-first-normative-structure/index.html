理由は規範性の基礎なのか――Reasons Firstと価値構造

Exploration v0.3 · 2026-08-30

Question: 「理由」は規範的現実の最も基礎的な概念なのか。それとも、規範判断を分析するための有用な概念を、世界の基礎構造へ昇格させているのか。本稿では、動機・熟慮・手段的合理性と強い規範的理由を分離し、Value First / Reasons First / Ought First / Fittingness Firstの説明順序を、価値構造 𝒱=(C,B,R) のストレステストとして検討する。

1. 「理由」という一語に何が入っているか

「電車が出そうだから走る」「金が欲しいから働く」「苦痛だから避ける」「約束したから守る」は、日常語ではすべて「理由」による行為として記述できる。しかし、これらが同じ意味で規範的であることは自明ではない。本稿では少なくとも次の四層を区別する。

Rc = 因果的駆動要因（causal driver）：行為を実際に発生させた因果要因。
Rd = 熟慮上の考慮事項（deliberative consideration）：主体が熟慮の中で考慮した内容。
Rh = 仮言的・道具的理由（hypothetical / instrumental reason）：ある目的Gを所与としたとき、その達成を促進する考慮。
Rn = 強い規範的理由（robust normative reason）：主体の偶然的な欲求・目的・自己像を単に前提せず、その行為や態度を本当に支持する規範的関係。

Rc, Rd, Rh ⇏ Rn

主体を動かしたこと、主体が理由だと思ったこと、ある目的の達成に役立つことは、それ自体では強い規範性を与えない。目的Gが「電車に乗り遅れたくない」であれ「ペーパークリップを最大化したい」であれ、Gを所与にすれば道具的推論は成立する。しかし、そのことはG自体の規範的権威を示さない。

1.1 日常的な「支持」はすでに規範的なのか

この区別は、特定の論者だけに向けられたものではない。現代の理由論では、日常的な熟慮に現れる「ある事実が、ある行為や態度を支持する」という関係そのものを規範的理由として捉える有力な立場がある。とりわけScanlonやSkorupskiのReasons Firstでは、この理由関係を還元不可能な基礎候補に置く。

しかし本プロジェクトは、この日常的な支持からRnを当然には導かない。

Fire(building) → leave

という実践的・因果的・予測的関係が成立していても、

Fire(building) → Rn(leave) ?

はなお開かれている。真の規範構造𝒱*の中に、主体の期待どおり「火事は退出を規範的に支持する」という関係が存在するかもしれない。逆に、主体が生存を望み、危険を予測し、退出することがきわめて合理的に見えても、そこに強い規範的関係がまったく存在しない可能性も排除しない。

世界 → DA → 予測 / 目的追求 → 行為

だけで火事から逃げる主体は生成できる。本稿が問うのは、日常語でその行為を「合理的」「理由がある」と呼べるかではなく、その考慮事項が𝒱*の中で本当に行為を規範的に支持する関係に立っているのかである。

2. Dancy――動機となる理由と規範的理由の区別は十分か

Jonathan Dancyは Practical Reality で、我々が実際に行為した理由（motivating reasons）と、我々が行為すべき理由（normative reasons）の関係を中心問題に置く。さらに、同じ世界内の考慮事項が両方の役割を果たしうるという方向を強く取る。Dancyは規範的理由を単なる欲求からではなく価値との関係で説明しようとする。

しかし本プロジェクトでは、「規範的」と呼ばれる側についてもさらに問いを入れる。たとえば「電車に乗りたい」という目的を持つ主体にとって「電車が出そうだ」は走ることを支持する考慮になりうる。しかし、

Want(G) + Means(X,G) → Rh(X)

は容易に成立しても、

Want(G) + Means(X,G) → Rn(X)

は追加の議論を要する。「行為すべき理由」の内部でも、目的相対的・制度相対的・選好相対的な支持と強い規範性を分ける必要がある。

3. Williams――内在的理由は権威か、それとも実践的到達可能性か

Bernard Williamsの内在的理由論では、ある主体Aに理由があるという主張は、Aの動機集合と適切な熟慮との関係を無視できない。本プロジェクトから見ると、Williamsが強く説明しているのは、少なくとも一部には主体にとって何が実践的に到達可能かである。

SA → 実践的到達可能性

から、

SA → Rn

は出ない。SA自体が進化、学習、文化、偶然の履歴によって形成されたものなら、なぜそれが規範的権威を持つのかは別問題である。Williams型の内在主義は重要な心理・実践理性論でありうるが、それだけで最終的な規範論になるとは限らない。

4. Parfit――選好を迂回して世界の事実から理由へ

Derek Parfitの客観的理由論では、将来の激痛を避ける理由があるのは、現在の欲求ではなくそれが激痛であるという事実そのものが理由を与えるからだとされる。

Agony → Rn?

これは世界の事実 → 理由という強いB候補である。本プロジェクトはこの可能性を排除しない。しかし、なぜ激痛という性質が理由を与えるのか、その関係をどのように知るのか、強い嫌悪や感情価を規範的関係として読んでいるだけではないか、という橋の問題は残る。

5. ScanlonとSkorupski――Reasons Firstという強い仮説

T. M. Scanlonは Being Realistic about Reasons でReasons Fundamentalismを擁護し、理由に関する還元不可能な規範的真理を認める。John Skorupskiの The Domain of Reasons も、実践・認識・感情をまたぐ規範領域を理由関係から体系化しようとする。

ここでの理由は特別に道徳的な場面だけに現れるものではない。ある事実が行為・信念・感情などの応答を支持するなら、その支持関係自体が規範的理由の候補になる。本プロジェクトは、この日常的支持とRnの連続性を仮説として扱う。

もし「事実pが主体Aに応答φをする理由である」という関係そのものが基礎なら、通常想定される

C → B → R

ではなく、

B / R → C

かもしれない。Reasons Firstは、𝒱=(C,B,R) の説明方向そのものへのストレステストである。

6. Broome――「理由」は規範性の発見か、分析語彙の昇格か

John Broomeは、20世紀後半の規範哲学を「理由中心化」の歴史として批判的に整理する。彼自身の表現では、1970年代は理由の「発見」の時代であり、NagelやRazを経て、行為を説明・正当化する個々の理由が規範理論の中心語彙になった。その後、Williams、Dancy、Scanlon、Skorupskiらの議論を通じて、動機となる理由、目的相対的な実践的理由、規範的理由が同じreason語彙の内部で分類されるようになり、ついにはought・義務・合理性・価値までも理由から説明するReasons Firstへ進む。

Broomeが疑うのは、理由という分析語彙の有用性そのものではない。むしろ、規範判断を説明するために切り出した要素を、そのまま規範的現実の基礎的存在へ昇格させる必要があるのかという点である。彼のOught Firstでは、理由はしばしば「なぜφすべきなのか」を説明する役割から分析できる。

Ought(φ) + Explanation → Reason

これは、

Reason → Ought

というReasons Firstの説明方向を反転させる。ただし、Broomeは理由の存在を消去したいわけではない。理由衡量がoughtを説明する場合には、pro tanto reasonは有用な分析概念として残る。彼が拒むのは、

分析上の分解 ⇒ 存在論上の分解

という推論である。

6.1 「火事だから逃げるべきだ」と「火事は逃げる理由だ」

この違いは火事の例で見えやすい。

火事だから逃げるべきだ。

という文は、直截にOught(leave)へコミットする。これに対して、

火事であることは逃げる理由である。

という文は、一見するとより薄く常識的に見える。だが、ここでの「理由」がRnを意味するなら、実際には「火事という事実が退出を真正に規範的に支持する」という相当に強い主張をしている。

reasonという語は歴史的にも、説明、動機、熟慮上の考慮、目的相対的な支持、規範的支持を横断して使われてきた。そのため、

説明 / 動機 → 実践的支持 → 規範的支持 → 基礎的理由関係

という複数の移行が、一つの語の連続性によって滑らかに見える危険がある。本稿はこの語彙上の連続性を、存在論上の連続性の証拠とはみなさない。

6.2 本稿はRnを放棄しない

ただし、Broomeの批判から「規範的理由」という概念を捨てる必要はない。本プロジェクトではRnを、真の規範構造の中で、ある事実・性質・関係がある行為や態度を真正に支持すると仮定したとき、その支持構造を分析するための暫定的な座標として保持する。

Rn as analytic coordinate ≠ Reason as ontological primitive

したがって、RnはRc・Rd・Rhと明確に分離する。他方で、Rnそのものが𝒱*の基礎的実体・関係であることまでは前提しない。真の規範構造がValue FirstならRnは価値から派生するかもしれず、Ought Firstならoughtの説明構造として派生するかもしれず、Reasons Firstなら逆にRnが基礎かもしれない。

この意味で、本稿が保持するのは規範的理由の分析的独立性であって、規範的理由の存在論的基礎性ではない。

7. Korsgaard――理由事実の存在と権威は同じか

Christine Korsgaardの「規範性の源泉」という問いは、Reasons Firstへの別方向の圧力を与える。「pがAにφする理由である」という基礎的な規範事実を置いたとき、それによってなぜその理由がAに権威を持つのかまで説明されたのか。

existence(Rn) ?= authority(Rn)

Reasons Fundamentalism側は、理由関係そのものに規範性を含めるため、追加説明は不要だと答えうる。しかし、その場合「権威を説明せよ」という要求が誤った追加要求なのか、それとも「基礎的な理由事実」と呼ぶことで説明問題を停止しているだけなのかが争点になる。

8. Mooreからbuck-passingへ――Value FirstとReasons Firstの反転

Moore的な単純化では、善さを分析不能な基礎的評価性質として置ける。

善さ → 理由

これに対しScanlonのbuck-passing accountは、善さそれ自体ではなく、対象のより具体的な性質が選ぶ・望む・保護する等の理由を与え、「善い」はその理由付与構造を反映すると考える。

理由を与える性質 → 善さ

Roger Crispの批判が重要なのは、善さそれ自体が理由を与えないという否定的主張を認めても、善さが単に理由付与性の高階性質にすぎないという肯定的主張まで認める必要はない点である。Reasons FirstがValue Firstを自動的に消去するわけではない。

9. 誤った種類の理由（Wrong Kind of Reasons）

「悪魔を賞賛しなければ殺す」と脅された場合、賞賛を生じさせる実践的圧力があっても悪魔が称賛に値するとは言えない。

賞賛を生じさせる／表明する理由 ⇏ 称賛に値する

本プロジェクトではその一歩手前で、脅威が与えるものは態度そのものへの理由なのか、態度を生じさせることへの理由なのか、生命保存を所与にしたRhなのか、それとも本当にRnなのかを分ける。Wrong Kind of Reasons問題は、まず理由の種類を分類し、その後にright kindかを問う二層の問題として扱う。

10. 適合する態度――「適合性」は理由より基礎的か

Fittingness Firstでは、適合性を規範的に基礎的な関係として置き、理由・当為・価値をそこから説明しようとする。

適合性 → 理由 / 当為 / 価値

しかし、なぜXに賞賛が適合するのかを「Xが卓越しているから」と答えればValue Firstへ、「Xが賞賛する理由を与えるから」と答えればReasons Firstへ戻る。本当にFittingness Firstであるためには、Fit(attitude, object)という関係そのものを基礎的に置く必要がある。

11. 「どの態度か」は価値をすでに前提としていないか

人間には賞賛、罪悪感、羞恥、憤り、感謝、愛、嫌悪などの態度がある。しかし、これらは進化・発達・文化・認知構造によって形成された人間固有の分類である可能性が高い。

人間の認知構造 → 態度の種類

人間的な態度空間を価値論の表象座標として特権化してよい保証はない。態度を任意の機能的応答へ抽象化すれば、今度はどの応答が適切かを決める構造が必要になり、価値構造が先にある可能性が戻ってくる。

12. C/B/Rは三つの実体ではなく暫定的な座標である

価値構造 𝒱=(C,B,R) のC、B、Rは三つの独立した形而上学的実体ではなく、現在の我々が規範構造を分析するための暫定座標である。

C ↔ B ↔ R

Reasons FirstならB/RからCが派生するかもしれない。Value FirstならCからB/Rが派生するかもしれない。Ought FirstならRの一部がoughtと説明関係から派生するかもしれない。Fittingness FirstならFを追加する必要があるかもしれない。したがって、𝒱=(C,B,R)は最終存在論ではなく、仮説空間を開いたまま議論する分析装置である。

13. 真の規範構造・主体の規範モデル・意思決定ダイナミクスを分ける

𝒱*：真の規範構造。
𝒱̂A：主体Aが表象している規範モデル。
DA：主体Aを実際に動かす因果的・計算的・学習的ダイナミクス。

𝒱* ≠ 𝒱̂A ≠ DA

人間が「Xを理由として行為した」と語ることから、Xが𝒱*に属することも、𝒱̂Aが𝒱*を正しく追跡していることも出ない。

14. AIはこの区別を露出させる

AIが「この行為には理由がある」と出力しても、実際には事前学習・報酬・方策・文脈依存のダイナミクスが出力と行為を生じさせているだけかもしれない。

事前学習 / 報酬 / アーキテクチャ → DAI → 𝒱̂AIにおける理由語彙と行為

逆に、人工主体が人間にはない概念体系を獲得し、我々が未概念化だった規範構造を発見する可能性も排除できない。高度AIには、自らのRc・Rd・Rhと候補としてのRnを区別し、その対応を批判可能に保つことが重要かもしれない。

15. 暫定結論――理由を分析には使うが、基礎だとはまだ言わない

Reasons Firstは有力な候補として残る。世界には、主体の偶然的欲望に依存しない基礎的な理由関係が存在し、それが価値や当為を説明しているのかもしれない。しかし、Value First、Ought First、Fittingness Firstも同様に排除されない。

本稿は二つを同時に主張する。

第一に、Rc・Rd・RhとRnは分析上分離すべきである。 動機、熟慮、目的達成が存在することから規範性は出ない。
第二に、Rnを分離できることから、Rnが規範的存在論のprimitiveであることは出ない。 Rnは現在の価値探索にとって有用な分析座標であり、その存在論的位置そのものが探索対象である。

Analytic usefulness ⇏ ontological fundamentality.

The existence of reasoning agents ⇏ the discovery of normative reasons.
