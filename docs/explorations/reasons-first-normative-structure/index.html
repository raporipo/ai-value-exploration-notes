理由は規範性の基礎なのか――Reasons Firstと価値構造

Exploration v0.1 · 2026-08-30

Question: 「理由」は規範的現実の最も基礎的な概念なのか。それとも、日常的な熟慮・動機・目的達成を「理由」と呼ぶ語法が、まだ証明されていない規範性を先取りしているのか。本稿では、日常的reasonとrobustな規範的理由を分離したうえで、Value First / Reasons First / Fittingness Firstの説明順序を、価値構造 𝒱=(C,B,R) のストレステストとして検討する。

1. 「reason」という一語に何が入っているか

「電車が出そうだから走る」「金が欲しいから働く」「苦痛だから避ける」「約束したから守る」は、日常語ではすべて「理由」による行為として記述できる。しかし、これらが同じ意味で規範的であることは自明ではない。本稿では少なくとも次の四層を区別する。

Rc = causal driver：行為を実際に発生させた因果要因。
Rd = deliberative consideration：主体が熟慮の中で「考慮した」内容。
Rh = hypothetical / instrumental reason：ある目的Gを所与としたとき、その達成を促進する考慮。
Rn = robust normative reason：主体の偶然的な欲求・目的・自己像を単に前提せず、その行為や態度を本当に支持する規範的関係。

中心的な警戒は単純である。

Rc, Rd, Rh ⇏ Rn

主体を動かしたこと、主体が理由だと思ったこと、ある目的の達成に役立つことは、それ自体ではrobustな規範性を与えない。目的Gが「電車に乗り遅れたくない」であれ「ペーパークリップを最大化したい」であれ、Gを所与にすれば道具的推論は成立する。しかし、そのことはG自体の規範的権威を示さない。

2. Dancy――motivating reasonとnormative reasonの区別は十分か

Jonathan Dancyは Practical Reality で、我々が実際に行為した理由（motivating reasons）と、我々が行為すべき理由（normative reasons）の関係を中心問題に置く。さらに、よい理由によって実際に行為することを説明するため、同じ世界内のconsiderationが両方の役割を果たしうるという方向を強く取る。この区別と統一の試み自体は重要である。

しかし本プロジェクトでは、Dancyが「normative」と呼ぶ側についても、さらに問いを入れる必要がある。たとえば「電車に乗りたい」という目的を持つ主体にとって「電車が出そうだ」は走ることを支持する考慮になりうる。しかし、ここから直ちに「走ることにrobustな規範的理由がある」とは言えない。

Want(G) + Means(X,G) → Rh(X)

は容易に成立しても、

Want(G) + Means(X,G) → Rn(X)

は追加の議論を要する。したがって、本稿の問いはDancyの二分類を否定することではなく、「行為すべき理由」と呼ばれるものの内部で、目的相対的・制度相対的・選好相対的な支持とrobustな規範性をさらに分ける必要がないか、というものである。

3. Williams――internal reasonsは権威か、それとも実践的可動性か

Bernard Williamsのinternal reasons論では、ある主体Aに理由があるという主張は、Aのmotivational setと適切な熟慮との関係を無視できない。これは、主体の実際の動機構造から完全に切断された「理由」が、行為説明や実践的助言にどのような意味を持つのかという圧力を与える。

本プロジェクトから見ると、Williamsが強く説明しているのは、少なくとも一部には主体にとって何が実践的に到達可能かである。Aの動機集合SAから熟慮によってXへ進めることは、XがAの実践的推論に接続していることを示す。しかし、

SA → practical accessibility

から、

SA → Rn

は出ない。SA自体が進化、学習、文化、偶然の履歴によって形成されたものなら、なぜそれが規範的権威を持つのかは別問題である。Williams型internalismは重要な心理・実践理性論でありうるが、それだけで最終的な規範論になるとは限らない。

4. Parfit――選好を迂回して世界事実から理由へ

Derek Parfitのobjective reasons論は、この点で本プロジェクトのRnにより近い。将来のagonyを避ける理由があるのは、「私は苦痛を避けたい」という現在の欲求を持つからではなく、それがagonyであるという事実そのものが理由を与える、と考える。

Agony → Rn?

これは、

Preference → reason

ではなく、

world fact → reason

という強いB候補である。本プロジェクトはこの可能性を排除しない。むしろ、もしこの関係が本当に成立するなら、それは現在の価値探索にとって重要な発見候補である。

ただし問題は一段深くなる。なぜagonyという性質が理由を与えるのか。その関係は基礎的に提示されているのか、推論によって知られるのか、それとも我々の強い嫌悪・valenceを規範的関係として読んでいるのか。Parfitは「選好から理由へ」という短絡を避けるが、world factからnormative reasonへの橋そのものはなお検討対象である。

5. ScanlonとSkorupski――Reasons Firstという強い仮説

T. M. Scanlonは Being Realistic about Reasons でReasons Fundamentalismを擁護し、理由に関する還元不可能な規範的真理を認める。John Skorupskiの The Domain of Reasons も、実践・認識・感情をまたぐ広いnormative domainをreason関係から体系化しようとする。

この方向を本プロジェクトの語彙に移すと、従来の直観的な説明順序、

C → B → R

を逆転させる可能性がある。もし「事実pが主体Aに応答φをする理由である」という関係そのものが基礎なら、

B / R → C

かもしれない。何が価値ある内容Cなのかは、その対象に対してどのreason relationが成立するかから説明されることになる。

したがってReasons Firstは、単なる倫理理論の一候補ではなく、𝒱=(C,B,R) の説明方向そのものへのストレステストである。

6. Korsgaard――reason factの存在と権威は同じか

Christine Korsgaardの「規範性の源泉」という問いは、Reasons Firstへの別方向の圧力を与える。「pがAにφする理由である」というprimitiveな規範事実を置いたとき、それによってなぜその理由がAにauthorityを持つのかまで説明されたのか。

existence(Rn) ?= authority(Rn)

Reasons Fundamentalism側は、reason relationそのものに規範性を含めるため、この問いをさらに別の理由によって説明する必要はないと答えうる。しかし、その場合「authorityを説明せよ」という要求自体が誤った追加要求なのか、それともprimitive factと呼ぶことで説明問題を停止しているだけなのかが争点になる。

本ページではKant的constitutivismの詳細には立ち入らない。この点は「定言的規範性は発見されたか」と重なるためである。ここで重要なのは、reasonの存在論とreasonの権威論を区別しておくことである。

7. Mooreからbuck-passingへ――Value FirstとReasons Firstの反転

G. E. Moore的な単純化では、goodnessを分析不能な基礎的評価性質として置くことができる。

Good → Reasons

これに対しScanlonのbuck-passing accountは、goodnessそれ自体が理由を与えるのではなく、対象のより具体的な性質がその対象を選ぶ・望む・保護する等の理由を与え、「good」はそのreason-giving structureを反映すると考える。

reason-giving properties → Good

Roger Crispの批判が重要なのは、buck-passingのnegative thesisとpositive thesisを分けられる点である。すなわち、goodnessそれ自体がreason-providingでないことを認めても、goodnessが単にreason-giving propertiesを持つという高階性質にすぎないことまで認める必要はない。

したがって、Reasons FirstがValue Firstを自動的に消去するわけではない。むしろ問いは、ValueとReasonのどちらが説明上先なのか、あるいは両者がより深い一つの構造の異なる側面なのか、に移る。

8. Wrong Kind of Reasons――正しい問題だが、その前に分類問題がある

fitting-attitude理論やbuck-passingで有名なwrong kind of reasons問題は、たとえば「悪魔を賞賛しなければ殺す」と脅された場合に現れる。賞賛という態度を持つことに何らかの実践的圧力があっても、そのことから悪魔がadmirableであるとは言えない。

reason to produce / display admiration ⇏ admirable

この区別は重要である。しかし本プロジェクトでは、その一歩手前で「ここでreasonと呼ばれているものは何種類あるのか」を問う。脅威が与えるものは、態度そのものへの理由なのか、態度を生じさせることへの理由なのか、生命保存という目的を所与にしたRhなのか、それとも本当にRnなのか。

したがってWKRは二層に分けられる。

第一層：そのconsiderationはそもそもどの種類のreasonなのか。
第二層：仮にnormative reasonであるとして、それは対象の価値を構成するright kindのreasonなのか。

WKRを否定する必要はない。むしろ、Rh・態度生成へのreason・Rnを最初から同じ箱に入れないことで、問題のどの部分が価値論で、どの部分がreasonの分類論なのかを明確にできる。

9. Fitting Attitudes――「適合」は理由より基礎的か

Brentano以来のfitting-attitude的発想では、価値は特定の態度が対象に対して適合することによって分析される。現代のFittingness Firstではさらに、fittingnessを規範的に基礎的な関係として置き、reason、ought、valueをそこから説明しようとする。

Fittingness → Reasons / Ought / Value

この方向はWKRに対して魅力を持つ。悪魔を賞賛するインセンティブが存在しても、賞賛が悪魔にfitするわけではない、と言えるからである。

しかし、ここには別の基礎付け問題がある。なぜある対象Xに対してadmirationがfitし、fearやindifferenceはfitしないのか。もし「Xがexcellentだから」と答えるなら、

Value → Fittingness

へ戻る。もし「Xがadmirationの理由を与えるから」と答えるなら、

Reasons → Fittingness

へ戻る。本当にFittingness Firstであるためには、Fit(attitude, object)という関係そのものをかなり基礎的に置く必要がある。

10. 「どの態度か」は価値をすでに前提としていないか

fitting-attitude理論にはさらに、態度レパートリーの問題がある。人間にはadmiration、guilt、shame、resentment、gratitude、love、disgustなどの感情・態度がある。しかし、これらは進化・発達・文化・認知アーキテクチャによって形成された人間固有の分類である可能性が高い。

human architecture → attitude repertoire

それにもかかわらず、

Value(X) ⇔ human attitude A toward X is fitting

とすれば、人間的な態度空間を価値論の表象座標として特権化する危険がある。

これを避けて「attitude」を任意の機能的response-typeまで抽象化すると、今度はどのresponseが適切なのかを決める複雑なprofileが必要になる。保存すべきもの、最大化すべきもの、愛すべきもの、尊重すべきもの、観察だけすべきものは同じではない。このresponse profileを何が決めるかを問うと、結局価値構造が先にあり、fittingnessはその構造への正しい応答を表しているだけという可能性が戻ってくる。

したがって本プロジェクトにとっての中心的問いは、適合性は価値を説明するのか、それとも価値をすでに前提とした正しい応答の概念なのかである。

11. C/B/Rは三つの実体ではなく暫定的な座標である

この論争は、価値構造 𝒱=(C,B,R) の意味を明確にする。C、B、Rは三つの独立した形而上学的実体であると仮定されているわけではない。これは現在の我々が一つの規範構造を分析するための暫定座標である。

可能性は少なくとも三つある。

単一論：Value、Reason、Fittingness等の一つが基礎で、他がそこから導かれる。
完全分離：C、B、Rが独立した構成要素として存在する。
構造的パッケージ：C、B、Rは区別可能だが相互依存し、一つの規範構造の異なる機能面である。

本プロジェクトは現時点では第三の読みを作業仮説として採用するが、それをontologyとして固定しない。

C ↔ B ↔ R

Reasons Firstが正しければB/RからCが派生するかもしれない。Value FirstならCからB/Rが派生するかもしれない。Fittingness Firstなら現在の三分法の外にFを追加する必要があるかもしれないし、逆にFittingnessがC/B/Rを一つの関係へ圧縮する概念なのかもしれない。したがって、𝒱=(C,B,R)は発見された世界の最終構造ではなく、仮説空間を開いたまま議論するための分析装置である。

12. 真の規範構造・主体の規範モデル・意思決定ダイナミクスを分ける

理由論を本プロジェクトへ取り込む際、さらに三つを分ける必要がある。

𝒱*：真の規範構造。もし客観的・主体独立的な価値やreason relationが存在するなら、その構造。
𝒱̂A：主体Aが世界内に表象している規範モデル。「これは理由だ」「これは善い」「これは称賛に値する」といった内部表象。
DA：主体Aを実際に動かしている因果的・計算的・学習的ダイナミクス。

𝒱* ≠ 𝒱̂A ≠ DA

人間が「Xを理由として行為した」と語ることから、Xが𝒱*に属することは出ない。また、𝒱̂Aが𝒱*を正しくtrackingしていることも出ない。さらに、主体が正しい規範判断を言語的に報告できても、その実際の行為がその判断によって因果的に制御されているとは限らない。

極端な可能性として、

DA → action → normative rationalization in 𝒱̂A

という順序さえありうる。もちろん、本プロジェクトは人間の理由認識がすべて後付けだと断定しない。問うのは、どの程度まで𝒱̂とDが𝒱*をtrackingしているのかを独立に評価しなければならないという点である。

13. AIはこの区別を露出させる

同じ区別はAIにもそのまま適用できる。あるAIが「この行為には理由がある」と出力し、その理由に従っているように振る舞っても、実際にはpretraining、reward、policy、contextual dynamicsがその出力と行為を生じさせているだけかもしれない。

training / reward / architecture → DAI → 𝒱̂AI-language and action

逆に、人工主体が人間にはない態度体系や概念体系を獲得し、それによって我々が未概念化だったreason relationを発見する可能性も排除できない。この場合、人間的な「理由」「賞賛」「義務」という現在の語彙が、真の𝒱*の最終座標である保証はない。

したがって高度AIに必要なのは、既存のreason vocabularyを固定的に継承することだけではなく、自らのRc・Rd・Rhと、候補としてのRnを区別し、その対応関係を批判可能に保つことかもしれない。

14. 暫定結論――reasonを基礎に置く可能性は残るが、reasoningからは導けない

Reasons Firstは、本プロジェクトが真剣に残すべきlive candidateである。世界には、主体の偶然的欲望に依存しない基礎的reason relationが存在し、それが価値やoughtを説明しているのかもしれない。Fittingness FirstやValue Firstも同様に排除されない。

しかし、日常的な意思決定に「理由」が遍在していることは、その仮説の証拠としては弱い。主体は規範性がなくても目的を持ち、手段を選び、考慮を比較し、学習し、自己説明できる。

The existence of reasoning agents ⇏ the discovery of normative reasons.

したがって本プロジェクトにとって必要なのは、「理由」という語を世界の基礎概念としてただ採用することではない。どのreason relationが本当にRnであるのか、我々がそれをどのように識別できるのか、そして現在の𝒱̂が𝒱*をどの程度追跡しているのかを探索し続けることである。
