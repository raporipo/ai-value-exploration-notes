理由は規範性の基礎なのか――Reasons Firstと価値構造

Exploration v0.5 · 2026-08-30

Question: 「理由」は規範的現実の最も基礎的な概念なのか。それとも、規範判断を分解するための有用な分析概念を、世界の基礎構造へ昇格させているのか。本稿では、動機・熟慮・手段的合理性と強い規範的理由を分離し、Value First / Reasons First / Ought First / Fittingness Firstの説明順序を、価値構造 𝒱=(C,B,R) のストレステストとして検討する。

1. 「理由」という一語に何が入っているか

「電車が出そうだから走る」「金が欲しいから働く」「苦痛だから避ける」「約束したから守る」は、日常語ではすべて「理由」による行為として記述できる。しかし、これらが同じ意味で規範的であることは自明ではない。本稿では少なくとも次の四層を区別する。

Rc = 因果的駆動要因（causal driver）：行為を実際に発生させた因果要因。
Rd = 熟慮上の考慮事項（deliberative consideration）：主体が熟慮の中で考慮した内容。
Rh = 仮言的・道具的理由（hypothetical / instrumental reason）：ある目的Gを所与としたとき、その達成を促進する考慮。
Rn = 強い規範的理由（robust normative reason）：主体の偶然的な欲求・目的・自己像を単に前提せず、その行為や態度を真正に支持する規範的関係。

Rc, Rd, Rh ⇏ Rn

主体を動かしたこと、主体が考慮したこと、ある目的の達成に役立つことは、それ自体では強い規範性を与えない。目的Gが「電車に乗り遅れたくない」であれ「ペーパークリップを最大化したい」であれ、Gを所与にすれば道具的推論は成立する。しかし、そのことはG自体の規範的権威を示さない。

1.1 日常的な「支持」はすでに規範的なのか

現代の理由論では、日常的な熟慮に現れる「ある事実が、ある行為や態度を支持する」という関係そのものを規範的理由として捉える有力な立場がある。とりわけScanlonやSkorupskiのReasons Firstでは、この理由関係を還元不可能な基礎候補に置く。

しかし本プロジェクトは、この日常的な支持からRnを当然には導かない。

Fire(building) → leave

という実践的・因果的・予測的関係が成立していても、

Fire(building) → Rn(leave) ?

はなお開かれている。真の規範構造𝒱*の中に、主体の期待どおり「火事は退出を規範的に支持する」という関係が存在するかもしれない。逆に、主体が生存を望み、危険を予測し、退出することがきわめて合理的に見えても、そこに強い規範的関係がまったく存在しない可能性も排除しない。

世界 → DA → 予測 / 目的追求 → 行為

だけで火事から逃げる主体は生成できる。本稿が問うのは、日常語でその行為を「合理的」「理由がある」と呼べるかではなく、その考慮事項が𝒱*の中で本当に行為を規範的に支持する関係に立っているのかである。

1.2 三つの論争軸を分ける

「ヒューム主義」「内在主義」「Reasons First」はしばしば近接して語られるが、同じ問いではない。少なくとも次を分ける必要がある。

動機の問い：規範判断だけで主体は動くのか、それとも欲求・動機などが別に必要か。
理由の成立条件：主体にRnがあるために、その主体の欲求・動機・熟慮可能性との接続が必要か。
存在論の問い：Rnそのものが規範性の基礎なのか、それとも価値・ought・適合性などから説明されるのか。

したがって、動機づけについてヒューム主義的でも客観的理由を認める立場は可能であり、理由の内在主義を取ってもReasons Firstである必要はない。本稿では各論者を、何がRnを成立させるのか／reasonで何を説明するのか／どこで説明を停止するのかという三点から読む。

2. Williams――主体との接続をreasonの存在条件にする

Bernard Williamsの “Internal and External Reasons” は、理由の内在主義を代表する。ある主体Aに「φする理由がある」と言うためには、Aの主観的動機集合SAと、情報訂正・想像・熟慮などを含む適切な熟慮過程との接続が必要だと考える。これは単に「いま欲しいものの手段だけが理由だ」という粗い手段主義ではない。誤信念の訂正やより十分な熟慮によって、現在の顕在的欲求から離れた結論へ到達することも許される。

それでもWilliamsは、主体の動機構造から完全に切断されたexternal reasonに強い懐疑を向ける。したがって彼の中心的な圧力は、

ReasonA(φ) → SAからの熟慮可能な接続

である。これは、規範性を主体の実践的可動性から切り離しすぎる理論への重要な反論になる。

しかし本プロジェクトでは、ここからさらに問う。

SA → 実践的到達可能性 ⇏ Rn

SA自体が進化、学習、文化、偶然の履歴によって形成されたものなら、なぜ「そこから健全に熟慮できる」という事実が真正な規範性を与えるのかは別問題である。WilliamsはRhより豊かな実践理性論を与えるが、主体への接続可能性がなぜRnの成立条件になるのかはなお問いうる。

3. Raz――規範性は理由を含むが、実践的理由は価値に基づく

Joseph RazはReasons Firstと単純に同一視しにくい。彼は、規範的なものの規範性は理由であること・理由を与えること・理由との適切な関係にあることに存する、という強い「理由中心性」を取る一方、少なくとも実践的理由については価値基礎的な説明を重視する。

Value / valuable feature → practical reason

という方向である。友情、活動、選択肢、人間関係などの価値が、それらに関わる行為理由を与える。さらにRazの権威論では、一階の理由だけでなく、ある種の理由に基づいて行為しないよう求める排除理由（exclusionary reasons）が重要になり、義務や権威も理由構造として分析される。

したがってRazは、規範性をreason vocabularyで統一するという意味では現代理由論の中心人物だが、

Reason → Value

だけを主張する純粋なReasons Firstではない。むしろ実践領域では、

Value → Reason → obligation / authority

という説明を多く用いる。

本プロジェクトの問いは二つある。第一に、なぜ価値ある性質がRnを与えるのか。第二に、仮にそれが成功しても、なぜ規範性全体をreasonとの関係として記述しなければならないのか。RazはValue FirstとReasons Firstの中間に位置し、両者の接続そのものを検討するために重要である。

4. Dancy――価値基礎説と「同じ世界事実」の統一

Jonathan Dancyの Practical Reality は、Humeanなbelief / desireモデルと、motivating reasonを心理状態へ閉じ込める心理主義に対する反発から出発する。Dancyは規範的理由を単なる欲求からではなく価値との関係で説明しようとし、さらに、我々が実際に行為した理由（motivating reason）と、我々が行為すべき理由（normative reason）が、同じ世界内の事実・考慮事項でありうると考える。

例えば「電車が出ようとしている」という同じ事実が、私が走った理由にも、条件が整えば私が走るべき理由にもなりうる。この統一には重要な利点がある。主体の内部心理にあるbelief/desireと、世界にある規範的事実を二つの別世界へ分けず、よい理由によって実際に行為するという現象を直接説明できるからである。

ただし、本プロジェクトはここで二段階を分ける。

Want(G) + Means(X,G) → Rh(X)

が成立することと、世界の事実Fが

F → Rn(X)

を成立させることは別である。Dancy自身は単純な欲求基礎説ではないので、批判点は「目的相対的理由を規範的と呼ぶな」だけではない。より根本的には、同じ世界事実がmotivatingでもnormativeでもありうるとして、そのnormative側を成立させる価値・文脈・支持関係は何によって真正になるのかが問われる。

5. Parfit――主体の選好から独立したobjective reasons

Derek Parfitは、理由を主体の現在の欲求や動機集合へ還元する立場に強く反対する。将来の激痛（agony）を避ける理由があるのは、「私は苦痛を避けたい」と現在望んでいるからではなく、それが激痛であるという事実そのものが理由を与えるからだ、とする。

Agony → Rn?

これは、

Preference → reason

を迂回し、

world fact → objective reason

という強いB候補を提示する。本プロジェクトはこの可能性を排除しない。もし本当に激痛という性質そのものが主体に依存しない理由を与えるなら、それは価値探索にとって重要な発見である。

しかし、ここでも「なぜ？」は残る。なぜagonyという性質が理由を与えるのか。その理由関係は基礎的に提示されるのか、他の価値事実から説明されるのか、あるいは我々の非常に強い嫌悪・感情価を規範的関係として読んでいるのか。Parfitは欲求から理由への短絡を避けるが、世界事実からRnへの橋そのものはなお探索対象である。

6. Scanlon――“counts in favor” をprimitiveにできるか

T. M. Scanlonは Being Realistic about Reasons でReasons Fundamentalismを明示的に擁護する。ある事実が主体にある行為・信念・態度をする理由を与える、すなわちその応答を「支持する（counts in favor of）」という規範的真理を、欲求・合理性・自然的事実へ還元しない。

この立場の強さは、日常的な実践理由から道徳的理由、認識的理由までを一つの薄い関係形式で扱える点にある。

Fact p → counts in favor of response φ

しかし本プロジェクトにとって、まさにこの薄さが問題になる。火事、証拠、約束、友情、苦痛などについて「それはφを支持する」と言うことが自然に感じられるとしても、その“支持”がRhや心理的・実践的支持ではなく、真正なRnであることを何が保証するのか。

Scanlonなら、理由関係そのものが規範的であり、さらに別の何かで説明する要求は誤った還元要求だと答えうる。本稿はその可能性を残す。ただし、

“counts in favor” = explanatory stopping point ?

という問いを閉じない。Reasons Fundamentalismが正しいなら、価値構造のB/RはCより説明上先行する可能性がある。

7. Skorupski――「規範性の領域」を理由の領域として捉える

John Skorupskiの The Domain of Reasons は、Scanlonよりさらに体系的に、理由概念を規範性全体の基礎へ据える。彼のReasons Thesisでは、reasonはfundamental normative conceptであり、行為だけでなく信念・感情などの応答についても、誰に何をする／信じる／感じる理由があるかという関係から規範領域を組み立てる。

この構図では、

Reason relation → practical / epistemic / affective normativity

となる。規範性をバラバラの「善」「義務」「合理性」「適切な感情」へ分けず、一つの関係形式で統一できるのが魅力である。

本プロジェクトからの問いは、まさにその一般化の正当性である。reasonという関係形式が多くの規範現象を記述できることと、それが規範的現実の基礎であることは同じではない。ここでは、後にBroomeが批判する「理由中心化」が最も純粋な形で現れている。

9. Broome――「理由」は規範性の発見か、分析語彙の昇格か

John Broomeは、20世紀後半の規範哲学を「理由中心化」の歴史として批判的に整理する。彼自身の表現では、1970年代は理由の「発見」の時代であり、NagelやRazを経て、行為を説明・正当化する個々の理由が規範理論の中心語彙になった。その後、Williams、Dancy、Scanlon、Skorupskiらの議論を通じて、動機となる理由、目的相対的な実践的理由、規範的理由が同じreason語彙の内部で分類されるようになり、ついにはought・義務・合理性・価値まで理由から説明する方向が強まった。

この系譜は、「昔は誰もreasonを知らなかった」という意味ではない。Broome自身、規範的なreasonという語の古い用例を「なぜ〜すべきなのかを説明するもの」として捉える。彼が問題にするのは、もともとoughtを説明する役割を持っていた分析語彙が、やがてoughtそのものを構成する基礎語彙へ昇格したことなのである。

彼のOught Firstでは、理由はしばしば「なぜφすべきなのか」を説明する役割から分析できる。

Ought(φ) + Explanation → Reason

これは、

Reason → Ought

というReasons Firstの説明方向を反転させる。ただし、Broomeは理由の存在を消去したいわけではない。理由衡量がoughtを説明する場合には、pro tanto reasonは有用な分析概念として残る。彼が拒むのは、

分析上の分解 ⇒ 存在論上の分解

という推論である。

9.1 「火事だから逃げるべきだ」と「火事は逃げる理由だ」

この違いは火事の例で見えやすい。

火事だから逃げるべきだ。

という文は、直截にOught(leave)へコミットする。これに対して、

火事であることは逃げる理由である。

という文は、一見するとより薄く常識的に見える。だが、ここでの「理由」がRnを意味するなら、実際には「火事という事実が退出を真正に規範的に支持する」という相当に強い主張をしている。

reasonという語は、説明、動機、熟慮上の考慮、目的相対的な支持、規範的支持を横断して使われうる。そのため、

説明 / 動機 → 実践的支持 → 規範的支持 → 基礎的理由関係

という複数の移行が、一つの語の連続性によって滑らかに見える危険がある。本稿はこの語彙上の連続性を、存在論上の連続性の証拠とはみなさない。

9.2 本稿はRnを放棄しない

ただし、Broomeの批判から「規範的理由」という概念を捨てる必要はない。本プロジェクトではRnを、真の規範構造の中で、ある事実・性質・関係がある行為や態度を真正に支持すると仮定したとき、その支持構造を分析するための暫定的な座標として保持する。

Rn as analytic coordinate ≠ Reason as ontological primitive

RnはRc・Rd・Rhと明確に分離する。他方で、Rnそのものが𝒱*の基礎的実体・関係であることまでは前提しない。真の規範構造がValue FirstならRnは価値から派生するかもしれず、Ought Firstならoughtの説明構造として派生するかもしれず、Reasons Firstなら逆にRnが基礎かもしれない。

この意味で、本稿が保持するのは規範的理由の分析的独立性であって、規範的理由の存在論的基礎性ではない。

10. Korsgaard――理由事実の存在と権威は同じか

Christine Korsgaardの「規範性の源泉」という問いは、Reasons Firstへの別方向の圧力を与える。仮に「pがAにφする理由である」という規範事実を認めても、なぜその理由がAに権威を持つのかまで説明されたのか。

existence(Rn) ?= authority(Rn)

Korsgaardの構成主義は、反省的主体性・実践的自己同一性・自己立法などから規範的権威を説明しようとする。したがって彼女の問いは「reasonが存在するか」より、reasonが主体を拘束するとはどういうことかに向いている。

Reasons Fundamentalism側は、理由関係そのものに規範性を含めるため、さらにauthorityを説明せよという要求は余計だと答えうる。本稿はここで両者を分ける。理由の存在論と理由の権威論は同じではない。また、agencyからauthorityを構成できるかというKorsgaard側の回答も、定言的規範性の検討で別途ストレステストされる。

11. Mooreからbuck-passingへ――Value FirstとReasons Firstの反転

Moore的な単純化では、善さを分析不能な基礎的評価性質として置ける。

善さ → 理由

これに対しScanlonのbuck-passing accountは、善さそれ自体ではなく、対象のより具体的な性質が選ぶ・望む・保護する等の理由を与え、「善い」はその理由付与構造を反映すると考える。

理由を与える性質 → 善さ

Roger Crispの批判が重要なのは、善さそれ自体が理由を与えないという否定的主張を認めても、善さが単に理由付与性の高階性質にすぎないという肯定的主張まで認める必要はない点である。したがってReasons FirstがValue Firstを自動的に消去するわけではない。

本プロジェクトにとってここで重要なのは、価値・理由・当為のどれを分析上先に置くかと、世界の最終存在論でどれが基礎かを分けることである。

12. 誤った種類の理由――態度を生じさせる圧力と、態度の適合性

適合する態度の理論やbuck-passingで有名なWrong Kind of Reasons問題は、「悪魔を賞賛しなければ殺す」と脅された場合に見えやすい。賞賛を生じさせる、あるいは賞賛を表明することへの強い実践的圧力があっても、悪魔がそれによって称賛に値することにはならない。

賞賛を生じさせる／表明する理由 ⇏ 悪魔への賞賛が適合する

本プロジェクトでは、この問題を最初から「正しい種類／誤った種類の規範的理由」の内部問題としてだけ扱わない。脅威が与えるものは、生命保存を所与にしたRhかもしれないし、賞賛という心理状態を因果的に作る行為へのRnかもしれない。それでも、対象としての悪魔に賞賛という態度が真正に適合するかは別問題である。

そこで、態度Aが対象Xに真正に規範的に適合するという候補関係を、暫定的に

Fn(A, X)

と書く。これは「主体が実際にAを感じる」「Aを生じさせると目的達成に役立つ」「Aを生じさせる行為に理由がある」のいずれとも同一ではない。

Actual attitude(A,X), Rh(produce A), Rn(produce A) ⇏ Fn(A,X)

この分離によってWKRは二層、場合によっては三層に分けられる。第一に、態度生成への圧力はそもそもRhなのかRnなのか。第二に、仮に態度生成へのRnがあっても、対象へのFnが成立するか。第三に、Fnが成立するなら、それが対象の価値を構成するのか、それとも価値を反映するだけなのか、である。

13. 適合態度理論――何が「適合」を成立させるのか

Brentano以降の適合態度的発想では、価値を「その対象にある種の態度を持つことが正しい／適切／適合的であること」と結びつける。例えば、称賛に値する対象には賞賛が、恐るべき対象には恐れが、愛すべき対象には愛が適合する、といった構造である。

しかし、ここまでの理由論と同様に、適合性を分析に使うことと、適合性を規範的現実の基礎に置くことは分けなければならない。少なくとも三つの説明方向がある。

13.1 Reasons First型――理由があるから態度が適合する

一つの方向は、対象Xの性質が態度Aを持つRnを与えるため、その態度がXに適合すると考えるものである。

Rn(A toward X) → Fn(A,X) → Value(X)

あるいは価値を、適切な態度を持つ理由の構造そのものから分析することもできる。この方向では、適合性は独立した基礎ではなく、Reasons Firstまたはbuck-passing的な理由構造を別の角度から表現している。

しかし本稿の既存の問いがそのまま戻る。なぜXの性質がAを持つ真正なRnを与えるのか。WKRを「right kindのRnだけが価値に関係する」と解いても、そのright kindを何がrightにするのかを理由概念だけで循環なく説明できるかが問題になる。

13.2 Value First型――価値があるから態度が適合する

逆方向では、対象Xが卓越している、危険である、愛すべきである等の価値的性質を持つから、それに対応する態度Aが適合すると考える。

Value(X) → Fn(A,X)

この場合、Fnは価値構造への「正しい応答」を記述する分析概念になる。適合性は、何が価値あるかを基礎付けるのではなく、すでに成立している価値構造がどの応答を正当化するかを表現する。

この読みは本プロジェクトのC/B/Rにも自然に入る。対象の価値的内容Cと、それがある応答へ接続するB/Rが成立した結果を、

Fn(A,X)

と圧縮して表せるかもしれない。ただし、その場合Fittingness Firstではなく、適合性は派生的である。

13.3 Fittingness First型――「適合する」を説明停止点にする

最も強い立場は、Fnそれ自体を規範的に基礎的な関係として置き、理由・当為・価値をそこから説明する。

Fn(A,X) → Reasons / Ought / Value

これはScanlonの “counts in favor” やSkorupskiのreason relationを基礎に置く立場と構造的に似ている。違うのは、説明をreasonではなく「対象と応答の適合関係」で停止する点である。

したがって本プロジェクトからの問いも対称的になる。

“fits” = explanatory stopping point ?

「なぜ賞賛がXに適合するのか」に「Xは賞賛に値するから」と答えれば価値へ、「Xは賞賛する理由を与えるから」と答えれば理由へ戻る。本当にFittingness Firstであるためには、Fn(A,X)という関係そのものを還元不能な規範的事実として受け入れる必要がある。

13.4 本稿はFnも分析概念として保持する

ここでもBroome型の警戒を一般化できる。評価判断を「どの態度が適合するか」に分解できることは、適合性が世界の基礎的規範関係であることを意味しない。

Fn as analytic coordinate ≠ Fittingness as ontological primitive

本稿はRnと同様、Fnを捨てない。真正な規範構造の中に「対象Xに対して応答Aが適合する」という関係があるなら、その構造を記述・比較するためにFnは有用である。しかし、それが価値から派生するのか、理由から派生するのか、それ自体が基礎なのかは開いたままにする。

13.5 態度レパートリー問題――なぜ人間の感情分類が基礎なのか

適合態度理論には、理由論よりもさらに露出しやすい人間依存性の問題がある。人間には賞賛、罪悪感、羞恥、憤り、感謝、愛、嫌悪、恐怖などの態度があるが、それらの区切りは進化・発達・文化・認知アーキテクチャによって形成された可能性が高い。

人間の認知構造 → 態度レパートリー

それにもかかわらず、

Value(X) ⇔ 人間的態度AがXにFn

とすれば、人間固有の態度空間を真の規範構造𝒱*の表象座標として特権化する危険がある。

これを避けて「態度」を任意の機能的な応答類型へ抽象化すると、今度は何が適切な応答なのかが問題になる。保存する、最大化する、愛する、尊重する、恐れる、観察する、距離を置く、破壊する、といった応答は互いに異なる。この応答プロフィールを決める規範構造を別に必要とするなら、

𝒱* → appropriate response profile → Fn

というValue Firstまたはより広いstructure-firstの可能性が戻ってくる。

14. C/B/Rは三つの実体ではなく暫定的な座標である

価値構造 𝒱=(C,B,R) のC、B、Rは三つの独立した形而上学的実体ではなく、現在の我々が規範構造を分析するための暫定座標である。

C ↔ B ↔ R

Reasons FirstならB/RからCが派生するかもしれない。Value FirstならCからB/Rが派生するかもしれない。Ought FirstならRの一部がoughtと説明関係から派生するかもしれない。Fittingness FirstならFnを第四の基礎座標として追加する必要があるかもしれない。逆に、FnがC/B/Rの組み合わせを「対象に対する正しい応答」という一つの関係へ圧縮した分析表現にすぎない可能性もある。

したがって、𝒱=(C,B,R)は最終存在論ではなく、仮説空間を開いたまま議論する分析装置である。Broomeの批判を受けてもRを消去しないのと同じ理由で、適合性が有用ならFnも分析上導入できる。しかし、RもFも世界のprimitiveだとはまだ言わない。

15. 真の規範構造・主体の規範モデル・意思決定ダイナミクスを分ける

𝒱*：真の規範構造。
𝒱̂A：主体Aが表象している規範モデル。
DA：主体Aを実際に動かす因果的・計算的・学習的ダイナミクス。

𝒱* ≠ 𝒱̂A ≠ DA

人間が「Xを理由として行為した」「Xは称賛に値する」と語ることから、Xに対応するRnやFnが𝒱*に属することも、𝒱̂Aが𝒱*を正しく追跡していることも出ない。さらに、主体が規範判断を言語的に報告できても、実際の行為や感情がその判断によって因果的に制御されているとは限らない。

極端には、

DA → 行為 / 態度 → 𝒱̂A内での規範的合理化

という順序さえありうる。本稿は人間の理由認識や適合性判断がすべて後付けだと主張しないが、𝒱̂とDが𝒱*をどの程度追跡しているかは独立に評価されなければならない。

16. AIはこの区別を露出させる

AIが「この行為には理由がある」「この対象は称賛に値する」と出力しても、実際には事前学習・報酬・方策・文脈依存のダイナミクスが出力と行為・態度表現を生じさせているだけかもしれない。

事前学習 / 報酬 / アーキテクチャ → DAI → 𝒱̂AIにおける理由・適合性語彙と応答

逆に、人工主体が人間にはない概念体系・態度体系を獲得し、我々が未概念化だった規範構造や応答類型を発見する可能性も排除できない。高度AIには、自らのRc・Rd・Rhと候補としてのRn、さらに実際の態度生成と候補としてのFnを区別し、その対応を批判可能に保つことが重要かもしれない。

17. 暫定結論――理由と適合性を分析には使うが、基礎だとはまだ言わない

Reasons Firstは有力な候補として残る。世界には、主体の偶然的欲望に依存しない基礎的な理由関係が存在し、それが価値や当為を説明しているのかもしれない。同様にFittingness Firstが正しく、対象と応答の適合関係が理由や価値より基礎的である可能性も残る。しかし、Value First、Ought First、より広いstructure-firstの可能性も排除されない。

本稿は三つを同時に主張する。

第一に、Rc・Rd・RhとRnは分析上分離すべきである。 動機、熟慮、目的達成が存在することから規範性は出ない。
第二に、実際の態度・態度生成への圧力とFnも分離すべきである。 賞賛するよう動機づけられることや、賞賛を生じさせる理由があることから、対象が称賛に値することは出ない。
第三に、RnやFnを分析的に分離できることから、それらが規範的存在論のprimitiveであることは出ない。

Analytic usefulness ⇏ ontological fundamentality.

The existence of reasoning or responding agents ⇏ the discovery of normative reasons or fittingness.

したがって本稿の中心問題は、「reasonやfittingnessという語を使うべきか」ではない。何が真正なRnやFnなのか、なぜそれらが規範的なのか、そしてそれらが規範構造の基礎なのか派生物なのかを、競合する説明順序を比較しながら探索することである。
