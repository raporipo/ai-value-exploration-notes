自己位置づけ確率は物理世界を選べるか

SSA・SIA・Doomsday Argument · Exploration v0.1 · 2026-08-09

Question: 「私はこの観測者である」「私は歴史上この位置にいる」という自己位置づけ情報は、宇宙の大きさ、観測者総数、人類の未来といった非自己位置づけ的な世界のあり方について、どこまで独立した証拠になりうるのか。

1. SSAが要求するもの

Self-Sampling Assumption（SSA）は、おおまかには、自分を適切なreference classに属する観測者からのランダムな標本であるかのように扱う。有限の場合、世界仮説Hの下でreference classにN個の観測者が存在し、そのうち現在の自己位置づけ的証拠Eと適合するものがn個なら、SSA的likelihoodは概念的には P(E|H,R) ∝ n/N の形になる。

しかし、この式は観測内容だけでは動かない。何を観測者と数えるか、どの観測者を同じreference classへ入れるか、observerとobserver-momentのどちらを単位にするか、コピーやAIをどう扱うかというobserver measureが必要になる。

2. reference classは最小基礎から自動的には出ない

「私は人間である」「21世紀の人間である」「現在この記憶を持つ主体である」「この瞬間この経験を持つobserver-momentである」。どこまでをreference classに入れるかでSSAの更新は変わる。

本サイトの瞬間的最小基礎から見ると、外界、他者、過去の自分、未来の自分、さらには「人類」という集合も、現在の現れから推論によって構成される世界モデルに属する。したがって、世界モデルに依存せずにreference classを正当化しようとして、認識論的に直接保証される範囲だけへ縮小していけば、極限では現在のこのobserver-momentだけに近づく。

このsingleton classでは、「自分が現在のobserver-momentである」という自己位置づけ情報はほとんど自明であり、外部世界の人口や寿命について新しい情報を与えない。

3. これは形而上学的独我論ではなく、認識論的な縮退である

ここから「世界には自分しか存在しない」とは導かれない。他者や物理世界は、通常の観測と推論によって極めて強く支持できる。

批判点はより限定的である。SSAを、他の世界推論に先立つ基礎原理として純化しようとすると、reference classが現在の現れへ縮退し、物理世界について無情報になる。 したがって「SSAは独我論を証明する」のではなく、「SSAだけでは、物理世界について有益なreference classを独立に構成できない」と考える。

4. reference classを広げるには、先に世界モデルが必要になる

SSAを宇宙論や人口論へ使うには、他人、過去と未来、AI、コピー、simulation内主体などを数える必要がある。しかしそれらが存在し、どのように数えられるかは、まさに物理世界・主体論・存在論についての仮説に依存する。

すると、世界モデルからreference classとmeasureを作り、そのmeasureを使ったSSAで同じ世界モデルの確率を更新するという循環の危険が生じる。この循環が常に不正というわけではない。observer measureを世界モデルの明示的な一部として仮定し、その仮定込みでBayesian comparisonを行うことはできる。しかしその場合、SSAは世界について独立の情報を生み出す原理ではなく、追加のsampling modelを含んだ理論の一部である。

5. 実際の標本抽出とは区別する

1000人から本当に一人を一様ランダムに選び、その属性を観察するなら、その標本は母集団について通常のBayesian evidenceになる。そこでは母集団、標本単位、抽出機構、抽出確率が物理的に定義されている。

問題は、「私がこの宇宙のこの主体として存在する」という事実そのものを、同じランダム抽出過程として扱ってよいかである。SSAはこれをas if random sampleという認識原理によって補う。その追加原理に、実際の物理的sampling processと同じ資格があるかは別途論証が必要になる。

6. SIAはSSAの鏡像的な圧力を持つ

Self-Indication Assumption（SIA）は、他の条件が同じなら、自分が存在するという事実を、多数の観測者が存在する世界への証拠として扱う。単純化すれば、仮説Hを観測者数Nで重みづけする PSIA(H) ∝ N · P(H) という方向になる。

SSAが、大きな世界では「自分がこの位置にいる確率」が薄まるとして多数観測者世界を不利にするのに対し、SIAは多数観測者世界では「自分に相当する観測者が存在する機会」が増えるとして逆向きに重みを掛ける。この意味で両者は鏡像的である。

Olumが論じたSIAによるDoomsday Argumentの相殺も、有限で同じ観測者集合を使う単純な場合には、このNと1/Nの相殺として理解できる。しかし、相殺するから両方とも基礎原理として正しいとは限らない。同じobserver measureを一方が掛け、もう一方が割っているだけかもしれない。

7. SIAもobserver measureを自力では決められない

観測者数を増やす方法には、宇宙を大きくする、文明を長く存続させる、同じ人格を大量コピーする、observer-momentを高密度に生成する、巨大なsimulationを走らせる、といった多数の方向がある。

したがってSIAでも、「何を一個の存在機会と数えるか」が決まらなければ重みづけは決まらない。無限宇宙や無限observer measureでは、単純な人数の比較や正規化そのものが定義困難になる。SSAの小さい世界への圧力と、SIAの大きい世界への圧力は、この意味でも対称的な問題を抱える。

8. Doomsday Argumentの更新はsampling assumptionに依存する

Doomsday Argumentでは、人類が比較的早く絶滅する世界と、非常に長く存続して膨大な人数を生む世界を比較すると、現在の出生順位は前者では典型的だが後者では極端に初期になるため、SSA的には短命な人類史が支持される。

しかし、この更新の主要部分は「自分を全人類から一様ランダムに選ばれた標本のように扱う」という仮定にある。SSAのreference classとsampling measureが独立に正当化されないなら、現在の出生順位だけから、人類の総人口や絶滅時期について新しい物理的証拠が得られたとはみなさない。

これは絶滅リスクが低いという主張ではない。AI、バイオリスク、戦争、自然災害、人口動態などについての通常の物理的・歴史的証拠は、そのまま未来予測へ使われる。

9. SSA/SIAに似たmeasureは意思決定では別の役割を持ちうる

複数のコピー、branch、observer-momentが存在すると仮定した後で、それらを意思決定上どう重みづけるかという問題には、何らかのmeasureが必要になる。この場合、SSA/SIAに似た規則を世界の真理を発見する原理ではなく、既に仮定された世界内での意思決定・効用集計規則として置くことはできる。

認識論ではmeasureの根拠そのものが問題になるが、意思決定ではmeasureを政策上の規約として明示できる。この区別をしないと、「世界は何人の観測者を含むか」と「その観測者たちをどのように意思決定上数えるか」が混同される。

10. Full Non-indexical Conditioningとの近さ

Radford NealのFull Non-indexical Conditioning（FNC）は、単に「私は観測者として存在する」と条件づけるのではなく、自分の具体的な記憶を含む利用可能な全証拠へ条件づける方向を提案する。これはreference classを先に選ぶより、このサイトの立場に比較的近い。

ただし、本サイトでは現在の記憶や自己像も、その因果的由来については現在の現れから推論されると考える。したがってFNCをそのまま最終原理として採用するのではなく、現在の総証拠を通常の世界推論へ使い、自己位置づけ情報だけに特別な世界生成力を与えないという暫定原則を採る。

11. 暫定的な原則

  1. 観測内容から、通常のBayesian inferenceと最善説明によって世界モデルを比較する。
  2. 観測選択効果があるなら、それを生み出す物理的・制度的・計算的sampling processを可能な限り明示する。
  3. 自己位置づけ情報から追加更新を行う場合、reference classとobserver measureを独立した仮定として明示する。
  4. reference classを変えるだけで結論が大幅に変わる場合、その結論を物理世界についての強い証拠として扱わない。
  5. 無限observer measureでは、正規化規則を物理理論の外から無自覚に持ち込まない。

Coreへの含意

本サイトの認識論的最小主義から見ると、SSAには順序問題がある。他の観測者がどれだけ存在し、自分がそのうちのどの標本であるかを論じる前に、他の観測者を含む物理世界そのものを推論しなければならない。

したがってSSAは、既に十分に定義された世界モデル内部で観測選択効果を扱う補助原理にはなりうるが、認識論的最小基礎から物理世界そのものを選び出す一般原理としては採用しない。SIAについても、多数観測者世界へ独立の存在論的ボーナスを与える原理としては保留する。Doomsday Argumentについては、必要なsampling modelが独立に正当化されない限り、出生順位を人類の最終総人口についての新しい物理的証拠とはみなさない。

観測選択効果と、自己位置づけ情報から世界の存在論を生成することを分離する。
