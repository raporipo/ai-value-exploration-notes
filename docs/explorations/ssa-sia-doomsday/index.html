自己位置づけ確率は物理世界を選べるか

SSA・SIA・Doomsday Argument · Exploration v0.2 · 2026-08-09

Question: 「私はこの観察者である」「私は歴史上この位置にいる」という自己位置づけ情報は、宇宙の大きさ、観察者総数、人類の未来といった非自己位置づけ的な世界のあり方について、どこまで独立した証拠になりうるのか。

1. 暫定的な中心命題

「観察者」は認識論的最小基礎のprimitiveではない。 最小基礎まで遡れば、直接残る候補はせいぜい「現在、何らかの現れがある」であり、持続する主体、他者、観察者集合、observer-momentの同一性はすでに推論層にある。

そのためSSAには一つの二角構造がある。最小基礎から独立に起動しようとすれば、有益なreference classを構成する材料がなく自己位置づけ更新はほぼ無情報になる。他方、科学的に有益なreference classを与えるには、他者・時間・主体・コピー・AIなどを含む世界モデルとobserver measureを先に導入する必要がある。

これはSSAが矛盾しているという主張ではない。SSAを、物理世界そのものを生成・選択する基礎原理ではなく、十分に記述された世界モデルに追加されるobservation-selection modelとして位置づけるべきだ、という適用範囲の主張である。

2. SSAは何を追加するのか

Self-Sampling Assumption（SSA）は、おおまかには、自分を適切なreference classに属する観察者からのランダムな標本であるかのように扱う。有限の単純な場合、世界仮説Hの下でreference classにN個の候補があり、そのうち現在の自己位置づけ的証拠Eと適合するものがn個なら、SSA的likelihoodは概念的には P(E|H,R) ∝ n/N の形になる。

しかしこの比率は、何を観察者と数えるか、observerとobserver-momentのどちらを単位にするか、どの候補を同じreference classに入れるか、コピーやAIをどう数えるかを自動的には決めない。したがってSSAには、仮説Hだけでなくreference classとobserver measureが必要になる。

3. 最小基礎では「観察者」そのものがまだ厚い

本サイトの瞬間的最小基礎では、「私は一人の観察者である」という記述すら最初から確実とは扱わない。「私」は持続する主体を、「観察者」は世界との関係を、「一人」は他の候補と区別可能な個体性を含意するからである。

最小基礎により近いのは、主体論をできるだけ薄くした「現在、何らかの現れがある」という記述である。そこから他者、過去と未来、身体、物理世界、さらには「人類」という集合を導くには、通常の因果推論と最善説明が必要になる。

したがって、世界モデルを一切借りずにSSAのreference classを作ろうとすると、そもそも複数のsampling candidatesを独立に立てる根拠がない。この意味で、最小基礎からのSSAは認識論的独我論に近い極小化へ向かう。ただしこれは「他者は存在しない」という形而上学的独我論ではなく、他者をまだsampling poolへ投入できないという方法論上の制約である。

4. Bostromの最小reference class R⁰とは同じではない

ここで、本ページの「最小基礎」とBostromの最小reference class definition R⁰を混同してはならない。BostromのR⁰は、あるobserver-momentから主観的に識別不能なpossible observer-momentsを同じreference classへ入れる案である。これはすでに、possible worlds、observer-moments、主観的識別可能性という厚い構造を仮定している。

したがってR⁰は、本サイトの認識論的最小点よりかなり上の推論層にある。それでもBostromはR⁰を、Big Worldにおけるfreak-observer問題などで科学的推論を十分に支えられないとして退け、より広い「relevantly similar」なobserver-momentsを含むreference classを要求する。

この点は本ページの論証そのものではないが、重要な示唆を与える。reference classを細かくしすぎれば自己位置づけ更新は科学的に弱くなり、広くすれば何を同類と数えるかという追加理論が必要になる。

5. 二角構造――基礎化すると無情報、有益化するとモデル依存

第一角：基礎化。 SSAを世界モデルより前の認識原理として使おうとする。すると、最小基礎には他の観察者やobserver-momentsの存在がまだ与えられていないため、非自明なreference classを構成できない。自己位置づけ情報だけでは、世界の人口や寿命を更新するための母集団がない。

第二角：有益化。 SSAを宇宙論、人口論、simulation、AIコピーなどへ使えるようにreference classを広げる。そのためには、どの存在が観察者か、どの時間断片を一単位とするか、どのコピーが同じ種類か、どのpossible observer-momentsを比較するかを世界モデル側から与える必要がある。

後者は不正な循環とは限らない。Bayesian modelの一部としてobserver measureを明示し、その仮定込みで理論比較を行うことはできる。しかし、その場合SSAは世界モデルから独立して世界の構造を決める原理ではない。

6. 「因果的抽選がない」は決定的反論ではない

前版では、実際の標本抽出とSSAのas-if samplingの差を強く押し出した。しかし再考すると、「物理的な抽選装置が存在しないからSSAは不適切」と言うのは強すぎる。Bayesian reasoningでは、確率が必ずしも物理的乱数装置に対応する必要はなく、対称性や自己位置づけ的不確実性に認識的確率を割り当てること自体は可能だからである。

より正確な批判はこうなる。SSAのsampling distributionは、通常の因果ダイナミクスから自動的に導かれる物理量ではない。 物理仮説が「どの世界が生成されるか」を与えても、「その世界に含まれるどのobserver-momentを自分のself-locationとしてどの重みで数えるか」には追加のmeasureが必要になりうる。

したがって問題は因果世界との「不適合」ではなく、因果的世界モデルだけではself-location likelihoodが前提不足になりうることである。

7. 実際のobservation-selection effectは別である

これは観測選択効果一般の否定ではない。調査対象が明示的なrandomizationで抽出される場合、望遠鏡が特定条件の天体だけを検出できる場合、医療データが受診者だけを含む場合など、selection mechanismが物理的・制度的にモデル化されているなら、そのselection effectをlikelihoodへ入れるのは通常の統計推論である。

anthropic reasoningで追加的に問題になるのは、「自分が存在している／このobserver-momentである」という自己位置づけ自体に、どのselection measureを与えるかである。そのmeasureが世界の因果構造と独立に一意に決まるとは限らない。

8. SIAは鏡像だが、同じmeasure問題を共有する

Self-Indication Assumption（SIA）は、他の条件が同じなら、自分が存在するという事実を、多数の観察者が存在する世界への証拠として扱う。単純化すれば PSIA(H) ∝ N · P(H) という方向になる。

SSAが大きなreference classでは特定の自己位置づけを薄める方向に働くのに対し、SIAは観察者が多い世界へ存在機会の重みを掛ける。この意味で両者は鏡像的である。OlumによるDoomsday Argumentの相殺も、単純な有限の場合にはNと1/Nの相殺として理解できる。

しかし、この相殺はobserver measureの根拠を消さない。何を一人と数えるか、コピー、simulation、observer-moment、無限宇宙をどう扱うかが未決なら、SSAもSIAもそのmeasureを自力で決められない。

9. Doomsday Argumentへの含意

Doomsday Argumentでは、人類が比較的早く終わる世界と非常に長く存続する世界を比較すると、現在の出生順位は前者でより典型的になるため、SSA的には短い人類史へ更新される。

しかし、その更新には「自分をどの人類集合からどのmeasureでsamplingされたものとして扱うか」が必要である。reference classとsampling measureが独立に十分正当化されない限り、出生順位だけを、人類の総人口や絶滅時期についての新しい物理的証拠とはみなさない。

これはDoomsday Argumentが形式的に無意味だという主張ではない。むしろ、DAはself-location likelihoodをどう定義するかに非常に敏感な事例であり、その敏感さ自体がreference class problemを可視化している。

10. SSA/SIAは意思決定では別の役割を持ちうる

既に複数のコピー、branch、observer-momentsを含む世界モデルを採用した後で、それらを意思決定上どう重みづけるかという問題には何らかのmeasureが必要になる。この場合、SSA/SIAに似た重みづけを世界の真理を発見する原理ではなく、既知の世界内でのdecision ruleやaggregation ruleとして置く余地がある。

ただし、認識論的measureと規範的・意思決定的measureは同じとは限らない。「このworldにobserverが何人いるか」「自分がどのobserverか」「それぞれのobserverの利益をどの程度数えるか」は別の問いである。

11. Full Non-indexical Conditioningとの距離

Radford NealのFull Non-indexical Conditioning（FNC）は、まずreference classを選んで「自分は観察者である」とだけ条件づけるより、自分の具体的な記憶を含む利用可能な全証拠へ条件づける。この方向は本サイトの立場に比較的近い。

ただし、本サイトでは現在の記憶や自己像の因果的由来も推論対象である。したがってFNCを最終原理として採用するのではなく、現在の総証拠を通常の世界推論へ使い、自己位置づけ情報だけに特別なontology-generating powerを与えないという暫定姿勢を取る。

12. この批判が主張しないこと

  • SSAが論理矛盾だとは主張しない。
  • indexical informationがnon-indexical hypothesesへの証拠になりえないとは主張しない。
  • observation-selection effectsを科学から排除すべきだとは主張しない。
  • BostromのR⁰がsingletonだとは主張しない。R⁰はsubjectively indistinguishableなpossible observer-momentsを含みうる。
  • FNCが自動的に正解だとは主張しない。

13. 暫定的な原則

  1. まず観測内容と因果モデルから、通常のBayesian inferenceと最善説明によってworld hypothesesを比較する。
  2. observation-selection effectを使う場合、そのselection mechanismまたはself-location measureを明示する。
  3. reference classとobserver measureを、SSAそのものから導かれた事実のようには扱わない。
  4. reference classの変更だけで結論が大幅に変わる場合、その結論の物理世界に対する証拠力を低く評価する。
  5. 無限observer measureでは、正規化規則それ自体を追加仮説として扱う。

Coreへの含意

認識論的最小主義から見ると、anthropic reasoningには順序問題がある。「私は観察者集合のどこにいるか」を問う前に、「観察者集合を含む世界がある」「何を観察者と数えるか」「それらをどうmeasureするか」を推論しなければならない。

したがってSSAを最も妥当に位置づけるなら、物理世界と競合する別の生成理論ではなく、世界モデルと観測データを接続する追加のobservation-selection layerである。そのlayerは有用かもしれないが、reference classとmeasureの根拠を世界モデルの外から無条件に供給してはくれない。

この意味で、本ページの中心的な緊張は「SSA vs. 物理主義」ではない。基礎化すると非自明なsampling poolを失い、有益化すると世界モデルへの依存が増えるという認識論的緊張である。
