自己位置づけ確率は物理世界を選べるか

SSA・SSSA・SIA・Doomsday Argument · Exploration v0.3 · 2026-08-09

Question: 自己位置づけ情報は、物理世界の非自己位置づけ的な仮説を更新しうるとしても、その更新に必要なreference classとobserver measureはどこから正当化されるのか。

1. まずBostrom自身の到達点を正確に置く

単純なSSAから直接Doomsday Argumentへ進むことを、Bostrom自身の最終的立場とみなすのは正確ではない。Anthropic Bias後半では、SSAは予備的定式化として再検討され、現在のobserver-momentを単位とするSSSA、observer-moment-relative reference classes、そしてObservation Equationへ進む。

同時にBostromは、SIAによってDoomsday Argumentを相殺する解決を採用していない。むしろSIAを拒否しつつ、単純なDoomsday Argumentはinconclusiveであり、実世界への適用には追加条件が必要だとする。

したがって本ページの論点は「Bostromはreference class problemを見落とした」という批判ではない。Bostrom自身がreference classの難しさをかなり深く認識した後にも残る、reference classの正当化問題である。

2. observer-momentと本サイトの「瞬間的最小基礎」は別物である

Bostromのobserver-momentは、observerの短い時間的断片である。そこではすでに、observerが存在すること、そのobserverが時間的に分割可能であること、possible worlds内に複数のobserver-momentsがあること、そしてそれらを比較・分類できることが前提になる。

これは本サイトの瞬間的最小基礎とは異なる。最小基礎では、「observer」「時間的断片」「他のpossible observer-moments」といった概念をまだprimitiveとして置かない。最も薄い候補は「現在、何らかの現れがある」である。

したがって、時間的に短いことと、認識論的に薄いことは同じではない。observer-momentは瞬間的でも、完全に推論層の概念である。

3. BostromのR⁰は、こちらの最小基礎ではない

Bostromは最小reference class候補R⁰として、現在のobserver-momentとsubjectively indistinguishableなpossible observer-momentsをまとめる案を検討する。これはsingletonとは限らないし、すでにpossible worlds、observer-moments、subjective indistinguishabilityという理論装置を含む。

さらにBostrom自身、R⁰ではBig Worldにおけるnormal observerとfreak observerの区別など、科学的推論に必要な情報が失われるため、これを退ける。より広い「relevantly similar」なobserver-momentsをreference classへ含める必要があるとする。

この点は重要である。「reference classを極小化すると科学的推論が弱くなる」という現象自体は、Bostromがすでに認識している。

4. 本ページの追加的問いは、その一段先にある

そこで残る問いは、R⁰より広いreference classを何が正当化するのか、である。

「人間」「同種の認知主体」「同じ情報処理能力を持つobserver-moments」「relevantly similarなsubjects」などの区分は、物理学、認知科学、主体論、因果モデル、進化史、simulation仮説などについての実質的な世界理解に依存する。

つまり、reference classを科学的に有益な程度まで豊かにするほど、そのreference classはすでに推論された世界モデルへ依存する。

これは直ちに循環論法ではない。Bayesian modelの一部としてreference classやobserver measureを明示し、その仮定込みで比較することは可能である。ただしその場合、SSSAは世界モデルから独立に世界を選ぶ基礎原理ではなく、世界モデルと観測を接続する追加のobservation-selection layerになる。

5. 最小基礎では「自己位置づけ問題」そのものがまだ成立していない

前版では「最小基礎まで縮めるとsingleton samplingになり無情報になる」と表現した。しかし、より厳密には一段手前で止めるべきである。

最小基礎には、そもそも「私はobserver集合のどこにいるか」という問いを立てるためのobserver集合がまだない。したがって、最小基礎からSSSAを直接起動するというより、SSSAは、他者・時間・主体・possible worldsを含む推論層が成立した後にのみ定義可能と考える方が正確である。

この意味で、本サイトの立場はanthropic reasoningを否定するのではなく、その認識論的階層を一段上へ置く。

6. 自己位置づけ情報はnon-indexical hypothesesを更新しうる

本ページは、「indexical informationはnon-indexical hypothesesへの証拠になりえない」とは主張しない。Bostromの理論の重要な狙いは、自己位置づけ情報が世界仮説を更新しうることを体系化する点にある。

問題は更新そのものではなく、どのself-location likelihoodを使うかである。そのlikelihoodは、observer-momentsの集合、reference class、measureを必要とする。したがって物理仮説Hだけでは足りず、しばしばHに加えてselection model Mが必要になる。

概念的には、更新対象を P(H | E) だけでなく P(H,M | E) と見る方が透明である。ここでMは、observer measureやreference class ruleを含む。

7. 「物理的抽選がない」ことは反論ではない

SSA/SSSAは、宇宙に実際の乱数装置があり「あなた」を抽選したと主張しているわけではない。自己位置づけ的不確実性に認識的確率を割り当てること自体は、物理的lotteryがなくても可能である。

したがって批判点は「因果世界と不適合」ではない。より正確には、通常の因果ダイナミクスだけではself-location likelihoodが一意に決まらない可能性があり、observer measureという追加構造が必要になる、である。

逆に、望遠鏡の検出限界、調査サンプル、医療データの受診者バイアスのようにselection mechanismが物理的・制度的に明示されている場合、そのselection effectをlikelihoodに入れることには特別なanthropic mysteryはない。

8. SIAは別解だが、Bostrom自身の解ではない

SIAは、他条件が同じなら観察者が多い世界ほど「自分が存在する機会」が多いとして重みづけする。単純化すれば PSIA(H) ∝ N · P(H) の方向になる。

Olumが示したように、単純な有限モデルではSIAのNとSSA的な1/Nが相殺し、Doomsday更新を消すことがある。しかしBostromはこの解法を採用しない。BostromとĆirkovićは、SIAを拒否しながらDoomsday Argumentも決定的ではないと論じる。

したがって、「BostromはSSSA+SIAでDAを捨てた」ではなく、SSSAとobserver-relative reference classesへ理論を作り替え、SIAは拒否しつつ、単純DAの普遍的妥当性を退けた、がより正確である。

9. Doomsday Argumentをどう位置づけるか

Doomsday Argumentは、self-location likelihoodの選び方が物理世界についての結論を大きく変える代表例である。出生順位を強い物理的証拠として扱うには、「自分をどのobserver populationのどのmeasureからsamplingされたものとして扱うか」という追加構造が必要になる。

その構造が十分に正当化されない限り、本サイトでは出生順位だけから人類の総人口や絶滅時期へ強く更新しない。

ただし、これはDAの形式が無意味だという意味ではない。むしろ、DAはreference classとobserver measureが結論へどれほど強く効くかを示すstress testである。

10. FNCはreference classを避ける一つの方向

Radford NealのFull Non-indexical Conditioning（FNC）は、先にreference classを選んで裸の「私はobserverである」に条件づけるより、自分の具体的な記憶を含む利用可能な全証拠へ条件づける。この点で、本サイトの「総証拠から通常の世界推論へ進む」という姿勢に近い。

ただしFNCも最終原理として自明ではない。現在の記憶や自己像の因果的由来自体が推論対象であり、無限世界・重複observer・measure問題などが消えるとは限らない。

11. 暫定的な階層整理

  1. 認識論的最小基礎：現在、何らかの現れがある。
  2. 通常の世界推論：外界、時間、他者、持続する主体、因果構造を最善説明として導く。
  3. 観察者モデル：何をobserverと数え、observer-momentへどう分割するかを定義する。
  4. observation-selection layer：reference class、observer measure、self-location likelihoodを置く。
  5. anthropic update：自己位置づけ情報をnon-indexical world hypothesesへ反映する。

この順序なら、anthropic reasoningを捨てずに、その前提を世界モデルの外へ隠さずに済む。

12. Coreへの含意

本ページの中心命題は、もはや「極小reference classなら無情報」という一点ではない。それはBostrom自身がR⁰の失敗としてかなり認識している。

より重要なのは、R⁰を捨ててより科学的に有益なreference classへ進むとき、その“relevant similarity”を何が正当化するのかという問いである。

本サイトの認識論的最小主義から見ると、その答えは最小基礎にはない。reference classは、物理世界・主体・時間・因果についての推論層の上に構成される。したがってSSSAは強力な補助理論になりうるが、物理世界を認識論的最小基礎から独立に選び出す原理ではない。

自己位置づけ確率を使う前に、何を自己位置づけの候補として数えているのか、その存在論的・認識論的由来を明示する。
