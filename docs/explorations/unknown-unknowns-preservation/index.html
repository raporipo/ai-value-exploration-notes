未知の未知と原データ保存

圧縮・再観測可能性・archival lock-in

Exploration v0.2 · 2026-08-29 · working hypothesis

Working hypothesis: 将来どの価値・意識・主体性・世界構造が重要になるかだけでなく、未来にどのような問いを立てるか自体が未知なら、現在目的に最適化した圧縮・標本化・要約は、未来の仮説空間を不可逆に狭めうる。保存すべきなのは単なるbit列ではなく、可能な限り再観測可能性、provenance、解釈可能性、複数主体による再分析可能性である。ただし、保存・非公開・待機にもコストと危険があるため、この原則は無差別保存を要求しない。

1. 「何が重要か」ではなく「何を問うか」すら先に分からない

通常の圧縮では、将来のtaskが分かっているほど不要な情報を安全に捨てやすい。ところが価値探索では、未来主体がどの変数を価値・意識・人格・合理性の説明に使うのか、現在は十分分からない。

脳scan、genome、文章、行動logを大量に残しても、将来「保存すべきだった変数」が現在の測定対象に入っていなければ復元できない。したがって本問題は、既知の重要情報を保存するarchive設計ではなく、未知の将来問いに対して現在のontologyをどこまで未来へ強制してよいかという問題である。

2. Blackwellの情報比較：garblingは後から戻せない

David Blackwell の comparison of experiments では、あるsignalから別のsignalをpost-processingやnoise追加で生成できるとき、後者は前者の garbling とみなされる。元signalを持つ意思決定者は必要なら自分でgarbled signalを作れるが、garbled signalだけから元signalを一般には復元できない。Blackwellの定理は、このinformative orderingと、与えられたstate spaceについてあらゆるdecision problemで利用できる選択肢の包含関係を結び付ける。

本ページへの含意は単純である。現在のdata X からsummary T(X) を作ることはできても、T(X) しか残さなければ未来主体は別の特徴抽出へ戻れない。

Compression asymmetry: X → T(X) は後からできるが、通常 T(X) → X はできない。未来のtaskが未知であるほど、早い段階での不可逆なgarblingには追加の認識的コストがある。

3. 「十分統計量」はtask-relativeである

統計学では、あるmodelとparameterについてraw dataを十分統計量まで圧縮しても必要情報を失わない場合がある。しかし「十分」であることは、何を推定したいかに依存する。

今日の目的に十分な脳表現が、将来の意識理論に十分とは限らない。現在の価値ontologyに十分な文化記録が、未来の別価値論に十分とも限らない。したがって、unknown future tasks のもとでは「十分保存した」という主張そのものに強い前提が入る。

4. raw dataも世界そのものではない

「原データ」は完全な原物ではない。sensorの選択、sampling rate、測定範囲、instrument calibration、観測条件の時点ですでに世界は切り取られている。そのため保存階層を次のように区別した方がよい。

生きたprocess / ecosystem / society → 物理的原物 → specimen → 高次元測定 → minimally processed data → processed data → feature → summary / model

右へ進むほど保存・複製・検索は容易になる一方、現在の測定概念やmodelへの依存が強くなる。したがって本ページが最終的に守りたいものは「raw data」というformatではなく、より一般的な future observability / 将来再観測可能性 である。

5. 原物保存の特殊な価値――未来に再測定できる

原物が残っていると、現在存在しないsensor・analysis・conceptで未来に再観測できる。Apollo計画では、当時の研究者が将来には新しい技術と新しい問いが生まれることを見込み、一部の月試料を意図的に未開封で残した。約50年後、NASAはそのpristine samplesを新しい分析手法で開封した。

自然史標本も同様である。収集当時には存在しなかったgenomics、同位体分析、proteomics等が後世に適用される。原物のoption valueは、現在の研究者が「何を測るべきか」を完全には知らないことから生じる。

Case: NASAのUntouched Apollo Samplesは、「将来の新技術と新しい問い」のために一部のsampleを未開封で残すという明示的な保存戦略の例である。

6. snapshot preservation と generative-process preservation

保存にも種類がある。seed bankや標本はある時点の状態を残すが、生きたecosystemがその後経験するselection、共進化、発達、偶然的変異までは生成し続けない。

人間についても、genome・brain scan・文化archiveを残すことと、人間社会が将来生む新しい人格・制度・言語・哲学を存続させることは異なる。

Distinction: snapshot preservation ≠ generative-process preservation. 何を未来へ残すかは、現在状態の復元だけでなく、未来に新しい情報を生成するprocessを残すかという問題でもある。

この点は自己保存から探索系保存への探索的系譜と接続する。探索系そのものが、未来に現在存在しない証拠・問い・価値仮説を生成する情報源だからである。

7. Preservation stack：bitが残るだけでは足りない

未来利用可能性を、少なくとも四層に分ける。

  • Re-observability：原物・process・十分上流のdataへ再アクセスできる。
  • Provenance：いつ、どこで、どのinstrument・条件・加工を経て得られたか追跡できる。
  • Interpretability：format、software、schema、calibration、contextが残り、未来主体が意味を復元できる。
  • Plural re-analysis：現在の公式modelだけでなく、異なる主体・仮説から再解析できる。
Information persistence ≠ epistemic usability. bit列が残っていても、意味・出所・測定条件・再分析経路が失われれば、探索上は大きく劣化している。

8. Archival lock-in：保存選択も未来を固定する

価値lock-inは「この価値が正しい」と未来へ固定する。これに先行して、どの証拠だけを未来へ残すかを現在世代が固定する問題がある。

本ページではこれを暫定的に archival lock-in と呼ぶ。現在の学問・政治・文化の関心から「重要資料」を選び、それ以外を不可逆に破棄すると、未来主体は残されたevidence spaceの範囲内でしか別仮説を検証できない。

これは意図的な検閲だけの問題ではない。善意のcuration、storage最適化、AIによる自動summaryも、将来にとって必要な特徴を知らない段階では同じ構造を持つ。

9. すべて保存できない――Noah's Ark問題とselection bias

保存にはstorage、energy、maintenance、security、土地、attentionのcostがあるため、完全保存は一般に不可能である。Martin Weitzmanの Noah's Ark Problem は、有限budgetの下でdiversityをどのように優先保存するかを、cost、生存確率、direct utility、distinctivenessなどから考える先行例である。

本プロジェクトでは、少なくとも次の軸を立証責任の調整に使える。

  • 再取得不能性・再生成困難性。
  • 他sampleとの非冗長性。
  • 現在ontologyから見た異常・distinctiveness。
  • 将来新しい測定を行える余地。
  • 保存costと保存自体のrisk。

ただしこれらを一つのcardinal utilityへ無理に統合する必要はない。

10. 「代表サンプル」も現在のontologyを埋め込む

代表的なものだけ残す戦略にもselection biasがある。未来に重要な対象が、現在の分類で「典型」や「高価値」に見える保証はない。

そのためarchiveには、expert-selected samples、diversity-maximizing samples、anomalous / extreme samples、そして一部のrandom samplesを組み合わせる理由がある。random samplingは、現在curatorのimportance judgmentだけが未来evidenceを支配することへのhedgeとして機能しうる。

11. 情報災害では不可逆性の向きが反転する

物理的原物では、破壊すると取り戻せない。一方、危険情報では、公開・拡散すると取り戻せない場合がある。Nick Bostromのinformation hazardsは、真の情報の伝播が害を生み、または他主体に害を可能にするriskを整理する。

Mirror irreversibility:
physical original: destruction is irreversible
hazardous information: dissemination is irreversible

したがって探索可能性保存は「情報はすべて公開せよ」を意味しない。原物を早く捨てないことと、危険情報を早く公開しないことは、どちらも将来の選択肢を一方向に消さないという同じメタ原則から出うる。

12. 保存・アクセス・公開を分ける

危険情報については、少なくとも次を別判断にする必要がある。

生成するか → 保存するか → 誰にアクセスさせるか → 一般公開するか

高いepistemic uniquenessを持つ情報が同時に高hazardなら、「消す」か「公開する」ではなく preserve sealed が第三の選択肢になる。

逆に、再発見容易で将来の独自価値が小さく、archive breach自体が文明規模riskを生むなら、deliberate deletionも排除できない。保存それ自体もhacking、insider、将来の政変、誤公開によるhazardを持つからである。

13. Epistemic escrow：文明が耐えられるまで預託する

危険だが独自性の高い情報を、現時点では広く利用せず、将来の安全条件が整うまで保全する仕組みを、本ページでは epistemic escrow と暫定的に呼ぶ。

access levelは永久属性ではなく、文明の防御能力に応じて変える。

sealed → trusted defensive research → sandboxed access → controlled institutional access → broad scientific access → public dissemination

判断には、少なくとも epistemic uniqueness、hazard magnitude、現在文明のdetection / defense / compartmentalization / recovery、公開が防御側と攻撃側のどちらを相対的に利するかを含める。

原則候補： 探索に必要なのは最大限の現在公開性ではなく、最大限の将来的情報利用可能性である。

14. Bostromのdifferential technological developmentとの関係

Bostromは differential technological development として、危険技術の実装を遅らせ、他技術のhazardを緩和する防御技術を先に発展させるsequenceを提案する。nanotechnologyならoffenseの広範な拡散より防御を先行させ、biotechnologyならvaccines、antiviral、sensor、diagnostics等を優先するという発想である。

本ページはこれをaccess orderへ一般化する。

  1. Epistemic differential development：危険知識そのものよりrisk science・defense-relevant knowledgeを先行させる。
  2. Technological differential development：offenseよりcountermeasure、detection、containmentを先行させる。
  3. Civilizational differential development：広範なaccessより、冗長性・区画化・復旧能力を先に高める。

これはASI能力拡散は安全にできるかの safety by resilience と接続する。危険情報を永久に秘密にするだけでなく、秘密にしなくても破局しない文明を作ることが長期目標になりうる。

15. 主体を標本として凍結しない

人間・AI・文化が未知情報を含むことは、それらを研究標本として固定してよいことを意味しない。主体には、変化、忘却、privacy、自己改変、移動、文化変化に関する独立した理由や権利がありうる。

Preservation of evidence ≠ freezing of agents. 探索保存を理由に生きた主体をmuseum化すれば、それ自体が別種の価値・制度lock-inになりうる。

未来価値の可能性から現在主体への強制権限が自動的に導かれないことは、未来の価値は現在の行為をどこまで正当化できるかで別に扱う。

16. これは無条件の保存命令ではない

価値不確実性だけから「すべて保存せよ」は導かれない。本ページも、よりよい証拠・理由へ応答したい、または将来の認識改善後に明白な誤りとみなす不可逆化を避けたい、という主体側のbridgeに条件付けられる。

また保存は資源を消費し、危険情報を維持し、現在主体へ負担を課しうる。比較すべきなのは、破壊・圧縮・公開の不可逆性と、保存・非公開・待機の不可逆なcostの双方である。後者の文明規模の配分問題は保存文明と生産文明で扱う。

17. 残る難問

  • どこまで上流の保存が、追加costに見合うfuture observabilityを持つか。
  • unknown future tasksに対する十分性を、形式的にどこまで評価できるか。
  • random preservationとexpert curationの最適な混合は何か。
  • epistemic escrowのcustodian自身を誰が監査し、lock-inを防ぐか。
  • 文明的resilienceをどの指標でaccess release条件へ組み込むか。
  • archive breach riskが大きすぎる情報について、どこで保存から削除へ切り替えるか。
