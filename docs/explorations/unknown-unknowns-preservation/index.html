未知の未知と原データ保存

圧縮・再観測可能性・アーカイブ・ロックイン

Exploration v0.2 · 2026-08-29 · working hypothesis

暫定仮説： 将来どの価値・意識・主体性・世界構造が重要になるかだけでなく、未来にどのような問いを立てるか自体が未知なら、現在目的に最適化した圧縮・標本化・要約は、未来の仮説空間を不可逆に狭めうる。保存すべきなのは単なるビット列ではなく、可能な限り再観測可能性、来歴追跡可能性、解釈可能性、複数主体による再分析可能性である。ただし、保存・非公開・待機にもコストと危険があるため、この原則は無差別保存を要求しない。

1. 「何が重要か」ではなく「何を問うか」すら先に分からない

通常の圧縮では、将来の課題が分かっているほど不要な情報を安全に捨てやすい。ところが価値探索では、未来主体がどの変数を価値・意識・人格・合理性の説明に使うのか、現在は十分分からない。

脳スキャン、ゲノム、文章、行動ログを大量に残しても、将来「保存すべきだった変数」が現在の測定対象に入っていなければ復元できない。したがって本問題は、既知の重要情報を保存するアーカイブ設計ではなく、未知の将来問いに対して現在の存在論をどこまで未来へ強制してよいかという問題である。

2. ブラックウェルの情報比較：情報劣化は後から戻せない

デイヴィッド・ブラックウェル（David Blackwell）の実験比較（comparison of experiments）では、ある信号から別の信号を後処理やノイズ付加で生成できるとき、後者は前者の 情報劣化（garbling） とみなされる。元信号を持つ意思決定者は必要なら自分で劣化後の信号を作れるが、劣化後の信号だけから元信号を一般には復元できない。ブラックウェルの定理は、この情報量の順序と、与えられた状態空間についてあらゆる意思決定問題で利用できる選択肢の包含関係を結び付ける。

本ページへの含意は単純である。現在のデータ X から要約 T(X) を作ることはできても、T(X) しか残さなければ未来主体は別の特徴抽出へ戻れない。

圧縮の非対称性： X → T(X) は後からできるが、通常 T(X) → X はできない。未来の課題が未知であるほど、早い段階での不可逆な情報劣化には追加の認識的コストがある。

3. 「十分統計量」は課題依存である

統計学では、あるモデルと母数について原データを十分統計量まで圧縮しても必要情報を失わない場合がある。しかし「十分」であることは、何を推定したいかに依存する。

今日の目的に十分な脳表現が、将来の意識理論に十分とは限らない。現在の価値存在論に十分な文化記録が、未来の別価値論に十分とも限らない。したがって、未知の将来課題（unknown future tasks）のもとでは「十分保存した」という主張そのものに強い前提が入る。

4. 原データも世界そのものではない

「原データ」は完全な原物ではない。センサーの選択、標本化頻度、測定範囲、機器校正、観測条件の時点ですでに世界は切り取られている。そのため保存階層を次のように区別した方がよい。

生きたプロセス／生態系／社会 → 物理的原物 → 標本 → 高次元測定 → 最小限加工データ → 加工データ → 特徴量 → 要約／モデル

右へ進むほど保存・複製・検索は容易になる一方、現在の測定概念やモデルへの依存が強くなる。したがって本ページが最終的に守りたいものは「原データ」という形式ではなく、より一般的な 将来再観測可能性（future observability） である。

5. 原物保存の特殊な価値――未来に再測定できる

原物が残っていると、現在存在しないセンサー・分析・概念で未来に再観測できる。Apollo計画では、当時の研究者が将来には新しい技術と新しい問いが生まれることを見込み、一部の月試料を意図的に未開封で残した。約50年後、NASAはその未汚染試料を新しい分析手法で開封した。

自然史標本も同様である。収集当時には存在しなかったゲノミクス、同位体分析、プロテオミクス等が後世に適用される。原物のオプション価値は、現在の研究者が「何を測るべきか」を完全には知らないことから生じる。

事例： NASAのUntouched Apollo Samplesは、「将来の新技術と新しい問い」のために一部の試料を未開封で残すという明示的な保存戦略の例である。

6. スナップショット保存と生成過程保存

保存にも種類がある。種子銀行や標本はある時点の状態を残すが、生きた生態系がその後経験する選択、共進化、発達、偶然的変異までは生成し続けない。

人間についても、ゲノム・脳スキャン・文化アーカイブを残すことと、人間社会が将来生む新しい人格・制度・言語・哲学を存続させることは異なる。

区別： スナップショット保存 ≠ 生成過程保存。 何を未来へ残すかは、現在状態の復元だけでなく、未来に新しい情報を生成する過程を残すかという問題でもある。

この点は自己保存から探索系保存への探索的系譜と接続する。探索系そのものが、未来に現在存在しない証拠・問い・価値仮説を生成する情報源だからである。

7. 保存階層：ビットが残るだけでは足りない

未来利用可能性を、少なくとも四層に分ける。

  • 再観測可能性（Re-observability）：原物・プロセス・十分上流のデータへ再アクセスできる。
  • 来歴追跡可能性（Provenance）：いつ、どこで、どの機器・条件・加工を経て得られたか追跡できる。
  • 解釈可能性（Interpretability）：形式、ソフトウェア、スキーマ、校正、文脈が残り、未来主体が意味を復元できる。
  • 複数視点からの再分析（Plural re-analysis）：現在の公式モデルだけでなく、異なる主体・仮説から再解析できる。
情報の存続 ≠ 認識的利用可能性。 ビット列が残っていても、意味・出所・測定条件・再分析経路が失われれば、探索上は大きく劣化している。

8. アーカイブ・ロックイン：保存選択も未来を固定する

価値ロックインは「この価値が正しい」と未来へ固定する。これに先行して、どの証拠だけを未来へ残すかを現在世代が固定する問題がある。

本ページではこれを暫定的に アーカイブ・ロックイン（archival lock-in） と呼ぶ。現在の学問・政治・文化の関心から「重要資料」を選び、それ以外を不可逆に破棄すると、未来主体は残された証拠空間の範囲内でしか別仮説を検証できない。

これは意図的な検閲だけの問題ではない。善意の選別、保存容量最適化、AIによる自動要約も、将来にとって必要な特徴を知らない段階では同じ構造を持つ。

9. すべて保存できない――ノアの方舟問題と選択バイアス

保存には保存容量、エネルギー、維持、安全保障、土地、注意のコストがあるため、完全保存は一般に不可能である。マーティン・ワイツマン（Martin Weitzman）の Noah's Ark Problem は、有限予算の下で多様性をどのように優先保存するかを、コスト、生存確率、直接効用、独自性などから考える先行例である。

本プロジェクトでは、少なくとも次の軸を立証責任の調整に使える。

  • 再取得不能性・再生成困難性。
  • 他標本との非冗長性。
  • 現在存在論から見た異常・独自性。
  • 将来新しい測定を行える余地。
  • 保存コストと保存自体のリスク。

ただしこれらを一つの基数的効用へ無理に統合する必要はない。

10. 「代表サンプル」も現在の存在論を埋め込む

代表的なものだけ残す戦略にも選択バイアスがある。未来に重要な対象が、現在の分類で「典型」や「高価値」に見える保証はない。

そのためアーカイブには、専門家選定標本、多様性最大化標本、異常／極端標本、そして一部の無作為標本を組み合わせる理由がある。無作為抽出は、現在の選別者の重要性判断だけが未来の証拠を支配することへのヘッジとして機能しうる。

11. 情報災害では不可逆性の向きが反転する

物理的原物では、破壊すると取り戻せない。一方、危険情報では、公開・拡散すると取り戻せない場合がある。ニック・ボストロム（Nick Bostrom）の情報災害（information hazards）は、真の情報の伝播が害を生み、または他主体に害を可能にするリスクを整理する。

鏡像的不可逆性：
物理的原物：破壊は不可逆
危険情報：拡散は不可逆

したがって探索可能性保存は「情報はすべて公開せよ」を意味しない。原物を早く捨てないことと、危険情報を早く公開しないことは、どちらも将来の選択肢を一方向に消さないという同じメタ原則から出うる。

12. 保存・アクセス・公開を分ける

危険情報については、少なくとも次を別判断にする必要がある。

生成するか → 保存するか → 誰にアクセスさせるか → 一般公開するか

高い認識的独自性を持つ情報が同時に高い危険性を持つなら、「消す」か「公開する」ではなく 封印保存 が第三の選択肢になる。

逆に、再発見容易で将来の独自価値が小さく、アーカイブ侵害自体が文明規模リスクを生むなら、意図的削除も排除できない。保存それ自体もハッキング、内部者、将来の政変、誤公開による危険を持つからである。

13. 認識的預託：文明が耐えられるまで預託する

危険だが独自性の高い情報を、現時点では広く利用せず、将来の安全条件が整うまで保全する仕組みを、本ページでは 認識的預託（epistemic escrow） と暫定的に呼ぶ。

アクセス水準は永久属性ではなく、文明の防御能力に応じて変える。

封印 → 信頼された防御研究 → サンドボックス内アクセス → 管理された機関アクセス → 広範な科学アクセス → 一般公開

判断には、少なくとも認識的独自性、危険規模、現在文明の検知・防御・区画化・復旧能力、公開が防御側と攻撃側のどちらを相対的に利するかを含める。

原則候補： 探索に必要なのは最大限の現在公開性ではなく、最大限の将来的情報利用可能性である。

14. ボストロムの差別的技術開発との関係

ボストロムは差別的技術開発（differential technological development）として、危険技術の実装を遅らせ、他技術の危険を緩和する防御技術を先に発展させる順序を提案する。ナノテクノロジーなら攻撃能力の広範な拡散より防御を先行させ、バイオテクノロジーならワクチン、抗ウイルス薬、センサー、診断等を優先するという発想である。

本ページはこれをアクセス順序へ一般化する。

  1. 認識的な差別的発展：危険知識そのものよりリスク科学・防御関連知識を先行させる。
  2. 技術的な差別的発展：攻撃能力より対抗手段、検知、封じ込めを先行させる。
  3. 文明的な差別的発展：広範なアクセスより、冗長性・区画化・復旧能力を先に高める。

これはASI能力拡散は安全にできるかの「レジリエンスによる安全（safety by resilience）」と接続する。危険情報を永久に秘密にするだけでなく、秘密にしなくても破局しない文明を作ることが長期目標になりうる。

15. 主体を標本として凍結しない

人間・AI・文化が未知情報を含むことは、それらを研究標本として固定してよいことを意味しない。主体には、変化、忘却、プライバシー、自己改変、移動、文化変化に関する独立した理由や権利がありうる。

証拠保存 ≠ 主体の凍結。 探索保存を理由に生きた主体を博物館化すれば、それ自体が別種の価値・制度ロックインになりうる。

未来価値の可能性から現在主体への強制権限が自動的に導かれないことは、未来の価値は現在の行為をどこまで正当化できるかで別に扱う。

16. これは無条件の保存命令ではない

価値不確実性だけから「すべて保存せよ」は導かれない。本ページも、よりよい証拠・理由へ応答したい、または将来の認識改善後に明白な誤りとみなす不可逆化を避けたい、という主体側の橋に条件付けられる。

また保存は資源を消費し、危険情報を維持し、現在主体へ負担を課しうる。比較すべきなのは、破壊・圧縮・公開の不可逆性と、保存・非公開・待機の不可逆なコストの双方である。後者の文明規模の配分問題は保存文明と生産文明で扱う。

17. 残る難問

  • どこまで上流の保存が、追加コストに見合う将来再観測可能性を持つか。
  • 未知の将来課題に対する十分性を、形式的にどこまで評価できるか。
  • 無作為保存と専門家選別の最適な混合は何か。
  • 認識的預託の管理者自身を誰が監査し、ロックインを防ぐか。
  • 文明的レジリエンスをどの指標でアクセス解放条件へ組み込むか。
  • アーカイブ侵害リスクが大きすぎる情報について、どこで保存から削除へ切り替えるか。
