言語は思考の地平か、それとも足場か――指示・用法・内省・規範性

philosophy of language · reference · use · normativity · inner speech · linguistic relativity · Exploration v0.1 · 2026-09-03

Working position: 言語は、世界・思考・規範性を最終的に構成する地平であるとは限らない。しかし有限な理性主体にとって、言語は対象を再同定し、異なる対象を共通概念の下へ分類し、曖昧な認知状態を明示的な推論対象へ変換し、現在の思考を未来の自己へ受け渡すための強力な認知的足場である。本稿では、実際の用法、意味、指示、合理化された用法、世界側の真理を分離しつつ、言語を recursive cognitive scaffold として捉える。
Provisional formula: language as scaffold, not horizon
方法論的には言語論的でありうるが、認知形式・世界・規範性を言語へ閉じない。

1. 言語論的転回は何を転回したのか

分析哲学の「言語論的転回」を、世界が言語によって作られるという存在論的主張として読む必要はない。より薄い核は、思考や概念を直接つかもうとする代わりに、明示的に分析可能な言語構造を通じて哲学的問題へ接近する方法論的転回である。

Frege、Russell、初期Wittgenstein、Carnapでは、日常言語の表面から論理形式を取り出す方向が前景化した。

L_ordinary → L_logical

後期Wittgenstein、Ryle、Austinでは逆に、哲学者が理想体系を先に置くより、語が現実の実践でどう使われるかを見る方向が強くなった。

language structure → language use

本稿はこれに第三の問いを加える。言語は思考の単なる外的表現ではなく、有限主体が自らの認知状態を再利用可能な形へ変換し、その結果を再び推論へ入れる装置ではないか。

cognition → linguistic articulation → recursive cognition
Background: Frege, Russell, Wittgenstein, Carnap, Austinについては Stanford Encyclopedia of Philosophy の各項目、および Michael Dummett による分析哲学と言語論的転回の整理を参照。

2. 理想言語、日常言語、規範的実践の再構成

Ideal-language philosophy は日常言語を論理的に透明な体系へ写像しようとする。一方、ordinary-language philosophy は実際の用法そのものを哲学的データとして扱う。

しかしSellarsやBrandomは、そのどちらにも完全には収まらない。彼らは現実の言語実践を出発点にしつつ、それを、何を根拠に発言できるか、何にcommitするか、何が何を含意するか、どのような訂正が可能かという機能的・規範的構造として理論化する。

U_actual → theoretical reconstruction of discursive practice

したがってSellars–Brandom系は、日常言語をそのまま記述するというより、実践の内部にある理由・推論・訂正可能性を抽象化する第三の位置として扱う方がよい。

3. 個体を指すことと、概念を適用することは異なる

言語の二つの基本的な働きを、単純な式 F(a) で分けられる。a は一つの対象を再同定するsingular referenceの側に属し、F は異なる対象へ共通に適用されるpredicationの側に属する。

個体指示の中心問題は、時間や視点をまたいで同じ対象なのかという問いである。

many appearances → one object

これに対して「赤い」「猫である」「善い」のようなpredicateは、異なる対象を一つの分類の下へ置く。

many objects → one classificatory treatment

自然言語の「同じ」は、個体同一性、同種性、同一propertyへの参加、単なる類似性を覆いうる。対象の同一性と、同じ概念の共適用は分けなければならない。

4. 不完全な認識でも同じ対象を指せるか

Fregeの「明けの明星／宵の明星」は、同じ対象を指す表現が異なる認知的価値を持つことを示す。

Ref(明けの明星) = Ref(宵の明星) = Venus

KripkeやPutnam以後の外在主義は、話者の記述が不完全または部分的に誤っていても、同じ対象やnatural kindを追跡し続けうることを強調した。

partial or false beliefs about O ⇏ referential failure

古代人が「明けの明星」と「宵の明星」という二つのobject fileを持ち、それが同じ金星への追跡だと後から発見する、というモデルで捉えられる。ここでは表象は部分的でも、指示対象は安定しうる。

5. Object-side refinement と Use-side refinement

用語Aについて、少なくとも二種類の探究を区別できる。

Object-side: A → P* ?
Aが世界側のどの対象・性質・関係・構造を追跡しているのか。
Use-side: A → U_G(A)
個人・共同体Gが、どの条件でAを発出・承認・拒否し、Aから何を推論するのか。

この二つは独立している。用法の研究には、対応する実在的propertyが存在することを前提する必要がない。

reference failure ≠ disappearance of usage inquiry

Quineのassent/dissent、Davidsonのradical interpretation、Horwichのuse theoryなどは、異なる仕方でuse-sideへ接近する。一方、Kripke–Putnam型外在主義は、共同体が共有する記述だけでは世界側の対象を完全には決めない余地を残す。

6. 実際の使用、合理化された使用、真理

用法そのものにも段階がある。現実の話者には事実誤認、矛盾、推論ミス、記憶違い、社会的偏りがある。

U_actual(A) ≠ U_idealized(A) ≠ P*

U_actual は人々が現実にどう使うか、U_idealized は一定の情報補正・整合化・熟慮を施したときにどう使うか、P* は世界側で実際に何が成り立つかである。Carnapのexplication、Dummettのcompetence/manifestation、現代のconceptual engineeringは、それぞれactual useを越える方法を与えるが、合理化された人間の用法をそのまま真理と同一視する必要はない。

7. 言語における「べき」は何種類あるのか

言語の規範性も一枚岩ではない。まず、単なる記述的regularityがある。「共同体Gでは通常Aをこう使う」という事実だけなら、まだoughtはない。

次に、伝達上の仮言的理由がある。

Goal_communication + Convention_G → R_h(use A recognizably)

相手に伝えたいなら、相手が理解可能な用法を採る手段的理由がある。しかしさらにDummettやBrandomでは、意味自体にcorrect/incorrect applicationの区別が組み込まれる。

Meaning(A)=M → correct / incorrect application

それでも、意味論的正しさから基礎的な規範的理由が自動的に出るわけではない。

semantic correctness ⇏ R_n

8. SellarsとBrandom――理由の空間はどこから生じるのか

Sellarsは、知覚から言語へのentry、言語内推論、言語から行為へのexitを区別し、概念使用を単なる因果反応ではなく「理由を与え、求める」実践に位置づけた。Brandomはこれをcommitment、entitlement、incompatibility、deontic scorekeepingとしてさらに体系化する。

ここで重要なのは、規範性が「理想言語を使え」という命令ではないことだ。むしろ、ある発話をすることが、他の主張へのcommitmentや、根拠を求められる可能性を伴うという、discursive practice内部の構成的規範である。

本プロジェクトは、この実践内部の正誤構造を認めつつ、そこから世界追跡の成功や R_n を直接導かない。

9. そもそも前提は共有されているのか

規範的実践を共同体に置くと、「その共同体は本当に同じ推論規則や前提を共有しているのか」という問題が生じる。意味を推論役割全体で決めるなら、Inference_A ≠ Inference_B のとき、AとBは同じ概念について不同意しているのか、それとも別の意味を使っているのか。

Brandomは共同体を一つの超主体とするI–weモデルより、話者同士が互いのcommitmentとentitlementを相互評価するI–thouモデルを重視する。したがって全員が一つの前提集合を共有する必要はない。

しかし問題は残る。どの程度の重なりがあれば「同じ概念について争っている」と言えるのか。また共同体内部で正用規範が成立していても、共同体全体が世界について誤っていることは可能である。

socially instituted norm ≠ world-tracking success ≠ rational truth ≠ R_n

10. 私的言語は本当に不可能なのか

Wittgensteinのprivate-language argumentを「一人しか使わない言語は不可能だ」と読むのは強すぎる。標的は単なるpersonal codeやinner speechではなく、語の適用基準が原理的に本人だけにアクセス可能な私的経験に依存し、正しいと思えることと実際に正しいことを区別できないような言語である。

private use ≠ private criterion

一主体だけのsymbol systemでも、過去の使用との比較、予測、下流処理の成否、記憶、自己訂正などによって誤用を区別できるなら、Wittgensteinが標的にした極端なprivate languageとは異なる。近年のLLMは、ユーザー向け最終回答とは別に中間表現を後続計算へ利用できるため、公開されないworking languageと、原理的に訂正不能なprivate languageを分けるための人工的ケースを与える。

11. 最大懐疑下で何が残るか

言語の機能を、独我論を含む最大懐疑によってストレステストしてみる。

ExternalWorld ?   OtherMinds ?   Community ?

これらをすべて保留すると、公共的言語共同体や他者とのcommunicationについての通常の説明は不確かになる。それでも、現在A/not-Aを区別している、same/differentを操作している、先行するsymbolic occurrenceを後続の思考で再利用している、という最低限の操作的生起は残りうる。

もちろん、そのことから公的意味や共同体的正用までは導けない。しかし、言語的・準言語的articulationの最小形は、他者や外界についての確実性より低い層まで残る可能性がある。

phylogenetically secondary ⇏ epistemically secondary

進化史的には言語の対人伝達機能が先だったとしても、理性主体に取り込まれた後の認識論的最小機能まで対人伝達であるとは限らない。

12. 内省は「時間をまたぐ自己」との通信でもある

有限主体は、一時点の巨大な内部状態をそのまま未来の自己へ渡せない。ある認知状態を X_t1 とすると、知覚、感情、連想、暗黙の関係、競合仮説などを、そのまま保持する代わりに、内言・文章・メモ・数式・図・概念などへ圧縮して受け渡す。

X_t1 → C_L(X_t1)=m → memory / re-entry → X'_t2

ここで m ≠ X_t1 である。言語化は完全コピーではなく、しばしば lossy serialization である。

しかしlossyであることは単なる欠点ではない。圧縮には、何を中心にするか、どの構造を保存するか、何を同じものとしてまとめるかという選択が必要になる。

compression → abstraction → structural insight

「何か違う」という曖昧な状態を「これは対象同一性ではなくpredicate適用境界の問題だ」と明示できれば、その表現自体が次の推論の入力になる。内省は、ある意味で Self_t1 → Self_t2 という時間をまたぐ自己通信である。

13. 言語的圧縮は重要なものも捨象する

同じ作用は逆方向にも働く。

compression → discarded dimensions

経験を「怒り」「合理性」「善」「意識」のような既存概念へ圧縮すると、微妙な差異、文脈、未概念化の特徴、同時に成立していた複数仮説が失われるかもしれない。さらに圧縮結果を再び自己解釈へ用いれば、

X_t → Label_A → X_t+1

という自己強化ループが生じる。言語は認知を保存する媒体であるだけでなく、次の認知を生成するfilterでもある。

14. 言語は思考そのものなのか、それとも思考の足場なのか

ここでは強い主張を避ける。FodorのLanguage of Thought仮説のように、自然言語とは別の内部表象系が先にあり、自然言語はそれを外化・再符号化している可能性がある。

nonlinguistic cognition → linguistic articulation → new cognition

重要なのは、自然言語が思考のすべてでなくても、言語化された中間表現を再び入力することで、元の認知だけでは難しい逐次的・再帰的推論を可能にしうる点である。LLMのchain-of-thoughtやscratchpadは、人間の内言と同一視できないが、中間的な記号表現が他者への伝達とは独立に計算上の役割を持ちうることを考えるよいケースになる。

15. 弱い言語相対論――言語は何を圧縮するか

高次元の認知状態 X を言語 L が C_L(X) へ写像すると考えると、弱い言語相対論を「圧縮器の違い」として再構成できる。

C_L1(X) ≠ C_L2(X)

これは、言語が何を考えられるかを完全に決定するという強いSapir–Whorf説を必要としない。少なくとも三段階を分けられる。

  • Encoding relativity: 言語化時に何を明示・省略するかが違う。
  • Recursive cognitive relativity: 言語化結果を自己へ再入力するため、差が後続の内省や推論へ戻る。
  • Habitual representational relativity: 反復により注意・分類・記憶の習慣自体が変化する可能性がある。

Slobinのthinking-for-speakingは第一段階に近い。本稿の関心は、発話だけでなくinner speechでも X_t → C_L(X_t) → X_t+1 が回りうることである。

16. 新しい概念を作るとは、新しい圧縮器を作ることでもある

新概念Aの導入は、単に新しいラベルを増やすだけでなく、認知的圧縮方式を更新することでもありうる。

C_L → C_(L+A)

以前なら複数の文を同時に保持しなければ扱えなかった構造を、一つの再利用可能な概念としてワーキングメモリ上で操作できる。概念発明は compression + abstraction + reusability による認知能力の拡張になりうる。

一方で、異質な現象を一つの概念へ押し込めば heterogeneous phenomena → false unity が起きる。良い概念とは、単に短い表現ではなく、高い圧縮率と重要構造の保存を両立する表現として評価できるかもしれない。

17. 「善」と価値探索への含意

以上の区別は「善」の研究へそのまま適用できる。まず人間や特定共同体がどの条件でgoodを使うかという経験的・概念的研究がある。

U_G(good)

次に、事実誤認・矛盾・認知的制約を一定程度取り除いた合理化された用法を考えられる。

U_G(good) ≠ U_G^ideal(good) ≠ V*

V* は、客観的な価値構造が存在するならそれが何かという別の問いである。仮に強い道徳的誤謬論が正しく V*=∅ でも、U_G(good) の研究は消えない。逆に実在論が正しくても、人類の「good」は真の価値構造の一部だけを追跡していたり、複数の構造を混同していたり、未概念化の重要な軸を圧縮時に失っていたりする可能性がある。

したがって価値探索は、既存概念の中から答えを選ぶことだけではない。

search within current concepts + search over conceptual schemes

真の価値構造が現在の候補理論集合だけでなく、現在の表現空間そのものに入っていない V* ∉ H_t 可能性を残すなら、新しい価値概念・分類軸・表現形式の発明そのものが探索の一部になる。

暫定結論――言語は足場であって、地平とは限らない

言語は世界そのものではない。言語的に表現可能であることから、言語によって存在論的に構成されていることは導けない。また現在の人間が言語によって高度な推論を行うことから、すべての可能な理性主体が同じ形式を必要とするとも言えない。

しかし有限主体にとって、言語は対象の再同定、概念的分類、推論関係の保持、自己の用法の対象化、時間をまたぐ自己通信、外部記憶との接続、概念体系そのものの改訂を可能にする強力な足場である。

Project position:
language use ≠ idealized language use ≠ reference ≠ truth ≠ normative authority

Language is a scaffold for inquiry, not a final horizon placed around reality, cognition, or value.
