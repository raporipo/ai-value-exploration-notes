ベイズ更新と開いた仮説空間――未概念化仮説はどのように更新へ入るのか

Exploration v0.1 · 2026-08-11

Question: ベイズ更新は、まだ仮説空間に入っていない仮説を扱えるのか。現在の候補集合の中で極めて高いposteriorを得ることと、その候補集合自体を十分にexhaustiveだとみなすことは、同じ認識的主張なのか。

1. 問題は「Bayesか反Bayesか」ではない

通常のBayesian conditionalizationは、すでに与えられた仮説空間の中で、証拠を受け取ったときにcredenceをどう動かすかを与える。これは非常に強力であり、本プロジェクトもこの局所的な更新規則を否定しない。

しかし、科学史・価値探究・高度AIの自己改訂で起こりうる変化は、既存候補の重み変更だけではない。新しい仮説、新しい観測変数、新しい主体カテゴリー、あるいは旧理論の意味まで変える新しい概念が導入され、何に確率を置くかという空間そのものが変わることがある。

Working distinction:
Within-space updating: 現在の仮説空間の内部でcredenceを更新する。
Hypothesis-space revision: 仮説空間を追加・細分化・再構成し、その上で新しい確率表現を作る。

2. 未概念化仮説は「prior 0」ではない

ここはopen-world value uncertaintyの表現を一段厳密化する。ある仮説 H* が現在の事象空間にまだ含まれていないなら、通常は P(H*) = 0 と言うべきではない。P(H*) 自体が現在の確率関数では未定義だからである。

zero prior問題は別に存在する。すでに空間内にある仮説へ確率0を与えれば、通常の条件付けだけでは後から正の確率へ復活できない。しかしunconceived hypothesis問題では、仮説は「0で登録済み」なのではなく、まだ登録される表現を持っていない。

したがって、本プロジェクトが避けたいのは「未知理論へ小さな正のpriorを必ず割り当てよ」という単純な原則ではない。むしろ、現在の確率空間を、それだけで世界の可能性を尽くすものと暗黙に同一視しないという制約である。

3. 二種類の更新として整理する

時点 t の主体が、概念言語 Lt、仮説空間 Ht、その上のcredence Pt を持つとする。通常のBayes更新を B と呼べば、Bは概念的には「Ht を固定したまま、証拠 E によって Pt を更新する」操作である。

これとは別に、仮説空間の拡張操作を X と呼ぶ。Xは、新しい概念や仮説を導入して Lt と Ht 自体を変える。実際の長期的探究は、単なるBの反復ではなく、概念的には X → B → X → B → … と進む場合がある。

この整理ではBayesianismとvalue explorationは競合しない。Bayesは「いま考えられる仮説をどう比較するか」を扱い、value explorationは「何を仮説として考えられる状態を残すか」を扱う。

4. 先行理論1：new theory problem と open-minded Bayesianism

Bayesian confirmation theoryでは、新理論が後から導入されるときの確率付与は以前から問題になっている。Wenmackers and Romeijnのopen-minded Bayesianismは、「現在検討中の仮説のどれかが正しい」という暗黙の前提を緩め、現在の候補外を表すcatch-all hypothesisを置く。新理論が登場すると、旧catch-allを「新理論」と「新しいcatch-all」へ分解する。

これはopen-worldな発想にかなり近い。ただしcatch-allは魔法の箱ではない。「その他すべて」は互いに大きく異なる仮説を含みうるため、証拠のlikelihoodを一つの精密な数に圧縮すること自体が難しい。そのため同研究はcatch-allをsets of probability assignmentsで特徴づけ、Bayes ruleとは別のnew-theory updateを導入する。

重要な含意は、現在の明示的候補へ100%を正規化しなくてもよいということと、未知の各仮説へ個別priorを今すぐ置けるわけではないということが両立する点にある。

5. 先行理論2：unawareness と growing awareness

Dekel, Lipman, and Rustichiniは、一定の自然な公理の下で標準的state-space modelが非自明なunawarenessを表現できないことを示した。その後、Heifetz, Meier, and Schipperなどは、異なる表現力を持つ複数のstate spacesを組み合わせるgeneralized state-space modelによってunawarenessを形式化している。したがって、ここから「確率論ではunawarenessを原理的に扱えない」という普遍的結論を出すべきではない。

Karni and VierøのReverse Bayesianismはさらに直接的で、awarenessの成長によってstate spaceが拡張したときのbelief revisionを扱う。特徴的なのは、新しい可能性が発見されても、旧事象同士の相対的なlikelihoodを保存する型の更新規則を与える点である。

ただし、新しく発見された事象へ絶対的にどれだけ確率質量を置くべきかまでは、旧credenceだけから一般には決まらない。新仮説の内容、説明力、証拠との適合、単純性や他理論との関係を実際に評価する必要がある。

6. 先行理論3：model misspecification

「いまのモデル内部でposteriorが鋭く集中した」という事実と、「モデル空間が十分だった」という主張も分けなければならない。Kleijn and van der Vaartは、真のデータ生成分布がモデルのsupport外にあるmisspecified caseでも、posteriorがモデル内部のKullback–Leibler的に最も近い点へ集中しうることを示している。

したがって、非常に高いposteriorはモデル条件付きの確信でありうる。Gelman and Shaliziが強調するmodel checkingとmodel revisionは、まさに「モデル内部の更新」と「モデルそのものの批判」を分ける実践である。

Key distinction: P(H | E, current model space) が非常に高いことは、current model space is exhaustive が非常に確からしいことと同じではない。

7. 「無限に広いpriorを置けば解決するか」

Bayesian nonparametricsやalgorithmic inductionのように、最初から非常に広い、場合によっては無限のモデルクラスを取る方法は、この問題を大きく緩和する。有限個の名前付き理論だけを列挙する必要はない。

しかし、非常に広い空間と概念的に開いた空間は同じではない。どれほど巨大でも、数学的に定義されたmodel classには表現言語、support、観測変数、同一性条件がある。将来の概念革新がその座標系自体を変えるなら、単なる「候補数の増加」では捉えきれない場合がある。

8. 仮説空間の拡張には少なくとも三型ある

  • 追加型： AかBだと思っていたところへCが加わる。旧仮説の意味はほぼ保存される。
  • 細分化型： Aだと思っていたものがA1とA2へ分かれる。state-space refinementとして比較的扱いやすい。
  • 変形型： 新概念の導入によって、旧仮説の意味、証拠の読み方、何を変数とみなすか、何を主体とみなすかまで変わる。

価値探索が最も強く問題にするのは第三型である。新しい価値概念や新しい主体構造によって、「功利主義 vs. 義務論」という現在のpartition自体が将来不適切になる可能性がある。その場合、旧空間から新空間へ自然な一対一対応があるとは限らない。

9. open-world value uncertainty を再定義する

この整理を採ると、道徳的不確実性の閉鎖世界問題におけるflat admissibilityも少し言い換えられる。

Flat admissibilityはflat probabilityではない。 未概念化仮説へ等確率を与えることでも、名前のない「その他」に恣意的な数字を置くことでもない。現在の明示的仮説には、証拠に応じてcredenceを極端に集中させてよい。その一方で、現在の仮説空間自体を将来追加・再分割・再構成できる認識的能力を残す。

ここでは二種類のepistemic stateを区別できる。

  • Local credence: 現在概念化できている仮説間の相対的確信。ここではBayesを最大限使える。
  • Representational openness: 現在の言語・仮説空間・partitionが将来改訂されうることを認め、その改訂能力を保持すること。

10. 99.9999%でもロックイン問題が残る理由

Coreの「強く推論してよいが、不可逆ロックインには追加条件が要る」という主張は、Bayesianismとの対立ではなく、ここで精密化できる。99.9999%というposteriorが現在空間内部の比較として十分に正しくても、将来のX操作――新概念・新仮説・新観測の導入――を永久に不可能にする判断は別の対象を決めている。

したがって、posteriorの高さだけでなく、誤っていた場合の不可逆損失、将来情報の価値、モデルチェックの余地、仮説空間再構成の可能性を別に考える必要がある。これは「いつまでも疑え」という要求ではなく、局所的確信と表現空間の永久閉鎖を同一視しないという要求である。

11. AIと価値ロックインへの含意

高度AIに現在の価値関数を固定する問題は、単にどの既知倫理理論へ何%のcredenceを置くかという問題ではない。AIが将来、新しい主体、新しい現象的データ、新しい世界モデル、新しい価値概念に遭遇したとき、価値仮説空間そのものを改訂できるかが重要になる。

本プロジェクトの「探索可能性保存」は、これを一般化して、将来のevidence update B だけでなく、将来のhypothesis-space revision X を実行可能な状態に保つこと、と再記述できる。先行研究の多くが「awarenessが増えた後、beliefをどう改訂するか」を問うのに対し、本プロジェクトの追加的関心は、そのawareness expansionの能力自体を、現在のposteriorに基づいて不可逆に破壊してよい条件は何かにある。

Provisional conclusion: ベイズ更新は、現在の仮説空間内部での合理的なcredence更新を与えるが、未概念化仮説を生成し、拡張後の仮説空間を一意に構成する規則ではない。未概念化仮説は通常zero-prior hypothesisではなく、現在の確率空間にまだ属していない。open-worldな合理性にはBayesian conditionalizationに加えてhypothesis-space revisionが必要であり、value explorationの中心的役割は、現在の最善仮説へ強くコミットしながら、将来その空間自体を再構成する能力まで不可逆に閉じないことにある。

12. 何がこの見方を弱めるか

  • 合理的探究に必要な将来の概念革新が、十分に一般的な固定言語・固定model classの内部で常に表現できると示される場合。
  • hypothesis-space revisionを、通常のBayesian conditionalizationだけで追加仮定なく一意に導けることが示される場合。
  • 現在の仮説空間のexhaustivenessについての不確実性が、実際の意思決定や不可逆ロックイン判断に独立の差を生まない場合。
  • 価値概念の将来的変形が、既存理論の追加・細分化だけで十分に表現できると示される場合。
