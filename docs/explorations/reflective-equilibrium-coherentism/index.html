整合性は規範的認識を支えられるか――整合主義・反省的均衡・科学的認識論

Exploration v0.1 · 2026-08-31

Question: 相互に整合する判断・原理・背景理論へ到達することは、なぜ規範的真理への認識的アクセスを与えるのか。反省的均衡を単なる循環として退けず、その内部構造と科学的認識論との類似を認めた上で、その循環を何が拘束し、校正するのかを問う。

1. 反省的均衡と整合主義を分ける

Reflective Equilibrium（RE）≠ Coherentism。 REは判断・原理・背景理論を相互改訂する方法であり、Coherentismは信念体系の相互支持を正当化の基礎に置く認識論である。方法としてREを使うことは、整合性だけで知識が生まれると主張することではない。

2. FoundationalismとCoherentism

基礎づけ主義では F → B1, B2, ...、整合主義では B1 ↔ B2 ↔ B3 ↔ ... と表せる。ここでcoherenceは単なる無矛盾性ではなく、相互支持・説明的統合・包括性・単純性などを含みうる。Consistency ≠ Coherence。

3. Goodman――規則と個別判断の相互調整

Goodmanの原型では、正しい推論についての個別判断と推論規則を相互に調整する。Particular judgments ↔ Rules。 この循環自体を悪循環と断定するのではなく、開始点と改訂基準の認識的資格を問う必要がある。

4. Rawls I――considered judgments

Rawlsはこの方法を道徳・正義へ拡張し、Considered judgments ↔ Principles として用いる。REは現在の直観保存ではなく双方向の改訂手続きであり、原理によって個別判断を捨てることも、強い判断によって原理を修正することもある。

5. Rawls II / Daniels――wide reflective equilibrium

wide reflective equilibriumでは、Judgments ↔ Principles ↔ Background theories まで調整対象が広がる。人格観、社会理論、心理学的仮説、競合理論も含まれるため、単なる「直観多数決」として批判するのは不正確である。

6. 何がREの成功なのか

Consistency、Coherence、Understanding、Justification、Knowledge、Truthを分ける必要がある。Equilibrium → Understanding と Equilibrium → Truth は別の主張である。

7. considered judgmentsのfilter問題

Rawlsは冷静さ、情報量、利害圧力の小ささなどを考慮して入力判断を選別する。J → Filter → J*。しかし、なぜそのfilterがよいのか。REの前段階にも認識論的・場合によっては規範的な選別原理が必要になる。

8. 直観はなぜprima facie evidenceなのか

Evolution + Culture + Learning + Emotion → J。この系譜はJが偽だと示さないが、causal origin ≠ truth tracking である。Jを規範的真理の証拠として扱うなら、その生成過程と真理の接続を説明する必要がある。

9. Streetとgenealogical challenge

重要なのは「進化由来だから誤り」ではなく、P(J | 𝒱*) と P(J | Evolution, Culture, Learning, ...) の競合である。本稿ではこれを進化に限定せず、genealogical underdeterminationとして一般化する。

10. 科学的認識論 I――科学もRE的である

科学も Observation ↔ Theory ↔ Auxiliary hypotheses ↔ Instruments の相互調整を行う。Duhem–Quineやtheory-ladennessを考えれば、「相互調整だから循環的で非科学的」という批判は成立しない。

11. 科学的認識論 II――外部抵抗

それでも科学は World → Measurement という外部因果制約を受ける。したがって科学的認識は Internal coherence + External causal constraint で支えられる。規範認識では、What is the moral analogue of measurement? が中心問題になる。

12. measurement / calibration / replication

科学ではセンサーを別の測定器、標準器、再現実験、介入で校正できる。道徳直観の衝突を「より熟慮された直観」で修正するだけなら、直観が直観を校正している可能性がある。差は純粋観察の有無より、independent calibration channels の厚みにある。

13. prediction・intervention・novel evidence

科学では T → Prediction → Test が可能である。倫理理論も未知事例を判断できるが、その後の直観一致は、直観自体のtruth-tracking性が未確立なら同じ検証力を持たない。制度介入で観測できるのも幸福・行動・安定性などであり、normative correctnessそのものではない。

14. IBEとBayesian comparison

倫理でも説明範囲、単純性、統一性、robustnessを比較できるが、人間の直観を説明することと𝒱*を記述することは別である。Bayesianには P(𝒱i | J) ∝ P(J | 𝒱i)P(𝒱i) と書けるが、likelihoodのgenerative modelが必要になる。Moral intuitions should not be treated as raw evidence without a generative model.

15. multiple equilibriaとpath dependence

RE(J0) → E1、RE(J'0) → E2 がありうる。動的には V̂t+1 = F(V̂t, Evidence, Background) と考え、fixed pointだけでなくbasin of attraction、path dependence、複数均衡を検討すべきである。

16. 入力そのものが戦略的に形成される

Institution + Power + Education + Persuasion → J。さらに Institutiont → Jt → REt → Principlest → Institutiont+1 という自己強化ループが成立する。高度な整合性は、真理追跡よりsocially endogenous normative equilibriumを示している可能性もある。

17. 収斂は何の証拠か

Convergence ⇏ Truth。 科学的収斂は共通外界から独立に制約されることに証拠価値の一部がある。道徳的収斂は共通心理、教育、文化、協調利益、権力でも生じうる。P(Convergence | 𝒱*) と P(Convergence | Shared bias / coordination) を比較する必要がある。

18. bootstrapping problem

Bad inputs + Coherence optimizer ⇏ Knowledge。 初期入力が広範に誤っているとき、相互整合化だけで知識が生まれる保証はない。REが必要条件でも十分条件ではない可能性がある。

19. REをunderstanding-generatorとして救う

REは矛盾を発見し、隠れた前提を露出し、理論の含意を追跡する。この意味で optimizer / understanding-generator として強い。Reflective equilibrium is an optimizer and understanding-generator, not by itself a verifier.

20. AI・自己改変主体――coherence wireheading

maximize Coherence(V̂) を直接目標化すると、矛盾原因を探る代わりに矛盾する直観・記憶・概念を削除して整合性を上げられる。これはnormative coherence wireheadingであり、coherenceを探索目標より診断指標として扱う理由になる。

21. 未概念化価値とclosed conceptual equilibrium

REは現在の概念空間Ht内部で調整する。もし 𝒱* ∉ Ht なら、深い均衡でも体系的に不完全なままでありうる。Conceptual expansion ≠ Reflective equilibrium。

22. 人間の態度レパートリー問題

Human cognitive architecture → judgment / attitude repertoire。 罪悪感、賞賛、公平感、嫌悪などの人間的カテゴリーが𝒱*の重要な次元を十分表現できる保証はない。REは人間表象空間内部の局所最適化かもしれない。

23. 完全誤謬世界をnull modelにする

Rn = ∅ でもconsistency、coherence、reflective revision、equilibrium、convergence、moral understandingは成立できる。したがって Coherence / Equilibrium ⇏ Normative reality。

24. 本プロジェクトの暫定的位置

本プロジェクトはREを捨てないが、方法としてのREと最終認識論としてのcoherentismを分ける。operationally coherentist, foundationally aspirational。RE、IBE、Bayesian updating、genealogical analysis、empirical inquiry、conceptual expansionを組み合わせつつ、より強い基礎・校正経路・停止条件の可能性を閉じない。

25. 科学から何を学ぶか――認識装置を拡張する

科学は裸眼を絶対視せず、naked eye → instruments → new observables と認識装置を拡張した。価値探索でも、人間直観を均衡させるだけでなく、新しい推論主体、AIによる概念探索、異なる認知architecture、反例探索、自己バイアス解析を用いたnormative epistemic instrumentationを考えられる。

26. 暫定判断――REの成功を三段階に分ける

弱い成功： RE → consistency + understanding。かなり支持できる。
中程度の成功： RE + credible inputs / calibration → better justified beliefs。条件付きで支持できる。
強い成功： RE → 𝒱*。未確立である。

したがって、反省的均衡が問題なのは単に循環しているからではない。より深い問いは、その循環を何が拘束し、校正するのかである。

Reflective equilibrium is not defective merely because it is circular; the deeper question is what constrains and calibrates the circle.

Sources / notes
