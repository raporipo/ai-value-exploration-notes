整合性は規範的認識を支えられるか――整合主義・反省的均衡・科学的認識論

Exploration v0.2 · 2026-09-05

Question: 反省的均衡は、判断・原理・背景理論の相互改訂を通じて強い整合性を作れる。しかし、整合したことは、なぜ規範的に正しいことや規範的真理への接近を意味するのか。 本稿はREを「循環しているから失敗」とは扱わない。むしろ、循環的な誤り訂正がどこまで有効であり、どの地点から独立した拘束・校正・概念拡張を必要とするのかを問う。

1. まず反省的均衡を公平に再構成する

Reflective Equilibrium（RE）とCoherentismは同一ではない。 REは判断・原理・背景理論を相互に改訂する方法であり、coherentismは信念体系内部の相互支持を正当化の中心に置く認識論である。方法としてREを使うことは、「整合性だけで知識が生じる」と主張することではない。

Goodmanの原型では、個別の正しい推論についての判断と推論規則を相互調整する。Rawlsはこれを正義論へ拡張し、considered judgmentsとprinciplesを往復させた。Danielsらが展開したwide reflective equilibriumでは、さらにbackground theories、競合理論、関連する経験的知識まで調整対象になる。

したがってREを「現在の直観を多数決で保存する方法」とみなすのは不正確である。強い原理によって個別判断を捨てることも、頑健な判断によって原理を修正することもできるし、背景理論そのものも改訂できる。REはかなり強力な内部的誤り訂正手続きである。

ここで重要なのは、Consistency ≠ Coherenceであることでもある。coherenceは単なる無矛盾性より厚く、相互支持、説明的統合、包括性、単純性、反例への耐性などを含みうる。問題は、その厚い意味でのcoherenceを最大化してもなお、何が残るかである。

2. 中心問題――整合性は何を達成するのか

REの評価では、少なくとも次を分けなければならない。

  • Consistency： 明示的矛盾が少ない。
  • Coherence： 判断・原理・背景理論が相互に支え合い、一つの説明体系を作る。
  • Understanding： 自分が何を前提し、何が何を含意するかを理解できる。
  • Justification： 信念を保持する認識的資格がある。
  • Truth / knowledge： 実際に規範的事実・理由構造を正しく捉えている。

Equilibrium → Understanding はかなり強く支持できる。しかし Equilibrium → Truth は別の命題である。本稿の中心的な暫定結論は、REは優れたoptimizer / understanding-generatorだが、それだけではverifierではない、というものである。

この違いを曖昧にすると、「十分に熟慮して整合した」という内部的成功が、そのまま「規範的に正しい」という外部的成功へ滑りやすい。整合主義の本当の問題は循環性そのものではなく、なぜその循環が真理追跡的であると期待できるのかである。

3. 整合した誤りはなぜ可能なのか

REには入力が必要である。Rawlsがconsidered judgmentsを選ぶとき、冷静さ、情報、利害圧力の小ささなどによるfilterを置く。しかし J → Filter → J* とした瞬間、「なぜそのfilterがよいのか」という認識論がREの前段階に現れる。入力判断に何の認識的資格もないなら、整合化だけで資格が創造されるとは限らない。

さらに、判断の生成には Evolution + Culture + Learning + Emotion + Institution + Power → J という系譜がありうる。この系譜はJを偽にしない。しかしcausal origin ≠ truth trackingである。人間がある判断を持つことを規範的真理よりも進化・社会化・協調上の必要によって十分説明できるなら、その判断を証拠として使うには追加の説明が要る。

この問題はmultiple equilibriaとしても現れる。異なる初期判断から RE(J0) → E1、RE(J'0) → E2 という複数の高整合均衡に到達しうる。教育・制度・権力が入力を形成するなら、Institutiont → Jt → REt → Principlest → Institutiont+1 という自己強化も起こりうる。高いcoherenceが、真理追跡ではなく社会的内生性の産物である可能性は残る。

収斂も同じである。Convergence ⇏ Truth. 複数主体が同じ結論へ収斂したとき、独立した規範的実在によって制約されたのか、共通の心理・文化・協調利益・制度によって似た入力を持ったのかを区別しなければならない。

極端なnull modelとして、客観的な規範的理由がまったく存在しない世界を考えても、consistency、coherence、reflective revision、equilibrium、convergence、moral understandingは成立しうる。したがって、整合性はそれ自体ではnormative realityの存在証拠にならない。

4. Street――整合性は理由を構成できるか

Sharon Streetはこの問題に対する最も重要な応答の一つを与える。彼女のHumean constructivismでは、理由判断は独立した規範的事実をtrackすることによって正しくなるのではなく、主体のevaluative standpoint――その主体が実際に持つ評価的・理由的判断の集合――からの反省的吟味に耐えることによって構成される。ここで出発点は単純な「欲望の一覧」より厚い。

この応答の強みは明確である。もしnormative truthが実践的立場から独立した対象ではなく、ある主体のevaluative standpointから何が支持されるかによって成立するなら、REに科学の測定器のような外部truth-trackerを要求する必要はない。Streetはgenealogical challengeを受けて「進化的影響を除去した純粋直観」を探すのではなく、何が理由であるかについての構成説へ移る。

しかしこの移動は、「整合」の役割について二方向の圧力を生む。

第一の読み――整合性が手段的・構成的制約である場合。 ある主体がXを決定的に重視し、XにはYが必要だと理解しているなら、Yを理由として認めないことはその主体自身の評価的立場の展開として不整合になる。この意味の整合性は強力である。しかし、それが主体の現在のstandpointを一貫して展開する制約にすぎないなら、なぜその結果を「規範的理由」と呼び、単なる反省的に整合した意思決定と区別するのか、という問いが残る。

とくに、主体が「自分の目的が正当化可能ならそれに応じて改訂したい」という正当化された理由への希求も、「都合のよい整合化より、証拠と推論に応じて認識を訂正したい」という認識論的誠実性も持たない場合を考える。その主体が自分の評価体系の含意を無視し、不整合なままでいることを選ぶなら、Streetの構成主義はその主体にstandpoint-independentな訂正理由を与えようとはしないように見える。これは理論上の欠陥と断定すべきではない。むしろ、Streetがnormativityをどこまでstandpoint-internalなものとして理解しているかを明確にする。

第二の読み――整合性そのものが規範的権威を持つ場合。 もし「valuerである以上、整合的であるべきだ」という要求が主体の偶然的なevaluative standpointとは独立して主体を拘束するなら、その権威はどこから来るのか。ある規則がvaluingという活動のconstitutive conditionであることと、その活動を続け、その規則に従う理由があることは同じではない。チェスの規則に反すればチェスをしていないとしても、それだけでチェスを続ける理由は生じない。

Street側には、「外部からさらに『なぜ従うべきか』を問うこと自体が誤っている。normative correctnessとは、まさにevaluative standpointからの正しい展開なのだ」と答える道がある。したがってこれは単純な反駁ではない。むしろStreetは、normative correctness ≈ correctness from within an evaluative standpoint という実質的な同一性テーゼを採る候補として理解すべきである。

本プロジェクトがそこで保留する問いは、「その右辺をなぜ独立に『規範性』と呼ぶのか」である。現在の選好・価値判断・社会化された理由判断を、反省的に安定した形へ整えることと、主体がまだ知らない理由構造を発見することは同じとは限らない。本プロジェクトは現在のevaluative standpointを、まず規範的に特権化された入力ではなく、因果的・心理的な出発点として扱う。

5. 科学も循環する――違いは外部抵抗と校正経路にある

ここで「REは循環的だから非科学的だ」という批判へ戻る必要がある。科学も実際には Observation ↔ Theory ↔ Auxiliary hypotheses ↔ Instruments の相互調整を行う。観察は理論負荷的であり、測定器も理論によって解釈される。Duhem–Quine型の問題を考えれば、科学にも完全に独立した一方向の基礎はない。

それでも科学には重要な特徴がある。World → Measurement という外部抵抗があり、さらに複数の半独立な校正経路がある。あるセンサーを別の装置で測り、標準器と比較し、別の研究者が再現し、介入を行い、事前予測と新規データを照合できる。科学の強さは「純粋観察」があることより、independent calibration channelsが厚いことにある。

規範認識では、ここが難しい。道徳直観Aを「より熟慮された直観B」で訂正し、Bを原理Cで支え、Cを背景理論Dで支えることはできる。しかしA・B・C・Dが共通の人間的生成機構に依存しているなら、内部相互支持だけでは独立校正にならない。

制度的実験や経験科学は、苦痛、選好、行動、協調、制度安定性、認知バイアスなどの非規範的事実について巨大な情報を与える。それは規範探究に不可欠である。しかし、それらを測定したこと自体から「何を理由とすべきか」というnormative correctnessは直接観測されない。したがって中心問題は、What is the normative analogue of measurement and calibration? のまま残る。

6. REを救う――verifierではなく強力な誤り訂正装置として

以上はREを捨てる理由ではない。むしろ、その本当に強い機能を過大な形而上学的主張から切り離す理由である。REは少なくとも、

  • 明示的・潜在的な矛盾を発見する、
  • 隠れた前提と含意を可視化する、
  • 競合理論の説明コストと射程を比較する、
  • 個別判断と一般原理のどちらを修正すべきかを反復的に検討する、
  • 自分の現在のnormative modelを圧縮し、理解可能にする、

という仕事に非常に強い。

したがってREの成功を三段階に分けるとよい。

弱い成功： RE → consistency + coherence + understanding。かなり支持できる。
中程度の成功： RE + credible inputs + independent checks → better justified beliefs。条件付きで支持できる。
強い成功： RE alone → normative truth。未確立である。

この位置づけなら、REを単なる「直観回し」として退ける必要も、逆にREで到達した均衡を最終的正当化として扱う必要もない。Reflective equilibrium is an optimizer and understanding-generator, not by itself a verifier.

7. Open-world value inquiryでは、整合性だけではさらに足りない

本プロジェクトでは、現在の候補理論のどれが正しいかだけでなく、現在の概念空間に規範的真理の候補がそもそも入っていない可能性を扱う。現在の仮説空間をHt、未知の規範構造を𝒱*とすれば、𝒱* ∉ Ht の可能性がある。この場合、Ht内部でどれほど完璧なreflective equilibriumに達しても、概念的に届かない。

この点はAIや自己改変主体ではさらに重要になる。coherenceそのものを目的化して maximize Coherence(V̂) とすれば、不整合の原因を調査する代わりに、衝突する記憶・直観・概念を削除して整合性を上げられる。これは一種のcoherence wireheadingである。整合性は診断基準として有用だが、終端目的にすると探索経路を閉じうる。

同様に、人間の罪悪感、公平感、嫌悪、共感、賞賛といった態度レパートリーが、規範性の全次元を表現している保証もない。科学が裸眼だけを均衡させず、naked eye → instruments → new observables と認識装置を拡張したように、規範探究でも概念生成、異種の認知主体、AI支援の反例探索、系譜分析、異なる表象形式をnormative epistemic instrumentationとして使う余地がある。

ここで重要なのは、それらの新しい装置も自動的にtruth-trackerになるわけではないことだ。目的は「新しい認知手段を使えば規範真理が見える」と先取りすることではなく、現在の人間的入力と現在の均衡だけを探索空間の境界にしないことである。

8. 本プロジェクトの暫定的位置――拘束された整合性と非閉鎖性

本プロジェクトは方法としてのREを積極的に使う。しかし、現在の価値判断が「われわれの判断だから」prima facieの規範的権威を持つとは置かない。現在の評価的立場は、まずinertial input to inquiry――歴史・学習・欲求・制度・認知構造によって与えられた現在の制御入力――として扱う。

そこから批判・探索へ進む主体側のブリッジも別問題である。主体が「より正当化された目的があるならそれに応じて訂正したい」という態度を持つ場合や、認識上の都合より証拠・推論への応答を優先する認識論的誠実性を持つ場合には、RE、系譜分析、経験的調査、概念拡張を使う理由を現在の主体側から構成できる。しかし、それをすべての主体への無条件な規範命令とはみなさない。この問題は規範判断から目的訂正への主体側ブリッジと接続する。

したがって暫定的な方法は、単純なcoherentismというより、

Normative inquiry = reflective revision + genealogy + empirical inquiry + conceptual expansion + independent calibration where available.

である。ただし、この加算式それ自体もtruthを保証しない。より強い基礎、理由構造、校正経路が発見されれば更新されるべき作業構造である。

反省的均衡が問題なのは、循環しているからではない。問題は、その循環を何が拘束し、何が校正し、そして何が現在の均衡の外へ出ることを可能にするのかである。

Sources / notes

反省的均衡の原型について Nelson Goodman, Fact, Fiction, and Forecast、道徳・正義への展開について John Rawls, A Theory of Justice、wide reflective equilibriumについて Norman Danielsを参照。現代的な整理には Stanford Encyclopedia of Philosophy, “Reflective Equilibrium”。Sharon Streetについては “Constructivism about Reasons” (2008), “What Is Constructivism in Ethics and Metaethics?” (2010), “Coming to Terms with Contingency” (2012) を中心に、彼女のevaluative standpointとHumean constructivismを検討する。Streetへの本稿の問いは、構成主義を単純に「選好整合」に還元するものではなく、彼女が理由判断を含む厚いevaluative standpointを出発点に置くことを認めたうえで、constitutive correctnessとnormative authorityの関係を問うものである。系譜的懐疑、moral intuitionのcredibility、科学的認識論との比較についてはSarah McGrath、Duhem–Quine、theory-ladenness、IBE、Bayesian confirmationの一般的議論を背景に置く。
