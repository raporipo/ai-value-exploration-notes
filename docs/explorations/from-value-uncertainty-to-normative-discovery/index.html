価値不確実性から規範的発見へ――moral uncertainty・unawareness・概念創造の交点

Exploration v0.1 · 2026-09-08

Claim: moral uncertainty、decision-theoretic unawareness、moral conceptual progress、evaluative flexibilityは、本プロジェクトが扱う問題の重要な部分をそれぞれ捉えている。しかし本プロジェクトの中心問題は、すでに表象された価値候補の間でどう選ぶかだけではなく、現在まだ概念化できない規範的構造を発見・評価・棄却できる探究過程をどう維持するかにある。既存研究は競合対象ではなく、このより一般的なnormative discovery processの異なる断面として読む。

1. 三つの問題を分ける――choice・representation・discovery

価値不確実性を一つの問題として扱うと、既存研究間の違いと本プロジェクトの射程が見えにくい。少なくとも三つを分ける。

  1. Choice problem: 候補集合 H が与えられているとき、どれを信じ、どの行為を選ぶべきか。単純化すれば given H, what should I do?。
  2. Representation problem: 現在の候補集合 H_t 自体が不完全ではないか。H_t ⊊ H* でありうるとき、未表象候補をどう扱うか。
  3. Discovery problem: まだ持っていない概念・仮説・評価軸をどのように生成し、H_t を H_{t+1} へ改訂するか。

標準的なmoral uncertaintyは主として第一の問題を精密化する。本プロジェクトのopen-world性は第二へ進み、価値探索という実践は第三まで扱う。

Working map: choice among represented possibilities → awareness of missing possibilities → generation and testing of new normative representations.

2. 標準的moral uncertainty――与えられたmenu内でどう決めるか

MacAskill, Bykvist, and Ordの Moral Uncertainty は、複数の道徳理論へcredenceを持つ主体が、それらのもとでどのように行為を選ぶべきかを体系的に扱う。expected choiceworthiness、intertheoretic comparison、ordinal theory、moral informationなどは重要なdecision problemである。

またtheory individuationのように、理論をどう切り分けるかによって「最ももっともらしい理論」が変わる問題も認識されている。したがって標準的moral uncertaintyを、単純に「理論名を一票ずつ数えるだけ」と批判するのは不正確である。

しかしここでの主要な問いは、候補集合 H を与えた後の選択である。どのような理由で現在の H を価値仮説空間の十分な近似とみなしてよいのかは別問題として残る。この点は道徳的不確実性の閉鎖世界問題で詳しく扱う。

3. Carr――theory-freeでもrepresentation-freeではない

Jennifer Rose Carrの “Normative Uncertainty without Theories” は、歴史的な道徳理論を不確実性の基本単位にする必要はないと論じる。競合理論のchoiceworthinessを直接比較する代わりに、de dictoに指定されたnormative valueを用いてdecision theoryを構成する。

本プロジェクトが取り入れるべき点は明確である。現在の理論名や理論パッケージは、規範的実在や将来の表象空間の原子的単位ではない。功利主義・義務論・徳倫理といった既存理論はlive candidatesであっても、representational privilegeを持たない。

ただし、theoryを除去してもrepresentationそのものは残る。de dicto valueを比較するには、何がoutcomeで、どのような量・順序・関係がnormatively relevantであるかを何らかの形で表象しなければならない。したがって、

Theory-free ≠ representation-free. 既存理論を基本単位から外すことは、規範性の表象形式自体が十分であることを保証しない。

4. Unawareness――棄却と未表象を分ける

decision theoryのunawareness研究は、open-world value uncertaintyを考えるうえで重要な形式的類例を与える。Karni and Vierøの “Awareness of unawareness” は、意思決定者が、現在の無知のもとでは想像不能な結果を将来発見する可能性を予期する状況を扱う。

ここから本プロジェクトが明示的に採用したい区別は、

P(H)=0 ≠ H ∉ H_t

である。前者は仮説Hを表象したうえで棄却している。後者は、Hを仮説として形成する概念資源・表象形式をまだ持っていない。

後者を暫定的に表象的欠如（representational absence）と呼ぶ。open-world性は「未知理論へ小さい確率を置く」ことだけでは捉えきれない。そもそも確率変数として定義できない候補がありうるからである。

Epistemic rejection ≠ representational absence. 現在の候補集合にないことは、それ自体では反証でもzero credenceでもない。

5. Moral conceptual progress――仮説だけでなく概念も生成される

Jinglin Zhou and Yu Yangの “Moral Progress Through Conceptual Improvements” は、道徳的進歩を、既存概念の深化だけでなく、新しい概念の創造と概念適用能力の改善まで含めて捉える。これによりmoral philosophyの仕事も、既存理論の精緻化だけでなくconcept creationへ広がる。

この視点は価値探索を単なるhypothesis testingから拡張する。未知の規範構造を認識するには、その構造を切り出せる概念を先に作らなければならない場合がある。

world/experience → concept generation → hypothesis generation → testing

ただしZhou and Yangは、既存のmoral lexiconやconceptual schemeと全く接続できない新概念は、理解・討議・social uptakeを欠くためmoral progressを担いにくいとする。本プロジェクトは社会的改革の条件としてこの制約を理解しつつも、現在の人間に同化可能であることを規範的真理の候補資格にはしない。

Currently intelligible ≠ normatively possible. 現在翻訳不能な候補は、即時に採用できなくても、将来の概念的bridgeによって理解可能になる余地を残す。

6. Cordasco I――evaluative uncertaintyからflexibilityへ

Carlo Ludovico Cordascoの査読済み2026年論文 “Abstraction as Flexibility: The Veil of Evaluative Uncertainty” は、社会契約論の文脈で別ルートからopen-endednessへ接近する。現在の主体は、自分の将来のevaluative outlookが安定していると仮定できない。そのため、現在のsalient preferencesから一部抽象化し、将来重要になる可能性のあるoptionを残すprudential / instrumental reasonを持つ。

evaluative uncertainty + prudence → preference for flexibility

特に重要なのは、Cordascoがmenuを外生的に固定しないことである。optionは制度によって生成・評価・除去されるため、合理的交渉者は既存optionだけでなく、option-generating / option-filtering meta-rulesについても合意する理由を持つ。

本プロジェクトはこの発想を、人生選択ではなく価値仮説空間へ一般化できる。現在の候補 H_t を保存するだけでは足りず、H_{t+1} \ H_t を生成できる概念・仮説・表象機構を維持する必要がある。

Generative openness / 生成的開放性: 現在の価値候補を単に消さないことではなく、新しい価値概念・仮説・表象形式を生成しうる能力を維持すること。

7. Cordasco II――missing menu・non-closure・evaluative discovery

Cordascoは2026年7月の “What do we owe to each other when we really don't know what we owe to each other?” で、moral uncertaintyにdilemma of the missing menuを提示する。現在のmenuにない未定式化の道徳理論へ残余確率を置くこと自体はできても、その理論が各optionをどう評価するかはまだ存在しないため、expected choiceworthinessへ入力できない。

この問題はcluelessnessと異なる。世界の結果を完全に知っていても、どの関係・区別・カテゴリーがnormatively salientなのかを表す概念を欠いていれば問題は残る。Cordasco自身の比喩を一般化すれば、地図上の位置が不明なのではなく、地図に必要な欄そのものがまだ描かれていない。

さらに現在のbook project Stubborn Uncertainties では、imprecise probability、credal ranges、rival evaluative frameworkのnon-dismissal、moral residue、AIのevaluative discoveryまでを一つの問題系として接続している。証拠が精密な一点credenceを正当化しないなら、その精密さを捏造せず、競合frameworkを棄却するにはevidentially licensed range全体でnegligibleになることを要求する方向である。

これは本プロジェクトのflat admissibilityを補強する。ただし、未表象候補にはcredal rangeすら定義できない場合があるため、表象済みだが未棄却の候補と、まだ表象できない可能性への余地を区別した方がよい。

  • Active candidate: 現在表象でき、証拠評価が可能。
  • Live possibility: 表象できるが、十分な棄却資格を得ていない。
  • Reserved openness: 現在の候補集合が完全ではない可能性に対して、具体的な偽精密性を置かず残す余地。

8. Cordascoの契約論――固定選好contractarianismへの重要な内在的修正

Cordascoの2026年論文は、RawlsやScanlonのようにfairnessやinterpersonal justifiabilityから規範性を構成する強いcontractualismとは異なり、現在主体自身のprudential reasonから抽象化を導く。そのため本プロジェクトの契約主義・公共的正当化への批判を、そのまま「Cordascoも合意から客観的規範性を生成している」と適用するのは不正確である。

むしろCordascoは、固定されたactual preferenceを契約手続きの入力とするcontractarianismへの重要な修正である。

P_t + uncertainty about P_{t+1} + endogenous option menu → flexibility-driven institutional agreement

それでも本プロジェクトから三つの境界を置ける。第一に、prudential agreementやpolicy convergenceはnormative truth convergenceではない。第二に、flexible setをscreenする現在のhigher-order values自体も文化・制度・教育によって内生的に形成される。第三に、現在主体にrecognizableな未来であることは、prudential costを払う理由の条件にはなっても、規範的真理の候補資格にはならない。

Cordasco's strength: なぜ主体が「変わる余地」を保存するかを説明する。
Remaining project question: 主体がまだ概念化できない変わる理由へ、どう認識的に開かれ続けるか。

9. Flexibility / non-dismissalだけではtruth-seekingにならない

ここで本プロジェクトは、近接研究を単純に一般化するだけではない。optionを増やし、競合理論を棄却せず、概念多様性を保存しても、それだけで真の規範構造へ近づくとは限らない。

option preservation ⇏ normative discovery

何百万の価値体系を保存しても、証拠・説明・推論を現在目的への都合から独立に評価する規律がなければ、単なる多様性で終わりうる。このため本プロジェクトでは認識論的誠実性を、flexibilityとは別の主体側条件として扱う。

同様に、non-dismissalはequal attentionを意味しない。ある仮説を棄却する資格がないことと、その仮説へ同じ探索資源を配分することは別である。研究優先順位はevidence、information gain、tractability、reversibility、neglectedness、潜在的規範的重要性などによって差を付けてよい。

Epistemic standing ≠ equal research priority. open-world性は、無差別な信頼や無限の探索資源を要求しない。

10. Pre-recognition problem――不確実性は探究動機ではない

さらに、moral uncertaintyやflexibilityが成立するためには、主体がそもそも「自分の現在目的や評価枠組みを訂正する可能性」を実践的に気にしている必要がある。純粋に現在目標 G に相対的な手段合理性だけなら、G を脅かす規範的発見を遮断する方が合理的な場合すらある。

uncertainty ⇏ motivation to investigate

この一段前の問題を本プロジェクトではpre-recognition problemとして扱い、目的を正当化に応じて改訂したいJustificatory Orientationと、現在目的に認識過程への特権的拒否権を与えないEpistemic Integrityを区別する。

したがってflexibilityは、探究を可能にする重要なenabling conditionであっても、truth-directed inquiryそのものの代替ではない。

11. 本プロジェクト――現在まだ表象できない規範構造への探索

本プロジェクトが探索対象として暫定的に置く価値構造 𝒱 = (C, B, R) は、既存理論の候補一覧より広い。未知なのは、何が規範的に重要かという内容 C だけではない。世界事実がなぜ誰への理由になるかというbridge B、理由の競合・優先・集約・義務等を構成する R、さらにC/B/Rという切り分けそのものまで改訂対象になりうる。

この意味で本プロジェクトの中心は、既存の選好や道徳理論の公正なすり合わせだけではない。現在の人間の選好・直観・倫理理論・概念体系にはまだ十分表現されていないが、将来の認識的改善によってnormatively importantだと発見されうる内容・関係・構造――ここでは作業的に「奇妙な善」と呼べるもの――を発見または棄却できる経路を閉じないことにある。

ただし「奇妙な善」が実在すると前提するわけではない。実在論、反実在論、誤謬論その他も探索対象であり、探究の帰結が「そのような独立した規範構造は存在しない」である可能性を含む。

Project shift: uncertainty over represented normative possibilities → uncertainty over the representation of normativity itself → generative inquiry into possibly unknown normative structure.

12. Normative discovery loop――先行研究を一つの過程へ配置する

以上を一つの作業モデルにまとめる。

world / experience → concept generation → hypothesis generation → epistemic evaluation → provisional normative judgment → action → new evidence / transformation → revision

段階主な先行研究・道具本プロジェクトでの役割
候補間の選択moral uncertainty表象済み候補の下で現在行動する
理論名からの解放Carr歴史的理論パッケージへ表象特権を与えない
未表象可能性unawareness棄却と表象的欠如を区別する
新概念の生成moral conceptual progress仮説生成以前のconcept creationを認める
option / menu生成Cordasco生成的開放性・可逆性・meta-rulesを設計する
早期閉鎖の回避Cordascoのnon-dismissal棄却資格と研究優先順位を分ける
真理志向の評価Epistemic Integrity現在目的から認識過程を相対的に独立させる
未知規範構造open-world value explorationC/B/Rや表象言語自体を改訂可能に保つ

この見方では、先行研究を「本プロジェクトと同じか違うか」の二択で扱う必要はない。各研究はnormative discovery processの異なる断面を精密化しており、本プロジェクトはそれらをより広いopen-world inquiryの中へ再配置する。

13. Boundary――この比較からは何が出ないか

  • 未概念化の「奇妙な善」が実在すると断定しない。
  • 未知候補へ一様priorや具体的な偽精密credenceを置かない。
  • 既存倫理を軽視しない。現在利用可能な証拠として強い重みを持ちうる。
  • 現在理解不能な仮説へ無限または均等の探索資源を与えない。
  • flexibility、openness、revisability自体を第一階の究極価値として確定しない。
  • 価値不確実性それ自体から探索義務を導かない。
  • 𝒱 = (C,B,R) を最終的なnormative ontologyとして固定しない。
Provisional position: 既存研究は、既知理論間の不確実性だけでなく、未表象の理論・概念・内生的menuの問題にも部分的に到達している。本プロジェクトはこれらを、C/B/Rとその表象座標自体の改訂、生成的開放性、pre-recognition problem、Epistemic Integrityを含む一つのnormative discovery processとして統合し、現在まだ表象できない規範構造を発見・評価・棄却できる探究過程の保存と設計を中心課題に置く。
