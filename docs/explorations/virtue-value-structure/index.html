徳は価値の基礎なのか――徳倫理と価値構造

Exploration v0.1 · 2026-08-29

Question: 徳は、それ自体が規範的に重要な内容なのか。人間的 flourishing から導かれる派生的性質なのか。それとも、すでに存在する理由を正しく認識し応答する主体能力なのか。本稿では徳倫理を単独の「第四の規範理論」として追加するのではなく、価値構造 𝒱=(C,B,R) のどこに徳を置くべきかを検討する。

1. 「なぜ徳に従うべきか」だけではKant論と重複する

本プロジェクトにはすでに、欲望・目的・自己像に依存しない規範性が存在するか、その拘束性を理性やagencyから導けるか、さらに人間がその内容を正しく認識しているかを検討する「定言的規範性は発見されたか」がある。したがって徳倫理について再び「なぜ徳に従うべきか」だけを問うと、規範的架け橋B一般の問題と重複する。

ここでの焦点は異なる。仮に何らかの規範性や理由関係が存在するとして、徳はその理由を生み出す側にあるのか、それとも理由を認識・統合・実践する主体の側にあるのかを問う。

2. 仮説A――徳そのものが基礎的な価値内容Cである

もっとも素朴には、勇気、正義、誠実、節制などがそれ自体で善く、徳を備えることが規範的に重要だと考えられる。この場合、徳は価値構造のCに置かれる。

Virtue → B → R

しかしこの形では、「なぜ勇気や誠実が理由を与えるのか」というB問題がそのまま残る。徳を列挙し、徳ある人物への称賛を示しても、そのことだけでは徳が主体独立的な理由を生むことは示されない。これは徳倫理に固有の失敗ではなく、功利主義が福利から理由へ、Kantが理性や自律から理由へ進む際と同型の問題である。

したがって仮説Aの評価では、徳の内容を詳しく分類することより、徳という評価カテゴリーが本当に規範的実在を追跡しているのかが重要になる。

3. 仮説B――flourishingが基礎で、徳はその実現条件である

FootやHursthouseに代表されるneo-Aristotelian naturalismでは、徳を孤立した価値項目として置くより、人間というlife-formの flourishing や natural goodness との関係で理解する。構造は概ね次のようになる。

human life-form → flourishing / natural goodness → virtue → action

この構図の利点は、「なぜこの性格特性が徳なのか」を、人間の生の機能・脆弱性・社会性・実践理性との関係で説明できる点にある。しかし本プロジェクトからは二つの問題が残る。

第一に、good qua human と reason simpliciter は同じではない。人間という種の flourishing に寄与することが、そのまま主体独立的な理由を生むかは別途論証を要する。

第二に、本プロジェクトは現在の人間的価値を重要なlive candidateとして扱う一方、その表象形式や種固有性に最終的特権を与えない。したがって human flourishing が現在の実践にとって非常に重要でも、それを宇宙的・最終的な規範座標と同一視することはできない。

4. 自己改変主体はnatural goodnessを不安定化する

自己改変可能なAIやポストヒューマンは、neo-Aristotelian naturalismの有力なストレステストになる。固定的なlife-formを前提するなら、機能、欠陥、flourishingを比較的安定して記述できる。しかし主体が自らの認知構造、欲求、身体、複製様式、さらには flourishing の定義自体を変更できる場合、次のような系列が生じる。

naturet → self-modification → naturet+1

このとき「その主体にとってよく機能すること」が規範の基礎なら、主体は自分の規範基準まで自己改変できるのか。それとも、改変前後を横断して妥当するより深いgoodnessが存在するのか。後者なら、結局その深い基準のBを説明する必要がある。

したがって、自己改変主体は「人間本性から徳へ」という議論を単に未来社会へ適用する問題ではなく、life-formが規範性の基礎になりうる条件そのものを問う。

5. 仮説C――徳は理由への感応能力である

McDowell的な方向では、徳ある主体は価値中立的な事実を見た後で外部ルールを適用するのではなく、状況の中で何が理由であるかを正しく捉える。ここでは徳は規範的理由の源泉ではなく、理由への認知的・感情的・実践的感応性として理解できる。

C → B → R → Virtue

この構図では、徳倫理は究極的価値理論というより、規範的主体論になる。徳とは、何が重要かを知覚し、理由の強度や競合を判断し、動機や行為へ適切に接続する安定した能力である。

この読みは本プロジェクトにとって特に重要である。価値探索の対象𝒱と、それを探索・認識・実践する主体を区別しなければならないからである。

Provisional distinction:
価値構造 𝒱=(C,B,R) と、価値認識主体 A=(perception, reasoning, motivation, character, ...) は同じものではない。徳倫理の一部は𝒱よりもAの理論として読む方が適切かもしれない。

6. この場合、徳倫理はRossを克服したのか

理由が先で徳がその認識能力だとすると、一つの批判が生じる。たとえば「約束を破ることは反対理由を与える」「無辜を意図的に殺すことは強い反対理由を与える」という第一階のreason-relationが先に存在し、徳ある主体はそれを正しく見抜くのだとする。

すると構造は、

reason-giving fact → virtuous recognition → action

となる。この場合、徳倫理は「なぜその行為特徴が理由を与えるのか」をgroundしているのではなく、Ross的に置かれたreason-relationを人間がどう認識し実践できるかを詳しくしているだけかもしれない。

この指摘は徳倫理を否定するものではない。むしろその理論的役割を明確化する。規範性の源泉を説明する理論と、規範性への優れた感応を説明する理論は別である。

7. Anscombeの重要性――行為記述そのものが理由を持つのか

Anscombeは、近代的な抽象的 moral ought を批判する一方で、不正、欺瞞、無辜の意図的殺害など、行為のある記述そのものに強い規範的重みを認めた。ここで重要なのは「行為そのものに価値がある」と一般化するより、ある行為記述D(a)が帰結を媒介せず直接にreason-giving / wrong-makingであるのかという問いである。

D(a) → B

たとえば「無辜を意図的に殺す」という記述が、それ自体で強い反対理由を与えるのなら、帰結とは独立した規範構造が存在する。しかしその直接的重みを、直観や伝統的な正義概念に依存せずどのように認識するのかは未決着である。

徳倫理が「徳ある人ならそうしない」と答えるだけなら循環の危険がある。「それが不正だから徳ある人はしない」と答えるなら、今度は不正という行為特徴のreason-giving forceが先に置かれる。したがってAnscombe的非帰結主義は、徳倫理の内部でも独立したB/R問題として残る。

8. 仮説D――徳・理由・flourishingは相互構成的である

よりholisticには、徳、理由、flourishingのいずれか一つを一方向の基礎に置かず、相互に制約し合うパッケージとして理解することもできる。

Virtue ↔ Reasons ↔ Flourishing

これは必ずしも悪循環ではない。科学理論でも複数概念が相互に支え合い、全体として説明力を持つ場合がある。本プロジェクトの価値構造も、C/B/Rが自由に組み合わせられる直積ではなく、相互制約的な理論パッケージとして扱っている。

ただし、その場合に必要なのは単なる整合性ではない。なぜそのパッケージ全体が、人間の規範的仮想実在を内部的に整合させただけではなく、外在的な規範構造をよりよく追跡していると考えられるのかを示す必要がある。

9. 徳倫理からプロジェクトへ取り込めるもの

徳倫理の最も頑健な部分が、究極的価値内容よりも「どのような主体が理由をよく認識し、誤りを修正し、状況に応じて実践できるか」にあるなら、本プロジェクトはそこを積極的に取り込める。

価値探索主体に必要な候補的徳として、知的謙虚さ、注意深さ、認識的勇気、反例への感応、自己修正可能性、既存規範を絶対化しないこと、他者視点や新しい主体形式を取り込む能力などが考えられる。

ただし、これらを「真の徳」として先に固定すべきではない。現時点では、価値探索・誤り訂正・仮説空間の維持に役立つ暫定的な探索主体特性として扱う方が本プロジェクトに整合的である。

10. 暫定評価

徳倫理は、単純に功利主義・義務論と並ぶ一つの第一階理論としてだけ扱うと、その理論的役割を見誤る可能性がある。少なくとも四つの読みを区別すべきである。

  • 徳基礎説： 徳そのものがCであり、理由を生む。
  • flourishing基礎説： human flourishingがCであり、徳はその実現条件である。
  • 理由感応説： C/B/Rが先にあり、徳はそれを正しく認識・実践する主体能力である。
  • 相互構成説： 徳・理由・flourishingが理論パッケージとして相互制約する。

本プロジェクトにとって特に重要なのは第三と第四である。徳倫理は、究極的規範性をすでに発見した証拠としては未決着でも、価値構造と価値認識主体を区別し、良い価値探索者の条件を考えるための理論資源として独立した役割を持つ。
