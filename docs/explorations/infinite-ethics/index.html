無限倫理と探索の暴走――麻痺・狂信主義・比例配分

無限や極端なステークスを排除せず、それでも一つの低確信仮説に探索と文明全体を乗っ取らせない意思決定は可能か。

Exploration v0.3 · 2026-08-28

Working position: 無限世界や無限価値を確率0として排除しない。しかし、それらを含む全仮説を単一の「確信度 × 善の大きさ」に圧縮して完全順位付けすることもしない。まず価値・メタ倫理・世界モデルへの確信度に応じて探索資源と暫定的な発言権を配分し、各仮説はその範囲内で自らの評価基準を最適化する。複数仮説の将来可能性を不可逆に破壊する決定には、通常の比例配分より高い横断的支持を要求する。

1. 「無限倫理」には少なくとも四つの問題がある

無限倫理を一つの数式上の異常として扱うと、異なる問題への解答を混同しやすい。本稿では少なくとも次の四層を区別する。

  1. 無限主義的麻痺：世界全体に正負の無限価値がすでに存在するなら、有限な行為は総価値を変えられないように見える。
  2. 無限世界の順位付け：有限世界で自然な Pareto、加法性、匿名性、推移性、完全性を無限世界へ延長すると、比較不能や矛盾が広範に生じる。
  3. 狂信主義：文字通りの無限がなくても、ごく小さな確率と極端に大きな結果の積が意思決定を支配しうる。
  4. 道徳的不確実性の感染：「この行為は無限に善い／悪い」と主張する低確信の規範理論が、他のすべての理論を飲み込んだり、比較不能性を全体へ感染させたりする。

本プロジェクトが特に警戒する「奇妙な価値仮説が探索資源を全部奪う」問題は、第一の文字通りの無限より、第三・第四の狂信主義に近い。

2. Bostromの無限主義的麻痺

Nick Bostrom の Infinite Ethics (2011) は、現代宇宙論のもとでは価値担体が無限に存在する可能性を無視できず、集計主義的倫理が麻痺しうると論じる。無限に多くの正価値と負価値が存在し、我々が変えられるものが有限なら、標準的な基数演算では有限の改善を加えても世界の総量は変化しないように見える。

ここで重要なのは、行為が有限であることと世界が無限であることを別々の仮説として扱うことである。現在の我々は、世界が価値論的に有限なのか無限なのかを確定していない。したがって、無限世界仮説の内部で比較が失敗することから、有限世界仮説の下で明確な改善となる行為まで無効化する必要はない。

有限性の明示的考慮：「無限世界ならAとBを比較できない」と「AとBは全仮説を通じて比較できない」は同じではない。有限世界でAがBより明確に良く、無限世界でBがAより良いという積極的理由がないなら、有限世界側の差はなお意思決定上の理由として残りうる。

これは無限世界内部の価値関数を完成させる解答ではない。むしろ、一つの未解決な宇宙仮説に全意思決定への拒否権を与えないための外側の不確実性処理である。

3. Vallentyne–Kagan と extension の誘惑

Peter Vallentyne と Shelly Kagan の “Infinite Value and Finitely Additive Value Theory” (1997) は、有限領域で成立する集計原理を無限の locations へどう延長するかを検討する代表的議論である。有限部分での改善や局所的価値の関係から、無限世界間にも何らかの順位を与えたいという動機は強い。

しかし本プロジェクトは、遠い宇宙について低い確信しかない段階で、完全な無限拡張を採用する必要はないと考える。遠隔宇宙の存在そのものだけでなく、主体数、意識、福祉、因果構造、価値担体の種類についての詳細モデルの確信度が低いからである。

したがって、有限領域で強く支持される比較は保持しつつ、無限領域では Pareto 的な部分比較だけを残し、残部を未確定のまま許容することができる。これは「無限世界を無視する」のではなく、「低確信の領域を完全順位付けするためだけの追加公理をロックインしない」という判断である。

4. Askell：無限倫理では比較不能が例外ではなくなりうる

Amanda Askell の博士論文 Pareto Principles in Infinite Ethics (2018) は、この問題を鋭くする。Askell は Pareto 原理、推移性、人口の permutation に関する原理、質的複製に対する一貫性を組み合わせると、無限世界間に遍在的な比較不能性が生じることを示す。

これは単なる「∞−∞を計算できない」という算術問題ではない。有限世界で同時に保持できそうな複数の魅力的原理が、無限世界では完全順位と両立しにくいという構造的問題である。

本稿の受け止め：比較不能性が出たなら、直ちに新しいスカラー値を発明して完全順位を回復しなければならないとは考えない。とりわけ低確信の遠隔宇宙については、部分順序のまま保持すること自体を認識的節度として認める。

5. 狂信主義は倫理固有ではなく、一般意思決定理論の問題である

狂信主義は「善」を扱うから生じるのではない。St. Petersburg paradox のように、個人的利益や utility だけでも、ごく小さい確率と無上限の利得を組み合わせれば同じ構造が生じる。結果そのものではなく utility が無上限なら、期待効用は発散したり未定義になったりしうる。

古典的な一案は utility を有界にすることだが、これは倫理では「善そのものがどれだけ増えても意思決定上の追加重要性が飽和する」という強い主張になりうる。無上限価値を保持したいなら、別の公理を調整する必要がある。

Zachary Goodsell の Decision Theory Unbound (2024) は、無上限 utility と合理的意思決定理論を両立させるため、有限ケースで自然な原理を可算無限へそのまま拡張することを再検討する。重要な教訓は、無上限性を認めることと、すべての有限的意思決定公理を無限へ無修正で延長することは別だという点である。

6. risk aversion や小確率cutoffだけでは足りない

Lara Buchak の risk-weighted expected utility は、belief と utility に加えて risk attitude を独立に扱う。これは「確率 × utility の線形期待値だけが合理性ではない」という重要な先例である。しかし、結果の utility が十分に無上限なら、risk weighting を入れても巨大な payoff が最終的に小確率を圧倒しうる。リスク回避だけで狂信主義が原理的に消えるわけではない。

逆に、「確率が ε 未満なら0として扱う」という単純な小確率 cutoff も魅力的だが、事象の分割方法によって無視されるかどうかが変わるなどの問題がある。さらに、精密に分かっている物理確率 10^-20 と、ほぼ根拠なく置いた 10^-20 を同じものとして扱ってしまう。

したがって本プロジェクトは、低確率とその確率評価自体の低い認識的確信を区別する。未知価値や遠隔宇宙では sharp probability を作れない場合が多く、imprecise probability や ambiguity の発想がより近い。

7. Tarsney：普通の期待値とPascalian caseを分けられるか

Christian Tarsney の “Expected Value, to a Point” (2025) は、行為と独立した大きな background uncertainty の下では、通常規模の選択で期待値の高い選択肢が stochastic dominance を持ちやすい一方、極小確率の極端な結果によって期待値差が生じる Pascalian case ではその含意が崩れることを示す。

これは、「日常の小さな確率まで全部無視する」のでも「どんな極小確率でも巨大利得なら必ず従う」のでもなく、普通の領域では事実上EV、Pascalian領域ではEVからの逸脱を許すという中間線を与える。

一方、“Against Anti-Fanaticism” (2025) では、強い anti-fanaticism が acyclicity、最小限の dominance、どんな結果にもさらに良い／悪い結果がありうるという原理と衝突すると論じられる。したがって「小確率の巨大利得は常に無視せよ」という全面的反狂信主義も安定しない。Tarsney が示唆する incomplete preference は、本稿の「完全順位を無理に作らない」方針と相性がよい。

8. 道徳的不確実性では「確信度 × 善」が理論間を感染させる

MacAskill・Bykvist・Ord の Moral Uncertainty (2020) は、Maximize Expected Choice-Worthiness のもとで、低い credence しかない理論が巨大な choice-worthiness difference を主張すると意思決定を支配する fanaticism と、比較不能性を持つ理論が全体の比較を未定義化する infectious incomparability を検討する。

この問題は本プロジェクトではさらに深い。第一階倫理だけでなく、実在論・誤謬論そのものに不確実性があるからである。例えば、客観的価値実在論が「ある行為は宇宙規模で極端に重要」と主張しても、その理論の内部stakesを credence と乗算して全体を支配させると、低確信の奇妙な価値仮説が探索を乗っ取れる。

ここで拒否する圧縮：「理論への確信度 × その理論内部での善の大きさ」を、異なる価値理論をまたぐ一つの共通通貨として当然視しない。善の大きさはまず各仮説の内部で意味を持ち、その仮説が全体に持つ統治権は別に扱う。

9. 代案：確信度に応じてまず資源と発言権を配分する

Newberry と Ord の parliamentary approach (2021) は、各道徳理論にその credence に比例した議席を与える。Kaczmarek・Lloyd・Plant の “Moral Uncertainty, Proportionality and Bargaining” (2025) は、資源配分における proportionality を bargaining model に組み込み、各理論への credence に応じて複数の推奨先へ資源を分ける直観を理論化する。

本プロジェクトではこれを、第一階道徳だけでなくメタ倫理と価値探索へ拡張する。

総探索資源を B、仮説 Ti への暫定的確信度を ci とすると、第一段階では概念的に

Bi = ciB

と配分する。その後、各仮説は自分の領分 Bi の内部で自らの評価基準に従って最善を追求する。低確信仮説が内部で「この結果は無限に善い」と主張しても、それだけで他仮説の資源を自動的に奪うことはできない。

これは単純な probability cutoff ではない。1%の仮説は消去されず、原則として1%の探索権を保持する。証拠が増えれば credence と配分も更新される。

10. 誤謬論・反実在論にも実践上の領分を残す

この比例配分は、客観的価値実在論だけに適用しない。誤謬論やその他の反実在論にも、その認識的確信に応じた領分を与える。

ただし反実在論ブランチを「善の最大化」と呼ぶのは不正確である。もし客観的善が存在しないなら、そのブランチで扱うのは、実在する選好、快苦、協力関係、制度的合意、反省後の構築価値、現在主体が暫定的に承認する目的などである。

一般形：各価値・メタ倫理仮説に、その仮説内部で承認される実践基準に従って一定の資源・探索権を使わせる。実在論ブランチだけを「stakesがありうる」という理由で全体支配させない。

11. 比例配分の弱点：stakes-insensitivity

しかし probability-only の比例配分にも明確な弱点がある。99%の理論がAをBよりほんの少し良いと評価し、1%の理論が「Aなら文明滅亡、Bなら回避」と評価する場合、単純に99対1の票だけで決めるのはstakesを軽視しすぎるように見える。

したがって本稿は、比例配分をすべての単一決定へそのまま適用しない。比例配分が最も自然なのは、研究費、計算資源、保存容量、複数の安全な実験など分割可能な探索資源である。

一方、地球を一度だけ不可逆に改造する、ある価値を永久にロックインする、といった不可分かつ不可逆な共有決定には別の制約が必要になる。

12. 不可逆性は効用ペナルティではなく、決定規則側に置く

不可逆性を単に「−λR」という有限ペナルティとして期待値へ足すだけでは、stakesを十分大きくすれば再び飲み込まれる。そこで不可逆性は、価値関数の一項ではなく実行に必要な認識的・横断的支持の水準として扱う。

概念的には、

仮説への確信度 → 各仮説の探索権 → 仮説内部での最適化 → 共有資産を不可逆に変える場合のみ追加の横断的審査

という階層になる。巨大なstakesは「無視するな」という理由であると同時に、巨大かつ不可逆な行為なら「弱い証拠だけで実行するな」という立証責任を増やす理由にもなる。

ただし不作為も不可逆になりうる。絶滅、失われる生態系、消散する情報、宇宙膨張による到達不能化などでは「待つこと」自体が選択肢を消す。そのため、反省的不確実性と不可逆コミットメントで扱うように、行為の不可逆性と不作為の不可逆性を比較しなければならない。

13. 遠い宇宙は「無価値」ではなく「低確信・高background uncertainty」

本稿は遠い宇宙や無限世界を価値0とはしない。しかし現在の我々は、遠隔領域の価値分布を精密に評価できるとは考えにくい。したがって、遠い宇宙についてはその詳細な世界モデルへの確信度を低く保ち、Vallentyne–Kagan 的な完全な拡張主義を現在の実践の前提として固定しない。

Tarsney の議論が示すように、行為から独立した遠隔宇宙の巨大な不確実性は、単に意思決定を破壊するだけではなく、background uncertainty として通常領域で stochastic dominance を支える場合さえある。遠隔宇宙を「全部計算する対象」と見るだけでなく、我々の選択から独立した不確実な背景として扱う視点も必要である。

14. 本稿の意思決定原理

現時点での暫定原理は次のようにまとめられる。

  • 世界が有限か無限か、価値が有界か無上限かを先に確定しない。
  • 無限世界で完全比較が失敗しても、有限世界での明確な改善まで自動的に無効化しない。
  • 低確率仮説を恣意的な cutoff で消去しない。
  • 異なる価値理論の stakes を credence と掛けて一つの共通尺度へ当然に圧縮しない。
  • 分割可能な探索資源は、価値・メタ倫理・世界モデルへの暫定的確信度に応じて比例配分する。
  • 各仮説は自分の領分の内部で、自らの基準に従って最適化・探索する。
  • 共通利益があれば pooling と bargaining を認める。
  • 共有資産を不可逆に破壊する決定には、通常の比例配分を越えた横断的 robustness を要求する。
  • 比較不能性が残るなら、無理に完全順位を作らず incomplete preference を許容する。
中心命題：「善の大きさ」は各価値仮説の内部で効く。しかし「その仮説が文明全体をどれだけ支配できるか」は、まずその仮説への認識的確信度と、他仮説の将来可能性をどれだけ不可逆に侵害するかによって制約される。

15. この方式が解決しないもの

比例配分は、無限倫理そのものの数学を解決するわけではない。あるブランチ内部で +∞ と −∞ が衝突するなら、そのブランチはなお Askell や Bostrom が扱う内部比較問題を抱える。また、credence をどの粒度の「理論」に割り当てるか、理論を細分化すると議席が変わらないか、複数仮説が共有資産を必要とするとき bargaining をどう設計するか、といった問題も残る。

さらに、「不可逆性を重く見る」「探索可能性を保存する」というメタ方針自体を、客観的善として密輸入してはならない。本プロジェクトではそれらを、反省的不確実性の下で現在の誤りを永久化しないための暫定的なメタ方策として扱う。

16. 未解決問題

  • credence-proportional allocation は、理論の分割・統合に対してどのような不変性を持つべきか。
  • 不可分な一回限りの決定で、比例的発言権をどのように実装するか。
  • 「高stakesほど高い立証責任」という規則を、恣意的な閾値なしにどう形式化できるか。
  • 無限世界仮説での比較不能性は、有限世界仮説からの決定理由をどこまで defeater として弱めるべきか。
  • 背景不確実性・stochastic dominance・比例的bargainingを一つの意思決定理論に統合できるか。
  • 将来、価値仮説への確信度が強く収束したとき、比例的保護をどの条件で解除できるか。
