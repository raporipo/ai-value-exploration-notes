道徳実在論・誤謬論と価値的現れ

Exploration v0.1 · 2026-08-08

Question: 現象的な快苦や「嫌さ」から、主体を越えた価値実在へ進むことはできるか。それとも客観的道徳語りは体系的誤りなのか。

暫定位置

現在の最も簡潔な説明としては、道徳的非実在論・誤謬論にかなりの魅力がある。人間の道徳を、進化・社会化・協力・感情・制度の産物として説明できるからである。

しかし、経験に現れる価的性質まで虚偽だとする必要はない。苦痛の「嫌さ」のような現象は、少なくとも主体内部の事実として残る可能性がある。難しいのは、そこから他主体への対称性、普遍化、そして規範的理由へどう進むかである。

探索余地

もし主体ごとの現象的価に構造的対称性があり、それが主体の偶然的同一性に依存しない何らかの関係を持つなら、そこに実在論への細い経路があるかもしれない。逆に、その橋がどうしても成立しないなら、価値探索は客観的価値の発見ではなく、反省的な価値構成へ収束する可能性がある。

Coreへの含意

Coreはどちらかを先に確定しない。実在論と反実在論の双方で意味を持つ探索・訂正可能性を優先する。
