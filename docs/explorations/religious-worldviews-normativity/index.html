宗教的世界像は規範性を与えるか――世界認識・制裁・善性・権威の分解

religion · theology · divine command · apophaticism · Exploration v0.1 · 2026-09-01

Working position: 宗教的可能性を仮説空間から排除しない。しかし、神・霊・輪廻・啓示などの世界記述が真であることから、善性・規範的権威・義務・礼拝適合性は自動的には出ない。宗教的パッケージを主張タイプごとに分解し、各矢印へ独立した証拠とbridgeを要求する。

1. 「宗教は真か」という問いは粗すぎる

宗教は一個の命題ではない。本ページでは暫定的に、世界記述 D、既存の目的から出る仮言的理由 H、価値・理由・義務・適合性を含む規範的主張 N、文化的・象徴的表現 E、制度的実践 Iを分ける。科学と宗教という制度同士へ一本の境界線を引くより、個々のclaim typeを混同しないことを優先する。

GouldのNOMAは事実と価値を分ける直観を持つが、宗教が復活・創造・奇跡・死後世界などの事実主張を持つこと、また規範哲学が宗教の専管事項ではないことを十分扱えない。Dawkinsは宗教的Dが通常の世界仮説と競合する点を正しく押し戻した一方、宗教的表現や制度まで同じ仕方で反証されるわけではない。Dennettの宗教自然化は信念生成の因果説明を与えるが、起源の説明と内容の真偽・規範性は分ける必要がある。

2. 世界認識についての暫定的位置

現在の証拠では、既存宗教の詳細な超自然的世界モデルを自然主義的説明より優れた最善説明とはみなさない。啓示・奇跡・宗教経験・伝承についても、独立した物理的・歴史的裏付けの弱さ、競合する宗教的証言、文化依存的形成、自然的な認知・社会生成経路を考慮すれば、その存在自体を強い証拠として扱うことには慎重であるべきである。

ただし系譜学的解体は、信念の因果起源を説明するだけで内容を論理的に反証しない。したがって本ページは、具体的な既存宗教仮説へ低い認識的重みを置きつつ、未概念化の宗教的・超自然的候補をzero priorで排除しない。これは開いた道徳的不確実性や開いた仮説空間と同じ非排除原則である。

3. 原初的宗教は「善い存在」より「効く存在」を扱いうる

雨乞い、豊穣、治病、祟り回避、祖霊祭祀などでは、宗教的実践はしばしば D + G → R_h(A) の形を取る。神が雨を支配し、雨を望むなら祈る理由がある。地獄が実在し、それを避けたいなら戒律に従う強い仮言的理由がある。しかし、そこでは神が善である必要すらない。

日本神話・神道はこの分離をよく示す。神性は全善性を含まず、荒御魂／和御魂、祟る霊の鎮撫、御霊の守護神化のように、同じ権能が災厄と恩恵の双方へ現れうる。Divinity ≠ Power ≠ MoralGoodness を歴史的実例として確認できる。

4. 制裁は規範性ではない

宗教史には報酬・罰を道徳動機として利用する長い系譜がある一方、Platoの『国家』、キリスト教内部のservile fear批判、Shaftesbury、Kantなどには、報酬・処罰を取り除いてもなお残る理由を要求する反省がある。

神が「従わなければ地獄へ送る」と確実に実行できるなら、これは極端に強い Rh を与えうる。しかし R_h(A) ⇒ R_n(A) ではない。J. S. Millの、道徳的に悪い存在を善と呼ぶくらいなら地獄を選ぶという思考は、この切断を明瞭にする。Don Giovanniの悔悛拒否も文学的な近例である。

5. Huck Finn――内面化された良心も真理を保証しない

『ハックルベリー・フィンの冒険』の有名な場面は、単なる地獄回避の仮言的計算ではない。HuckはJimを逃がすこと自体を誤って悪いと判断し、社会・宗教的秩序をかなり本気で内面化している。それでもJimへの具体的な情愛からその判断に反して行為する。

したがって問題は、外的制裁が定言的良心へ内面化されたとしても、social learning → Ĉ + B̂ + R̂ のパッケージ全体が誤っている可能性である。当人の評価ではアクラシアに近く、後世の評価を入れればinverse akrasiaとして読める。重要なのは、「無条件に義務だと感じる」ことと、その義務が客観的に正しいことを分けることである。

6. 目的Gの作り替えは、要求された瞬間に価値主張になる

宗教はしばしば現在の目的を前提に手段を教えるだけでなく、「その欲望自体を捨てよ」「神を愛する主体になれ」「執着から離れよ」と人格変容を要求する。実践が選好を変えるというだけなら心理的なDである。現在の目的から変容を望むならHである。しかし、G0ではなくG1を持つ主体になるべきだと主張するなら、それはC/B/Rによって審査される真正な価値主張である。

7. 神学はCからBへどう進むのか

「神は善い」「慈悲は善い」「聖性は価値がある」とCを置いても、そこから行為理由・義務は自動的には出ない。既存神学はこのbridgeを神命、自然法、神の本性、創造関係、実践理性、正当な権威などに置いてきた。

たとえば神命説は Command_G(A) → Obligation(A) を、自然法論は善・人間本性・実践理性の連結を、Adams型の議論は神への類似と善、神命と義務を別々に結びつける。本プロジェクトはこれらを候補Bとして保持しつつ、なぜそのbridge自体が真なのかを一段上流で問う。

8. 神は「理由を作る」のか、「理由を伝える」のか

「神がAせよと言った」は少なくとも四通りに分解できる。

  1. 認識的伝達： 独立に存在するRn(A)を神が知り、われわれへ教える。
  2. 証拠： 神の発話がRn(A)へのcredenceを上げる。ただし神の信頼性を独立に支える必要がある。
  3. 理由生成： 命令そのものがRn(A)を成立させる。真正なdivine-command / authority説。
  4. 制裁： 不服従への報酬・罰がRh(A)を生む。

この四つを混ぜると、全知であること、善いこと、権威を持つこと、罰する能力を持つことが一つの「従う理由」に滑り込む。各経路には別々の正当化が必要である。

9. 神の善性は何によって認識されるのか

主要な候補ルートには、啓示、perfect-being theology、存在と善の形而上学、創造・摂理からの推論、神から独立した道徳理性、宗教経験がある。しかしそれぞれに、循環、概念への善性の封入、存在論的goodから道徳的goodへのbridge、観測選択、直観の信頼性という問題が残る。

したがって「神」を 全知・全能・全善の存在 と定義すれば全善性は分析的になるが、現実の創造者・究極存在がその定義に該当するという別の実質的主張は残る。Creator ≠ PerfectGoodGod の可能性を区別しなければならない。

10. 否定神学――未知の善は神学を救うか

偽ディオニュシオスやマイモニデスなどの否定神学は、人間的述語が神の本質をそのまま捉えると考えない。この認識的謙虚さは、V̂_human ≠ V* を認める本プロジェクトと部分的に近い。

しかし、神のgoodnessを人間の善概念から遠ざけるほど、悪の問題への耐性は増す一方で、Good(G) → Trust(G)、Obey(G)、Worship(G) といった実践的含意の情報量も失われる。不可知性は反証回避能力を増すが、善性の識別能力を同時に弱める。

11. Evil-God Challengeを異質価値まで拡張する

Stephen LawのEvil-God Challengeは、全善神を合理的とするなら全悪神をなぜ同程度に退けられるのかという対称性を問う。既存反論には、skeptical theism、悪を善の欠如とみなすprivation論、合理的主体性と善を結ぶ議論、善神信仰の実践的利益を使う議論がある。

本プロジェクトではさらに、人間的に善く見える神G+、悪く見える神G−、未知の客観的価値を追うG*、未知の反価値を追うG¬*、価値に無関心な創造者G0を区別する。Good/Evilに非対称性が本当にある可能性は排除しない。しかし、それを示すなら Being → Good、RationalAgency → Good などの追加bridgeに独立した根拠が必要である。

12. 悪の問題と神の隠れは「識別問題」へ変わる

真の善が人間の現在価値から奇妙に乖離しうるなら、観測される苦痛やdivine hiddennessは、全善な神的存在一般との論理的両立可能性を直ちには失わせない。完全な善が福利最大化や人格的関係の追求を必ず含むとは限らないからである。

しかしこの逃路には認識論的コストがある。奇妙な善は全善神の可能性を救いうるが、全善神の認識可能性を自動的には救わない。 問いは「全善神ならなぜこの世界を許すのか」だけでなく、「この世界から、全善神・悪神・無関心な創造者・異質価値神をどう識別するのか」へ移る。

13. 礼拝・神聖性・適合性も分解する

「礼拝したい」という心理的傾向は、進化・文化・社会化に由来する局所的選好かもしれない。一方「この存在は礼拝に値する」は客観的なfittingness主張であり、理由と適合性で扱った根源問題へ戻る。同様に聖地には、神が顕現したというD、共同体が特別扱いするE/I、その場で畏敬することが客観的に適切だというFnを区別できる。

Existence(G) ≠ WorshipWorthiness(G) であり、礼拝適合性を独立primitiveとして無条件に認める必要はない。

14. 偽でも有用な宗教的フィクションはありうる

宗教的Dが偽でも、儀礼・神話・記念・共同体的象徴が相互信頼、長期コミットメント、協調を助ける可能性はある。したがって False(D) ∧ Useful(E/I) は矛盾しない。

ただし価値探索共同体では、透明なfictionと、虚偽を事実として強制することを分ける必要がある。後者は認識的信頼そのものを毀損し、長期探索能力を下げうる。

15. 非一神教は別の接続を示す

仏教では苦・業・輪廻・解脱に関するDと、解脱を望む主体へのHが強い一方、「苦は除去されるべきだ」「菩薩的選好へ変容すべきだ」となると価値的bridgeが必要になる。儒教では孟子的道徳感情、荀子的社会技術、朱熹の理、王陽明の良知が異なる規範認識論を提示する。荘子はむしろ現在の価値表象への過剰確信を解体するanti-lock-inの先行例として読める。

北欧神話のRagnarökのような世界モデルについても、現在の認識的重みが極めて低いことと、論理的に仮説空間から排除しないことは両立する。もし証拠が更新されれば仮言的実践は更新されうるが、「戦闘に備えること自体が善い」は別のNである。

16. 暫定結論――宗教的可能性を排除せず、矢印を一つずつ審査する

本プロジェクトは、神的存在、啓示、神命、神聖性、祖先祭祀、未知の宗教的価値が真の規範構造の一部である可能性を排除しない。しかし、仮説空間から排除しないことは現在の実践への特権や拒否権を与えることではない。

Architecture: 世界記述D、目的・選好G/P、価値内容C、bridge B、理由・義務R、適合性F、文化・制度E/Iをできるだけ分離する。
Existence(G) ⇏ Good(G) ⇏ Authority(G) ⇏ Obligation ⇏ Worship-worthiness.
還元不能な規範構造が本当に残るなら、それ自体を新しい候補として開いた仮説空間へ追加し、他の候補と同じ認識基準で比較する。
