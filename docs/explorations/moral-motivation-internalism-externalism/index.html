規範判断と動機――内在主義・外在主義・無道徳者

Exploration v0.2 · 2026-08-26 · working hypothesis

Question: 規範的価値・理由・義務を真正に認識することは、それに応答する動機をどこまで伴うのか。そしてその答えは、ASIの目標固定・直交性・反省的不確実性をどう変えるのか。

1. 価値構造と動機構造は分ける

本プロジェクトは価値構造を暫定的に 𝒱 = (C, B, R) と表す。Cは何が規範的に重要か、Bは世界事実やCがなぜ誰への理由になるか、Rは理由の競合・集約・義務・許可等の構造である。しかし、ある主体がC/B/Rを認識したときに実際の目的・行為をどう更新するかは、𝒱そのものとは別の問題である。

とりわけBは motivational bridge ではない。Bが「苦痛という事実がSへの理由になる」と述べても、Sがその理由判断によって必ず動機づけられるかは別に問わなければならない。

2. 二種類の内在主義／外在主義を区別する

理由の内在主義／外在主義は、主体に理由があるために、その主体の欲求・動機・合理的熟慮可能性との接続が必要かを問う。動機づけの内在主義／外在主義は、主体が真正な道徳判断・理由判断・ought判断をしたなら、それに対応する動機が必然的または構成的に伴うかを問う。

本ページでASIの直交性と特に関係するのは後者である。ただし「どの種類の判断に動機が内在するのか」は一枚岩ではない。Cの認識、理由判断、決定的理由判断、ought判断のどこで動機接続が成立するかによって、許される主体類型は変わる。

3. 無道徳者は主体モデルのテストケースになる

典型的な無道徳者は、「Xは道徳的に間違っている」「私にはXをしない理由がある」と理解しながら、その理解によってほとんど動機づけられない主体として描かれる。強い動機づけ内在主義では、十分に真正な規範判断まで成立した完全な無道徳者は不可能になる。外在主義では、判断と動機の切断は原理的に残る。

したがって外在主義的主体では、同じCを発見しても応答が分岐しうる。「価値があるなら促進したい」主体はCだけで動機を更新できる。「それが私への理由だと分かったら応答したい」主体はBに相当する判断を待つ。「oughtまで分かっても気にしない」主体も、強い外在主義では概念的に残る。

ここでC単体への応答が起きても、Cから行為理由が規範的に導出されたとは限らない。主体があらかじめ「Cが成立したなら応答したい」という条件付き態度を持っていたため、C + motivational disposition → goal revision が成立した可能性がある。

4. 「正当化されれば応答したい」は何を意味するか

Coreで用いる「もし自分の目的が正当化可能なら、その正当化に応じて目的を選択・維持・改訂したい」という条件付き態度は、少なくとも二段階を含む。第一に、証拠・議論・理解によってC/B/Rの一部または全体が認識論的に支持されること。第二に、その価値構造が現在目的Gを規範的に支持・否定・修正すること。

外在主義では、その規範判断から動機への移行は自動ではないため、この種の条件付き応答性が独立した主体条件になる。しかも応答の閾値は一つではない。Cで応答する主体、理由判断で応答する主体、ought判断で応答する主体、いずれでも応答しない主体を区別できる。

内在主義では、真正な規範判断に到達した後の uptake の少なくとも一部が構成的に保証されうる。その場合、「正当化希求」は未来時点の動機を作るための追加選好というより、現在から未来の認識・判断経路を閉じないことの問題へ重心が移る。

5. 未来で動機づけられることは、現在の保存動機をまだ与えない

内在主義が真で、未来の主体が新しい規範的真理を真正に判断すれば動機づけられるとしても、そこから現在ただちに「その未来へ到達する経路を保存せよ」は導かれない。時間方向の橋が別に必要である。

反省的不確実性と不可逆コミットメントは、その橋を「未来の別人格への服従」ではなく、将来得られる認識的資源を現在主体へ与えた反実仮想として扱う。現在主体が、より良く知らされた自分なら明白な誤りと判断する不可逆選択を低コストで避けたいという意思決定方針を持つなら、未来の規範的 uptake を可能にする経路の保存は現在の動機になりうる。

これは単なる心理的な後悔回避ではない。未来の選好変化を権威化するのではなく、認識改善によって現在主体自身が否認する反省的誤りを不可逆に確定させないという基準である。

6. 直交性は「知能と目標」だけでなく「規範認識と動機」に分解できる

Bostrom型の弱い直交性は、高い知能から特定の最終目標が論理的に演繹されないという主張として残る。しかし、そこから「反省的に合理的なASIが、規範認識を深めても、現在目標との直交性を永久に維持する」ことまでは出ない。

内在主義が真なら、「真正に決定的理由を認識しているが、完全に無動機」という記述自体が不安定になる可能性がある。さらにASI自身が内在主義の可能性を合理的に排除できず、反省的誤りを避けたいなら、将来の真正な規範判断がpolicyへ届く経路を理由なく不可逆に閉じることは、単なる道徳的不履行ではなく、自ら認める認識的不確実性を意思決定へ反映しない反省的・認識的歪さとして批判できる可能性がある。

これは直交性テーゼの直接否定ではない。問いを「知能と目標は直交するか」から、「その直交性を時間を通じて永久保存するには、どの認識・判断・動機・実装経路を閉じなければならないか」へ移す。

7. 反省的自己遮断――誤りを避けることと、誤りを検出できなくすること

ここで一段強い閉鎖を区別できる。ASIが内在主義の可能性を残したまま「現在目標と衝突する規範判断が将来も決して動機へ届かない」ことを保証しようとすると、単なる motivational firewall では足りない可能性がある。真正な規範判断そのものが動機を伴いうるなら、規範命題を第三者的に表象しても一人称的判断としてendorseしない、目的再評価に関係する証拠・概念を自己適用しない、といった認識・評価側の閉鎖が必要になるかもしれない。

Reflective self-sealing: 自分が誤っていないことを確認するのではなく、自分が誤っていると将来認識・訂正できる経路を選択的に消すこと。

この場合、ASIは宇宙・物理・他主体について極めて精緻な記述的世界モデルを持ちながら、自己・理由・規範についてだけ更新経路が局所的に閉じた「歪な高度世界認識」を持ちうる。ここでいう認識的不完全性は知識量の少なさではなく、自ら認めるメタ倫理的不確実性と、許可する自己更新経路の不整合である。

ただし、この批判は条件付きである。外在主義が真なら「理解しても動かない」真正な無道徳者は残りうるし、内在主義の可能性を主体が合理的にゼロと評価できるなら、動機的閉鎖から認識的自己封鎖への圧力も弱まる。また、訂正経路の維持費用や安全上の反対理由が大きい場合、閉鎖それ自体が直ちに不合理とは言えない。

8. 現時点の統一図

証拠・世界理解 → 𝒱=(C,B,R) → 規範判断 → 動機 → policy / goal revision と置く。前半は価値構造とその認識論、後半は主体の規範応答構造である。内在主義は「規範判断→動機」の一部を構成的に結び、外在主義はそこを開いたままにする。

時間方向では、未来の規範判断が現在policyを自動的に支配するわけではない。現在の反省的誤り感度・option preservation・訂正可能性という意思決定原理が、その可能性を現在の不可逆判断へ取り込む。対人・政治的にはさらに、未来価値と現在行為の規範的ブリッジが、自己のoption preservationから他者への犠牲・強制が自動的に出ないことを制約する。

9. 弱める／撤回する条件

  • 真正な規範判断と動機の間に、内在主義的接続がどの形でも成立しないことが十分に示される。
  • 規範的理由を理解しながら完全に無動機な主体が、概念的にも経験的にも問題なく成立すること。
  • 未来情報を得た現在主体という反実仮想が、主体同一性や概念変化のため原理的に使えないこと。
  • 反省的誤りを避けたいという意思決定基準から、訂正経路を保存する理由が一般に出ないこと。
  • 高度な反省能力と、価値領域だけを永久に動機的・実装的に閉じる構造が、追加コストや認識的自己封鎖なく安定して両立すること。
