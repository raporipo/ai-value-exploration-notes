人口倫理と将来の主体

Exploration v0.1 · 2026-08-08

Question: 人間、AI、人工意識、改変された主体を含む将来世界で、「誰を存在させるか」は価値探索そのものをどう変えるか。

価値の担い手を固定できない

人口倫理では、既存主体の厚生だけでなく、将来どの主体を生成するかが問題になる。AI時代には主体の種類そのものを設計できる可能性があるため、この問題はさらに強くなる。

異なる認知構造や現象的経験を持つ主体が、現在の人間にはアクセスできない価値的事実を捉える可能性があるなら、主体生成は単なる人口数の問題ではなく、探索空間の設計でもある。

危険

しかし「多様な主体を作れば探索が進む」と単純化すると、苦痛を持つ主体の生成や、価値探索のために主体を道具化する問題が生じる。主体的探索可能性を守ること自体が、生成される主体への扱いを正当化するわけではない。

未解決

  • 潜在的主体への配慮は、存在前からどこまで成立するか。
  • 人工意識の生成を探索手段として扱ってよい条件は何か。
  • 主体数と主体種類の多様性をどう区別するか。
