Foundational thesis

Decision Policy — Acting Under Incomplete and Revisable Values

Working translation v0.1 · 2026-09-07

Thesis: When states, probabilities, value scales, and comparison structures are adequately represented, this project may use expected-utility maximization or other appropriate optimization strongly. When the value scale, intertheoretic comparability, candidate value space, or even the future evaluator itself remains incomplete, incomparable, unconceived, or revisable, it should not manufacture false precision and force the problem into a single scalar objective. Decide strongly where comparison is justified; respond to the remainder with robustness, value of information, reversibility, option value, adaptability, and preserved corrigibility. Strong present action can therefore coexist with future value revision.

1. Scope — choice rather than belief

Epistemic Policy concerns what to believe, how strongly to believe it, and which world models, hypothesis spaces, and epistemic methods to adopt. This page concerns which action, policy, or allocation to choose given that epistemic state and the agent's current value state. Value theory asks what counts as a value or reason; decision theory asks how to act from such inputs when they are incomplete.

Decision theory should therefore not be used as a substitute for value discovery. The fact that a preference can be represented by an expected-utility function does not establish that the preference is normatively correct. Likewise, internal coherence of a decision rule does not make the rule an ultimate normative principle.

Boundary: epistemic state + value state + feasible actions + constraints → decision policy → action. Uncertainty does not imply practical paralysis.

2. Baseline case — do not reject expected utility

If states s, actions a, subjective probabilities P(s), and a sufficiently cardinal utility U(a,s) are available, the familiar rule EU(a)=Σs P(s)U(a,s) is a powerful decision criterion. Representation theorems in the von Neumann–Morgenstern and Savage traditions clarify conditions under which preferences can be represented as expected-utility maximization.

The issue is not “EU or anti-EU.” If probabilities and value scales are sufficiently trustworthy and differences among outcomes are commensurable on the relevant scale, there is no reason to avoid expected utility or ordinary optimization. The real question is whether the agent is entitled to use that numerical representation.

The standard model presupposes an adequately represented action space, state space, outcome mapping, probability model, value scale, and comparison or aggregation rule. The project is mainly concerned with cases in which some of these are unsettled.

Baseline rule: sufficiently represented decision model → use the strongest justified optimization available.

3. How much quantification is justified? — representational entitlement

Assigning numbers does not license arbitrary arithmetic. If only ordinal ranking is justified, A > B may be meaningful while U(A)-U(B) or cross-person averages are not. Interval structure, ratio structure, interpersonal comparability, and intertheoretic comparability each require additional assumptions.

Nor must rational preference always be complete. Some pairs may be genuinely unresolved rather than tied. Treating incomparability as indifference creates trade-offs that the current value model does not support.

Value representation may therefore be scalar, interval- or set-valued, multi-attribute, ordinal, partially ordered, or explicitly incomparable. Even an additive multiattribute form such as V(a)=Σi wi vi(a) requires substantive independence and trade-off structure rather than following automatically from “multiple values exist.”

Representational rule: Quantification is conditional on representational entitlement. Do not invent more cardinality, comparability, or aggregation than the current evidence and value structure support.

4. Represented value uncertainty — what if several theories are live?

Even when candidate value theories are already represented, simple expectation across them may be ill-defined. Credences in T1 and T2 do not suffice for P(T1)U1(a)+P(T2)U2(a) if the theories' choiceworthiness scales have independently arbitrary units. This is the intertheoretic comparability problem in the moral-uncertainty literature.

Where comparison is sufficiently grounded, expected choiceworthiness may be used. Where it is only partial, the agent may rely on dominance, shared anchors, partial ordering, or a family of value functions compatible with current judgments. In the spirit of Robust Ordinal Regression, if A is at least as good as B under every compatible model, that is a strong necessary preference; if A wins only under some compatible models, it remains merely possible.

Incomparability is therefore information about the current representation, not merely a failure to decide. The agent can use the comparable structure to narrow the choice set and then rely on robustness, information acquisition, and reversibility for what remains.

Represented uncertainty: uncertain theory ≠ automatically commensurable theory.

5. Unrepresented value — do not give an imaginary weight to an unknown theory

Bayesian Updating and Open Hypothesis Spaces argues that a hypothesis not yet present in the hypothesis space need not be a zero-prior hypothesis; its probability may simply be undefined in the current representation. Value inquiry has the same problem. A not-yet-represented V* outside the current candidate set 𝒱t should not be treated as a fictitious “unknown theory party” with, say, five percent of the current practical vote.

The possibility of unconceived value should primarily affect E (search for new value candidates), P (preserve the capacity to reassess), caution around irreversible acts, and future option value. Represented value uncertainty can directly inform first-order action comparison; unrepresented possibilities mainly constrain the openness of the decision architecture.

Open-value rule: unrepresented value possibility → exploration / preservation / optionality, not → fictitious scalar utility.

6. Do not force one decision rule onto every problem

The preceding sections motivate decision-rule pluralism. Use expected utility when probabilities and cardinal utilities are adequately available; use imprecise or robust rules when beliefs or utilities are set-valued; use dominance or partial orders when comparison is partial; use RDM or regret when the model itself is deeply uncertain; use VOI and real options when future information matters; use DAPP when adaptation through time matters; and use reflective policies when the value function itself can change.

This is not “anything goes.” A decision rule is constrained by the informational structure it presupposes. Stronger optimization requires stronger representational entitlement.

Method-selection rule: use no stronger decision rule than the currently justified representation supports.

7. E / P / X — three classes of action in value inquiry

Allocating Inquiry Under Unresolved Normative Uncertainty distinguishes E: active inquiry, P: preservation of inquiry options, and X: realization of present values. These should be understood as action classes, not three terminal goods. E raises information now; P keeps future information acquisition possible; X directly realizes what current live value models support.

Under resource constraints the agent must choose an allocation (Et,Pt,Xt). The allocation should change with justificatory relevance, value of information, irreversibility of inquiry opportunities, inquiry risk, opportunity cost in present value, and preservation cost. E/P/X are therefore policy variables, not fixed moral shares.

The E/P distinction is especially important. If active inquiry is dangerous or expensive while preservation is cheap, the agent may rationally pursue X strongly, retain P, and temporarily reduce E.

8. Deep uncertainty — prefer robustness when the model itself is fragile

When uncertainty concerns not merely parameter values but which futures are plausible, how causal models operate, or which outcome metrics matter, the problem enters the domain of Decision Making under Deep Uncertainty. Robust Decision Making (RDM) does not optimize for one best-estimate future; it runs candidate policies across many plausible futures, discovers conditions under which they fail, and iteratively redesigns them to reduce those vulnerabilities.

RDM should not be reduced to worst-case maximin. The point is not to optimize against the most extreme imaginable state, but to seek acceptable performance across a wide range of plausible world and, where possible, value representations, using satisficing, regret, multi-metric evaluation, and vulnerability discovery as needed.

Robustness rule: optimize when the model is adequate; stress-test when the model itself is deeply uncertain.

9. Should we seek more information? — VOI and the risk of inquiry

Active inquiry E is itself a decision. Value of Information (VOI) asks how much an agent should pay for information that may improve later choices, often by comparing the optimal expected value before and after receiving that information.

Value inquiry requires at least three extensions. First, inquiry may generate a new value model or comparison axis rather than merely reveal which known state obtains. Second, inquiry itself may be hazardous, as with dangerous experiments or high-capability AI. Third, inquiry can destroy subjects, samples, raw data, or institutional conditions needed for future inquiry.

Information is therefore not monotonically valuable. Decision relevance, expected epistemic improvement, inquiry cost, present-value opportunity cost, inquiry risk, and effects on future inquiry capacity all matter.

Inquiry rule: epistemic gain alone ≠ sufficient reason for active inquiry.

10. Irreversibility and the value of waiting — real options

When an investment or commitment is costly to reverse, can be delayed, and waiting is expected to bring information, not acting now can preserve a valuable option. Real-options analysis treats future opportunities to invest, expand, contract, switch, or abandon as options whose loss is part of the opportunity cost of irreversible action.

For this project, that idea can be extended into reflective option value. What is preserved is not merely the right of a future agent with the same utility function to react to better market information, but the possibility that a future evaluator with better value understanding or a richer comparison structure can choose again.

Waiting is not free. Present value may be lost; technical opportunities may disappear; competitors may move first; and inaction may itself create irreversible losses. Real-options work also shows that competition can erode the option value of waiting. The relevant comparison is therefore between the irreversibility of acting and the irreversibility of waiting.

11. Choose a pathway, not only a one-shot act — DAPP

Dynamic Adaptive Policy Pathways (DAPP) addresses deep uncertainty by committing to near-term actions while designing pathways for switching policies as observations change. It uses adaptation tipping points, signposts, and triggers to anticipate when a policy will no longer meet its goals and when another action should be activated.

This structure directly combines strong present action with future corrigibility. Represent a policy as π: future evidence/state → future action: pursue X strongly now; increase E if anomaly A appears; strengthen P as irreversible threshold B approaches; revise the policy if a new value structure C becomes credible.

Adaptive rule: Strong present action need not be a one-shot final decision. Choose a response pathway to future information, not only a current act.

12. Why reversibility must sometimes be designed early — Collingridge

Collingridge's control dilemma observes that early in a technology's development it is relatively easy to change but difficult to predict its consequences; later, consequences become clearer but sunk costs, skills, infrastructure, institutions, and dependence make change difficult. In shorthand, knowledge ↑ while changeability ↓ can move in opposite directions.

“Wait until we understand it, then make the irreversible decision” therefore fails as a general policy. The capacity to change may disappear while understanding is still developing. This creates a reason to build staged deployment, rollback, monitoring, branching, independent alternatives, and exit paths into systems before their long-run effects are fully known.

The problem is especially acute for AI and value lock-in, where economic, political, and security dependence can make later correction far more costly than early redesign.

13. Reflective decision — how far should the present self bind the future self?

Ordinary dynamic-choice theory already asks whether a present agent should use commitment against predictable future preference change or instead defer to future judgment. This project goes further because Vt → Vt+1 may reflect learning, corruption, manipulation, preference drift, value discovery, or cognitive enhancement, and the present agent may not be able to tell which in advance.

Future preference is not automatically authoritative, but current preference is not automatically privileged either. Permanently binding future evaluators and surrendering to every future preference change each require additional justification.

The meta-policy M from Reflective Uncertainty and Irreversible Commitment belongs here: inertia, inquiry, suspension, and related policies govern how a subject continues acting when its current goal lacks a settled justification. Even when the justified objective is Null, action continues, so the agent needs a second-order policy for how to use current values provisionally, when to revise them, and which self-modifications to permit.

Reflective rule: current value use ≠ current value privilege ≠ future-value surrender.

14. Multiple agents — separate aggregation, branching, and coercion

A single-agent decision policy does not determine what a society of humans, AIs, future agents, and distinct value-inquiry lineages should do. Social choice and judgment aggregation show that even when individuals have coherent preferences or judgments, aggregating them into one coherent social ordering or collective judgment while preserving all attractive conditions may be impossible.

Maintaining plurality should therefore be distinguished from immediately compressing everyone into one social utility. Aggregation, bargaining, voting, premise-based judgment aggregation, decentralization, exit, forks, and polycentric institutions are distinct institutional decision rules with distinct failure modes.

Collectively selecting A is also distinct from being authorized to coerce dissenters into A. The distinction from Normative Bridges from Future Value to Present Action remains: reason ≠ permission ≠ obligation ≠ coercive authorization. A social decision procedure does not manufacture coercive authority by itself.

15. Overall structure — strong action, no false precision, preserved correction

The resulting decision policy is not a fixed algorithm. It selects decision rules according to the representation currently justified, and actions then change the evidence, option set, value state, and sometimes the evaluator itself.

{ epistemic state, value state, comparability, feasible actions, constraints }t → decision policyt → actiont → { new evidence, new options, new value state }t+1

Optimize strongly where comparison is justified; do not force incomparable values into a fabricated scalar. Stress-test under deep model uncertainty; evaluate information and option value when future learning matters; compare the irreversibility of action and inaction; design adaptive pathways through time. When values themselves are revisable, use current values in practice without automatically granting them authority to destroy the capacity for future reassessment.

This decision policy is itself revisable, just like the Epistemic Policy. Better future comparison structures, decision theories, or cognitive capacities may replace it.

What this page does not claim

  • That expected-utility theory is false. It remains central in adequately represented standard cases.
  • That incomplete value must always be handled by maximin, minimax regret, or RDM.
  • That incomparability is permanent; inquiry may discover new comparison structure.
  • That reversibility, inquiry, optionality, or pluralism is itself an ultimate value.
  • That irreversible action should always be postponed; inaction, competition, and expiring opportunities may also be irreversible.
  • That future values automatically outrank present values, or vice versa.
  • That social plurality automatically produces correct collective decisions.
