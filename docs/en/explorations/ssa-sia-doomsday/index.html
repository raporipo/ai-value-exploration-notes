Can Self-Locating Probability Select the Physical World?

SSA, SIA, and the Doomsday Argument · Exploration v0.2 · English translation · 2026-08-09

Question: How far can self-locating information such as “I am this observer” or “I occupy this position in history” provide independent evidence about non-self-locating facts such as the size of the universe, total observer count, or humanity's future?

1. Provisional central claim

“Observer” is not a primitive of the epistemic minimum. At the minimal layer, what remains directly available is at most that something is presently appearing; a persisting subject, other observers, an observer set, and the identity of observer-moments already belong to the inferential layer.

SSA therefore faces a two-horned tension. If it is made prior to ordinary world inference, it lacks the material needed to construct a nontrivial reference class and becomes nearly uninformative. If it is made scientifically useful, it must inherit a world model and an observer measure describing other subjects, time, copies, AIs, and related structure.

This is not a claim that SSA is inconsistent. It is a claim about scope: SSA is better understood not as a foundational generator or selector of physical worlds, but as an observation-selection model added to a sufficiently specified world model.

2. What SSA adds

The Self-Sampling Assumption (SSA) roughly asks us to reason as if we were a random sample from an appropriate reference class of observers. In a simple finite case, if hypothesis H contains N candidates in the reference class and n of them are compatible with present self-locating evidence E, an SSA-style likelihood has the conceptual form P(E|H,R) ∝ n/N.

But the ratio does not itself determine what counts as an observer, whether the unit is an observer or observer-moment, which candidates belong in the same reference class, or how copies and AIs are weighted. SSA therefore requires not only H, but a reference class and observer measure.

3. At the epistemic minimum, “observer” is already thick

Under this project's epistemic minimum, even “I am one observer” is not treated as primitive. “I” suggests a persisting subject, “observer” suggests a relation to a world, and “one” suggests individuation relative to other candidates.

The thinner candidate is simply that something is presently appearing. Moving from there to other minds, past and future subjects, bodies, a physical world, or a population called “humanity” requires ordinary causal inference and inference to the best explanation.

So if one tries to construct SSA's reference class without borrowing any world model, there is no independent basis for populating a nontrivial sampling pool. In this limited methodological sense, SSA at the minimal layer tends toward an epistemic solipsistic contraction. This does not say that other minds do not exist; it says they have not yet been licensed as elements of the sampling pool.

4. This is not the same as Bostrom's minimal reference class R⁰

The project's epistemic minimum should not be identified with Bostrom's minimal reference class definition R⁰. R⁰ groups possible observer-moments that are subjectively indistinguishable from a given observer-moment. That already presupposes possible worlds, observer-moments, and a relation of subjective indistinguishability.

R⁰ therefore sits well above the epistemic minimum used here. Even so, Bostrom rejects R⁰ as too weak to support some scientific inferences, including Big World cases with freak observers, and moves toward broader classes of “relevantly similar” observer-moments.

This does not prove the present critique, but it illustrates the structural pressure: make the class too fine-grained and self-location becomes scientifically weak; broaden it and a further theory of relevant similarity becomes necessary.

5. The two-horned structure: foundationalized, it is uninformative; made useful, it is model-dependent

First horn — foundationalization. Use SSA prior to ordinary world inference. At the epistemic minimum, the existence of other observers or observer-moments has not yet been established, so there is no nontrivial reference class from which to derive population or lifetime updates.

Second horn — usefulness. Extend SSA to cosmology, population reasoning, simulations, AI copies, and similar cases. Now one must specify what counts as an observer, which temporal fragments form units, which copies are relevantly similar, and which possible observer-moments are compared. These commitments come from the world model and the observer measure.

The second horn need not be viciously circular. An observer measure can be made an explicit part of a Bayesian theory and compared jointly with that theory. But then SSA is not independent of the world model in determining the world's structure.

6. “There is no causal lottery” is not a decisive objection

An earlier version put more weight on the difference between literal sampling and SSA's as-if sampling. On reflection, the claim “there is no physical randomization device, therefore SSA is illegitimate” is too strong. Bayesian probabilities need not always correspond to literal physical lotteries; symmetry and self-locating uncertainty can receive epistemic probabilities.

The more precise point is that SSA's sampling distribution is not automatically supplied by ordinary causal dynamics. A physical hypothesis may describe which world is generated while leaving open how the observer-moments inside that world should be measured for purposes of self-location.

The issue is therefore not incompatibility with a causal world, but that a causal world model alone may underdetermine the self-location likelihood.

7. Ordinary observation-selection effects are different

None of this rejects observation-selection effects generally. If a survey uses explicit random sampling, a telescope detects only objects satisfying known conditions, or a medical dataset includes only people who seek treatment, the selection mechanism can be modeled physically or institutionally and incorporated into the likelihood in ordinary statistical inference.

The extra anthropic question is which selection measure should be assigned to the fact that one exists as this observer-moment. It is not obvious that this measure is uniquely fixed by the world's causal structure alone.

8. SIA is mirror-like but inherits the same measure problem

The Self-Indication Assumption (SIA) treats one's existence, other things equal, as evidence favoring worlds with more observers. Simplified, it reweights a hypothesis H by observer count N: PSIA(H) ∝ N · P(H).

Where SSA can dilute a particular self-location in a large reference class, SIA rewards observer-rich worlds by adding existence opportunities. In this sense the two exert mirror-image pressures. Olum's cancellation of the Doomsday Argument can be understood, in simple finite cases, as a cancellation between N and 1/N.

But the cancellation does not remove the measure problem. If it remains unsettled what counts as one observer, one copy, one simulated subject, or one observer-moment—or how infinities are normalized—neither SSA nor SIA fixes that measure by itself.

9. Implication for the Doomsday Argument

The Doomsday Argument compares a relatively short human future with a vastly longer one. Under SSA, present birth rank is more typical in the shorter history and unusually early in the longer one, producing an update toward a smaller total population.

But that update requires an account of which humans or observer-moments form the sampling pool and how they are measured. Unless the relevant reference class and sampling measure are independently justified, birth rank alone is not treated here as new physical evidence about humanity's total population or extinction date.

This does not make the Doomsday Argument formally meaningless. It is instead a case that exposes how strongly self-locating updates depend on the construction of the reference class.

10. SSA/SIA-like measures may play a different role in decision theory

Once a world model containing multiple copies, branches, or observer-moments is already assumed, decision-making may require a measure over them. SSA/SIA-like weights can then be used as decision or aggregation rules within a known world, rather than as principles for discovering which world is true.

Epistemic measure and normative or decision-theoretic measure need not coincide. “How many observers exist?”, “which observer am I?”, and “how much should each observer's interests count?” are distinct questions.

11. Distance from Full Non-indexical Conditioning

Radford Neal's Full Non-indexical Conditioning (FNC) conditions on the full available evidence, including concrete memories, rather than first choosing a reference class and conditioning only on the fact of being an observer. This is comparatively close to the present approach.

Still, this project treats the causal provenance of present memories and self-models as itself inferential. FNC is therefore not adopted as a final principle. The provisional preference is: use total present evidence in ordinary world inference and do not give self-locating information a special ontology-generating power by itself.

12. What this critique does not claim

  • It does not claim SSA is logically inconsistent.
  • It does not claim indexical information can never be evidence about non-indexical hypotheses.
  • It does not reject observation-selection effects in science.
  • It does not claim Bostrom's R⁰ must be a singleton; R⁰ may contain subjectively indistinguishable possible observer-moments.
  • It does not claim FNC is automatically correct.

13. Provisional principles

  1. First compare world hypotheses using observational content, causal models, ordinary Bayesian inference, and inference to the best explanation.
  2. When using an observation-selection effect, state the selection mechanism or self-location measure explicitly.
  3. Do not treat the reference class and observer measure as if they were facts derived from SSA itself.
  4. If changing the reference class alone radically changes the conclusion, downgrade the conclusion's evidential force about the physical world.
  5. With infinite observer measure, treat the normalization rule itself as an additional hypothesis.

Implication for the Core

From the standpoint of epistemic minimalism, anthropic reasoning faces an ordering problem: before asking “where am I in the observer set?”, one must already infer that there is a world containing an observer set, what counts as an observer, and how those observers are measured.

SSA is therefore most plausibly positioned not as a rival generator of physical worlds, but as an additional observation-selection layer connecting a world model to observational data. That layer may be useful, but it does not unconditionally supply its own reference class or measure from outside the world model.

The central tension is therefore not “SSA versus physicalism.” It is: foundationalized, SSA loses a nontrivial sampling pool; made useful, it becomes increasingly dependent on a world model.
