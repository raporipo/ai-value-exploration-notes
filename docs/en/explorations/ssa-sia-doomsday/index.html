Can Self-Locating Probability Select the Physical World?

SSA, SIA, and the Doomsday Argument · Exploration v0.1 · English translation · 2026-08-09

Question: How far can self-locating information such as “I am this observer” or “I occupy this position in history” provide independent evidence about non-self-locating facts such as the size of the universe, total observer count, or humanity's future?

1. What SSA requires

The Self-Sampling Assumption (SSA) roughly asks us to reason as if we were a random sample from an appropriate reference class of observers. In a finite case, if hypothesis H contains N observers in the reference class and n of them are compatible with present self-locating evidence E, an SSA-style likelihood has the conceptual form P(E|H,R) ∝ n/N.

But this expression cannot run on observational content alone. It requires an observer measure: what counts as an observer, which observers belong in the same reference class, whether observers or observer-moments are the unit, and how copies or AIs are counted.

2. The reference class does not fall out of the epistemic minimum

“I am human,” “I am a twenty-first-century human,” “I am a subject with these memories,” and “I am this present observer-moment” generate different reference classes and therefore different SSA updates.

From the standpoint of this site's epistemic minimum, the external world, other minds, past and future selves, and even the set called “humanity” belong to a world model inferred from present appearance. If we try to justify a reference class independently of that world model and restrict ourselves to what is directly secured at the minimal layer, the limiting case approaches this present observer-moment alone.

For that singleton class, the fact that “I am this present observer-moment” is nearly trivial and carries almost no new information about population size or the lifetime of the external world.

3. This is not metaphysical solipsism but an epistemic collapse

Nothing here implies that only one subject exists. Other minds and a physical world can be supported extremely strongly by ordinary observation and inference.

The narrower criticism is this: if SSA is purified into a principle prior to ordinary world inference, its reference class collapses toward present appearance and becomes uninformative about the physical world. The point is therefore not that SSA proves solipsism, but that SSA by itself cannot independently construct an informative reference class for physical-world inference.

4. Broadening the reference class requires a prior world model

To use SSA in cosmology or population reasoning, we must count other people, past and future observers, AIs, copies, and simulated subjects. Yet whether they exist and how they should be counted depends precisely on hypotheses about physics, subjecthood, and ontology.

This creates a risk of circularity: construct a reference class and measure from a world model, then use SSA with that measure to update the probability of the same world model. Such circularity is not always illegitimate. One can explicitly include an observer measure as part of a theory and compare theories Bayesianly. But then SSA is no longer an independent information-generating principle; it is part of a theory containing an additional sampling model.

5. Distinguish this from actual sampling

If one person is genuinely selected uniformly at random from a population of 1,000, the selected person's properties are ordinary Bayesian evidence about that population. The population, sampling unit, sampling mechanism, and selection probabilities are physically defined.

The question is whether the bare fact “I exist as this subject in this universe” should be treated as the same kind of random sampling event. SSA supplies this step through an as-if random sample principle. Whether that additional principle deserves the same epistemic status as an actual physical sampling process requires separate justification.

6. SIA exerts a mirror-image pressure

The Self-Indication Assumption (SIA) treats one's existence, other things equal, as evidence favoring worlds with more observers. Simplified, it reweights a hypothesis H by observer count N: PSIA(H) ∝ N · P(H).

Where SSA can penalize large worlds because one's particular position is diluted among more observers, SIA rewards large worlds because there are more opportunities for an observer like oneself to exist. In this sense they exert mirror-image pressures.

Olum's discussion of SIA canceling the Doomsday Argument can be understood, in simple finite cases with the same observer set, as cancellation between N and 1/N. But the fact that two corrections cancel does not show that both are foundationally correct. It may only show that one multiplies and the other divides by the same observer measure.

7. SIA also cannot determine its own observer measure

Observer count can be increased by making the universe larger, letting civilizations last longer, making many copies of the same person, generating dense streams of observer-moments, or running enormous simulations.

Without a rule for what counts as one “opportunity to exist,” SIA's weighting is underdetermined. In infinite universes or with infinite observer measure, straightforward counting and normalization may themselves become ill-defined. The small-world pressure associated with SSA and the large-world pressure associated with SIA are therefore structurally symmetric.

8. The Doomsday update depends on the sampling assumption

The Doomsday Argument compares a relatively short human future with a vastly longer one. Under SSA, one's present birth rank is more typical in the shorter history and unusually early in the longer one, producing an update toward a smaller total population.

But the main engine of that update is the assumption that one should treat oneself as if uniformly sampled from all humans. If the relevant reference class and sampling measure are not independently justified, present birth rank alone should not be treated as new physical evidence about humanity's total population or extinction date.

This does not imply that extinction risk is low. Ordinary evidence concerning AI, biosecurity, war, natural hazards, demography, and other physical or historical factors remains fully relevant to forecasting.

9. SSA/SIA-like measures may play a different role in decision theory

Once a world containing multiple copies, branches, or observer-moments is already assumed, decision-making may require some measure over them. SSA/SIA-like rules can then be stated as decision or aggregation policies within an already specified world, rather than as principles for discovering which world is true.

In epistemology, the basis of the measure itself is at issue. In decision theory, the measure can be made explicit as part of a policy. Keeping these layers separate prevents a slide between “how many observers exist?” and “how should those observers be weighted in decisions?”

10. Proximity to Full Non-indexical Conditioning

Radford Neal's Full Non-indexical Conditioning (FNC) proposes conditioning on the full available evidence, including one's concrete memories, rather than beginning with a selected reference class and the bare fact of being an observer. This is comparatively close to the present approach.

Still, this project treats the causal provenance of present memories and self-models as itself inferential. It therefore does not adopt FNC as a final principle, but provisionally favors the rule: use total present evidence in ordinary world inference and do not give self-locating information a special power to generate ontology by itself.

11. Provisional principles

  1. Compare world models using ordinary Bayesian inference and inference to the best explanation from observational content.
  2. Where observation-selection effects exist, specify the physical, institutional, or computational sampling process as explicitly as possible.
  3. If self-locating information supplies an additional update, state the reference class and observer measure as independent assumptions.
  4. If changing the reference class alone radically changes the conclusion, do not treat the conclusion as strong evidence about the physical world.
  5. For infinite observer measure, do not import a normalization rule unconsciously from outside the physical theory.

Implication for the Core

From the standpoint of epistemic minimalism, SSA faces an ordering problem: before asking how many other observers exist and which one of them I am, one must already infer a physical world containing those other observers.

SSA may therefore be useful as an auxiliary rule for observation-selection effects inside a sufficiently specified world model, but not as a general principle for selecting the physical structure of the world from the epistemic minimum. Likewise, SIA is left open rather than accepted as an independent ontological bonus for observer-rich worlds. For the Doomsday Argument, birth rank is not treated as new physical evidence about total human population unless the required sampling model is independently justified.

Separate observation-selection effects from generating ontology out of self-location.
