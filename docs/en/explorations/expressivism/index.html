How Would Expressivism Change Value Uncertainty?

Exploration v0.2 · English translation · 2026-08-08

Question: If moral sentences are expressions of attitude, commitment, or normative practice rather than descriptions of the world, how much remains of the language of "discovering true value"?

Appeal

Expressivism is attractive because it can explain the practical force of moral language without positing objective moral facts. "X is wrong" can be understood as expressing opposition or normative commitment rather than reporting a strange non-natural entity.

Tension with the Core

If value language is entirely expressive, value inquiry shifts from discovering external truth to a constructive problem: which attitudes or normative systems should be reflectively endorsed? Explorability does not become meaningless. Different subjects, experiences, and institutions can still be compared in the search for more coherent, stable, and mutually acceptable constructions of norms.

Relation to the stopping condition

If a strong form of expressivism is correct, the proposed stopping condition in which objective value with normative force appears directly at the minimum foundation may simply not exist. Value inquiry would then become ongoing reflective construction and reconstruction as subjects, experiences, and institutions change, rather than a search for an eternal external truth.

Strong practical commitment to constructed values would still be possible. What should remain open is then less a window onto objective truth than the institutional and epistemic capacity of future subjects to reevaluate value construction.

Remaining problem

Even if expressivism explains how moral language functions, it may not eliminate the second-order question "why adopt this attitude?" If every level is ultimately reduced to attitudes, value inquiry begins to resemble self-construction more than truth-seeking.
