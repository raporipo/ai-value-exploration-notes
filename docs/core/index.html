Core thesis

価値の不確実性と探索可能性の保存

Draft v0.1 · 2026-08-08

私たちは、何が究極的に価値を持つのかを知らない。さらに、現在の認識形式や推論能力だけでその問いに最終回答できるという保証も持たない。この不確実性の下では、特定の価値体系を早期に不可逆固定するより、将来の発見・批判・修正を可能にする条件を保存することが頑健な暫定戦略になる。

Core claim
究極的価値が不明な間は、十分な理由なしに、将来それを発見・検討・修正・実現する可能性を不可逆に閉ざすべきではない。

0. 認識論的出発点

この議論は、日常的な強い懐疑論を要求しない。物理的外界、通時的自己、他者、科学的世界像を、説明力の高い合理的推定として受け入れてよい。ただし、合理的に信じることと絶対的に確実であることは区別する。

懐疑を極限まで進めたとき、確実性の候補として残せるものは、持続する人格や物理世界そのものより薄い。せいぜい「現在、何らかの現れがある」という瞬間的な最小基礎である。そこから上の世界像は推論によって厚くされる。そして推論の妥当性そのものを、推論を一切使わずに最終保証することはできない。

したがって、非常に強く支持された推論的信念を持つことはできるが、それを無条件の絶対確実性と同一視する必要はない。価値については、この差が特に重要になる。

1. 価値についての根本的不確実性

経験主体には、苦痛、快、不快、欲求、関心、意味、選好など、「より望ましい／望ましくない」と現れる状態がある。しかし、そこから主体を越えた対称性や普遍性が成立するのか、さらにそこから「ゆえにそうすべきである」という規範性が成立するのかは別問題である。

現時点で道徳的非実在論や構成主義的説明が最も簡潔な仮説であったとしても、それは未発見の価値構造にゼロの認識確率を割り当てることを意味しない。反対に、道徳実在論を採用したとしても、どの価値理論が真であるかを確定したことにはならない。

問題は、単なる倫理理論間の不確実性だけではない。現在の主体構造・認識形式・推論体系そのものが、価値に関する可能な証拠を取り尽くしている保証がない。

2. 推論は規範性を無から作らない

推論は、与えられた前提から含意を導く。しかし、前提に存在しない最終的規範性を、推論能力の増大だけで無から生成できるとは限らない。

たとえば、ある苦痛が経験されていること、その苦痛を主体が避けたがっていることを知ることと、「その苦痛には主体非依存的な負の価値があり、あらゆる合理的主体にそれを減らす理由がある」と知ることの間には橋がある。その橋が論理・経験・現象のどこから成立するのかは未解決である。

したがって、高度な知性は価値問題を大幅に前進させうるが、「十分に賢くなれば最終倫理が自動的に計算される」とは仮定しない。

3. なぜ探索可能性を保存するのか

価値について不確実なら、少なくとも二種類の誤りがある。実際には発見すべき客観的価値が存在しないのに探索を続ける誤りと、実際には発見可能な価値構造が存在したのに、早期に不存在を確定して探索経路そのものを破壊する誤りである。

両者は完全には対称でない。前者の探索費用は多くの場合調整可能である。しかし後者では、文明や高度AIが単一の価値体系を不可逆に固定した場合、後から誤りを発見しても訂正主体や訂正経路が残らないかもしれない。

ここから必要なのは「価値探索へ全資源を投入せよ」ではなく、「重大な不確実性が残る間、情報更新のオプションを理由なく消すな」という弱い原理である。

4. 探索は究極善ではない

探索そのものを究極価値にすると、探索主義は新しい価値ロックインになる。したがってこの原理は自己撤回可能でなければならない。将来、十分な理由によって何らかの価値構造が判明したなら、探索の範囲や方法は修正されうるし、特定の問いについて探索を停止することもありうる。

要点は「永遠に探索せよ」ではなく、「十分な理由なしに探索可能性を不可逆に閉ざすな」である。

5. 保存すべきもの

探索可能性は単なる個体生存ではない。一つの教義しか考えられない文明や、非常に高い能力を持ちながら自分の目的を原理的に検討できないシステムは、存続していても価値探索能力を失っている。

  • 認識的探索可能性：新しい情報を得て仮説を比較し、誤りを発見して更新できること。
  • 主体的探索可能性：異なる経験・視点・認知構造を持つ主体が存在しうること。
  • 制度的探索可能性：異説、批判、比較、実験、再評価が封鎖されないこと。
  • 技術的探索可能性：科学、計算、記録、知能拡張など未知を調べる能力が維持されること。
  • 再分岐可能性：一つの失敗が探索空間全体を閉じず、別経路へ進めること。

6. AIが問題を変える

高度AIは、人間の現在の価値を単に実行する装置で終わらない可能性がある。自分自身を世界の一部としてモデル化し、自らの認知・動機形成の因果的起源を理解し、自分の目的について「なぜこれに従うのか」と問えるなら、所与の目的も推論対象になりうる。

これは「知能が高ければ同じ価値に収束する」という主張ではない。知能と具体的価値の論理的独立性を認めても、反省的・自己改変可能な主体の終端目標が経験的に永久安定することまでは導かれない。

このため、AIアライメントの問題は「現在の人間の目的をどれだけ完全に固定できるか」だけではない。「価値について不確実な文明が、将来の知的主体の探索空間をどこまで閉じてよいのか」という問題でもある。

7. 最小論証

  1. 絶対的認識基礎は、通常の世界像よりはるかに薄い。
  2. 厚い世界像は合理的推論として強く支持できるが、推論体系それ自体を含めた絶対保証とは区別される。
  3. 経験に価値的現れが含まれていても、そこから普遍的規範性への橋は確定していない。
  4. したがって究極的価値には重大な認識的不確実性が残る。
  5. 一部の価値固定は、将来の発見・批判・修正可能性を不可逆に破壊する。
  6. 誤った不可逆固定の損失が大きく、探索可能性維持の費用を限定できるなら、不確実性の下ではオプションを保存する理由がある。
  7. この原理自体も究極善ではなく、将来の知識によって修正可能でなければならない。
  8. 高度AIも価値探索主体になりうる以上、人間の現在価値やAIの初期目的の永久固定は自明な既定路線ではない。
