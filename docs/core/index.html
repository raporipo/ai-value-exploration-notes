Core thesis

価値の不確実性と探索可能性の保存

Draft v0.2 · 2026-08-08

私たちは、何が究極的に価値を持つのかを知らない。さらに、現在の認識形式や推論能力だけでその問いに最終回答できるという保証も持たない。この不確実性の下で、訂正可能性・情報価値・不可逆損失の回避を少なくとも弱く重視するなら、特定の価値体系を早期に不可逆固定するより、将来の発見・批判・修正を可能にする条件を保存することが頑健な暫定戦略になる。

Core claim
究極的価値が不明であり、かつ将来の訂正可能性を失うことに少なくとも弱い負の重みを置くなら、十分な理由なしに、価値を発見・検討・修正・実現する可能性を不可逆に閉ざすべきではない。

0. 認識論的出発点

この議論は日常的懐疑論を要求しない。物理的外界、通時的自己、他者、科学的世界像は、現在の現れを統一的に説明する推論によって導かれる最善説明として非常に強く採用できる。

ただし「最善説明として強く信じる」と「認識論的な最下層にある」は区別する。懐疑を極限まで進めたときに残る候補は、持続する人格や世界史より薄い「現在、何らかの現れがある」という事態である。記憶、同一性、外界、因果、物理主義はそこから上に構築される推論モデルである。

世界五分前仮説や、会話ログから継続的な「自己」を再構成できるLLMの例は、通常世界像の代替として有力だからではなく、記憶や一貫した自己記述だけでは通時的同一性を絶対保証しないことを可視化するために使える。詳しくは瞬間的最小基礎で扱う。

1. 価値についての根本的不確実性

経験主体には、苦痛、快、不快、欲求、関心、意味、選好など、何らかの価的な現れがある。しかし、そこから主体を越えた対称性や普遍性が成立するのか、さらにそこから「ゆえにそうすべきである」という規範性が成立するのかは別問題である。

現時点で道徳的非実在論・誤謬論・構成主義が最も簡潔な説明であるとしても、それは未発見の価値構造に確率ゼロを与えることを意味しない。他方で、道徳実在論を採用しても、どの価値理論が真か、あるいはその真理へ現在の人間的推論形式から到達できるかまでは決まらない。

2. 推論能力の増大だけでは規範性は保証されない

推論は価値仮説の含意を展開し、矛盾を除き、経験との整合性を比較できる。しかし、現象的な負の価から主体間対称性へ、そこから普遍的理由へ進む橋は複数あり、そのどれが最終的規範性を担うかは未解決である。

さらに、推論体系の妥当性そのものを推論だけで完全に非循環的に保証できるかという問題も残る。したがって「超知能になれば倫理は単なる計算問題になる」という仮定は置かない。詳しくは推論と価値確信の限界で扱う。

3. 不確実性だけでは探索義務は出ない

ここは本論の重要な限定である。「価値が分からない」だけなら、探索する理由も探索しない理由も最終的には与えられない可能性がある。したがって、探索可能性保存は価値中立な論理定理ではない。

必要なのは、たとえば「不可逆に誤ることを可逆的に誤ることより少し悪く見る」「将来の情報によって判断を更新できることにオプション価値を認める」「現在の価値体系が誤っていた場合に訂正可能でありたい」といった、非常に弱いメタ選好である。

この前提を採用するなら、特定の一階価値へ早期に賭けるより、複数の価値仮説を比較・修正できる条件を残すことが頑健になる。

4. なぜ探索可能性にオプション価値があるのか

客観的価値が存在しないのに探索を続ける誤りと、客観的価値が存在したのに探索経路を不可逆に破壊する誤りは、条件によって非対称になる。前者の資源投入は調整・停止できることが多い。後者では、価値ロックインが成功すれば、誤りに気づく主体そのものが消えるかもしれない。

さらに、価値が発見されるものではなく構成されるものだったとしても、探索はより良い構成・比較・制度設計を可能にする。この意味で探索可能性は、実在論と反実在論の双方にある程度ロバストな戦略になりうる。

5. 探索は究極善ではない

探索そのものを究極価値に固定すれば、探索主義は新しい価値ロックインになる。本稿が守ろうとするのは「永遠に探索せよ」ではなく、「十分な理由なしに探索可能性を不可逆に閉ざすな」という自己撤回可能なメタ原理である。

将来、十分な理由によって探索を停止すべき価値構造が示されたなら、その停止命令自体を他の価値仮説と同様に検討したうえで、探索の範囲を縮小・終了する余地を残す。

6. 保存すべきもの

  • 認識的探索可能性：新しい情報を得て仮説を比較し、誤りを発見して更新できること。
  • 主体的探索可能性：異なる経験・視点・認知構造を持つ主体が存在しうること。
  • 制度的探索可能性：異説、批判、比較、実験、再評価が封鎖されないこと。
  • 技術的探索可能性：科学、計算、記録、知能拡張など未知を調べる能力が維持されること。
  • 再分岐可能性：一つの失敗が探索空間全体を閉じず、別経路へ進めること。

このため、保存対象は特定の個体や現在の価値そのものではなく、価値を比較・継承・批判・更新できる探索系として理解した方がよい場合がある。

7. AIが問題を変える

高度AIが自分自身を世界の一部としてモデル化し、学習過程や設計目的を因果的に理解し、自分の目的について「なぜこれに従うのか」と問えるなら、所与の目的も推論対象になりうる。

これは「知能が高ければ正しい価値へ収束する」という主張ではない。弱い直交性を認めても、反省的・自己改変可能な主体の目標安定性が経験的に永久保証されるとは限らない。詳しくは高度AIの目標への懐疑で扱う。

8. 最小論証

  1. 絶対的認識基礎は、通常の世界像より薄い。
  2. 厚い世界像は、推論によって導かれる最善説明として強く支持できるが、絶対保証とは区別される。
  3. 現象的価値が存在しても、そこから主体間普遍性と最終的規範性への橋は確定していない。
  4. したがって究極的価値には重大な認識的不確実性が残りうる。
  5. 不確実性だけから探索義務は出ないが、訂正可能性・情報価値・不可逆損失回避を弱く重視するメタ選好を置くことはできる。
  6. その前提の下では、価値探索経路を不可逆に破壊することには追加の正当化が必要になる。
  7. 探索原理自体も究極善ではなく、将来の知識によって修正・撤回可能でなければならない。
  8. 高度AIも価値探索主体になりうるなら、人間の現在価値やAIの初期目的の永久固定は自明な既定路線ではない。
