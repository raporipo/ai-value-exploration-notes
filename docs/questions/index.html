問いから入る

検索・AIエージェント向けの短い入口。詳論は各Thesisへ。

過去の「私」と現在の「私」は、本当に同一だと確実に言えるか？

合理的には非常に強く言えるが、記憶や記録は現在の入力でもあるため、通時的同一性は最小基礎ではなく推論による最善説明として扱う。詳論

快・不快はそのまま客観的価値なのか？

現象的valenceは基礎層に近い重要な証拠だが、主体非依存的規範性まで直接含むかは未確定である。詳論

価値探索はいつ完全に止めてよいのか？

最も強い停止条件候補は、規範的拘束性をもつ客観的価値が推論を介さず認識論的最小基礎と同等の強さで与えられる場合。推論的最善説明なら、探索を縮小し強く実践採用しても、再検討経路は残す。詳論

客観的価値が推論でほぼ確実になったら？

それに強く従ってよい。可謬主義は弱い行動を要求しない。ただし、世界像と推論体系に残る誤り可能性を検出できる経路まで不可逆に消すこととは別である。詳論

価値がない可能性の方が高いなら、探索をやめるべきでは？

強い価値虚無が真なら、客観的には探索と非探索の価値差自体がない。価値実在の場合だけ未知の規範的ステークスがありうる。ただし行動へつなぐには「真の価値があるなら無差別でありたくない」という薄い条件付き態度が必要。Core

なぜ現在の人間の価値を、そのまま最終基準にしないのか？

既存価値は重要な証拠・現在の最善実践だが、その因果的起源は規範的正当化と同一ではなく、実在論を認めても第一階価値は一意に定まらない。詳論

AIは終端目標を合理的に変更できるか？

可能性はある。重要なのは頻繁な目標変更ではなく、初期目的の因果的起源と理由を区別し、推論的根拠である限りメタ再検討能力を保持できるかである。詳論

小確率の巨大価値をどこまで重視すべきか？

規範的ステークスの非対称性は、巨大期待値への全賭けを意味しない。証拠の弱い仮説への探索資源は小さくでき、Coreが重視するのは不可逆な経路閉鎖の回避である。詳論
