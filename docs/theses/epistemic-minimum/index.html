Foundational thesis

瞬間的最小基礎

Working draft v0.1 · 2026-08-08

Thesis: 懐疑を最大化した場合、絶対的確実性の候補として残せるのは、通時的な人格や物理世界ではなく、せいぜい「現在、何らかの現れがある」という瞬間的で極薄い基礎である。

主張の射程

この命題は「外界は存在しない」「自己は存在しない」という実践的懐疑論ではない。外界、他者、通時的自己、物理主義的世界像は、最善説明として非常に強く信じてよい。ここで区別しているのは、合理的確信度と論理的・認識論的な最終基礎である。

なぜ「私」より薄くするのか

「私は考える」という表現には、すでに持続する主体や同一性が持ち込まれている可能性がある。最小化するなら、まず残るのは主体の厚い実体ではなく、何らかの現れ・思考・経験が現在あるという事実である。そこから瞬間的主体、記憶による通時的連続性、外界、他者、物理的世界像を推論によって構成していく。

確実性と説明力

基礎を薄くするほど世界について語れることは減る。反対に、推論を許すほど絶対的確実性は弱まるが、説明力と予測力は飛躍的に増す。したがって目的は最小基礎だけに閉じこもることではなく、どこから推論が始まっているかを明示することにある。

Coreとの関係

価値論においてこの区別が重要なのは、ある価値命題が非常に強く支持されうることと、その命題が絶対的な規範的基礎として保証されることが同じではないからである。価値探索の必要性は、この残余的不確実性を重く扱う。

反論候補

  • 論理法則そのものを使わずに「現れがある」と記述できるのか。
  • 「現在」という概念がすでに時間構造を前提としていないか。
  • 現れの存在から主体を分離すること自体が不自然ではないか。
  • 実践的には確率1に近い信念と絶対確実性を区別する意味がどこまであるか。
