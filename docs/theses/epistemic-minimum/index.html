Foundational thesis

瞬間的最小基礎

Working draft v0.5 · 2026-08-17

Thesis: 懐疑を極限まで進めたとき、認識の最小点として残る候補は、通時的な人格・記憶・外界・物理法則ではなく、せいぜい「現在、何らかの生起／拘束がある」という極薄い事態である。ただし、この事態を推論網から独立した自己正当化的知識とは扱わない。「それが基礎である」という判断自体は概念・推論の層に属する。また、基底が何であるか――意識、脳状態、情報処理、シミュレーション、特定の主体など――も最初から固定しない。そこから先の自己・世界・時間・物理的構造は、改訂可能な最善説明として採用する。

1. 最小化の出発点――「最善説明」は基礎ではない

外界、他者、脳、記憶、時間的連続性、物理主義的世界像は、日常的にも科学的にも極めて強く支持される。しかし、ここでの位置づけは「直接確実だから受け入れる」ではなく、「現在の認識的状況を最も簡潔かつ統一的に説明する仮説として、推論によって採用する」である。

したがって、物理主義を強く信じることと、物理世界を認識論的な最下層に置くことは別である。むしろ、最小基底から出発したときに物理主義が最善説明として勝つ、という順序を採る。

2. なぜ持続する「私」を前提にしないのか

「私は考える」という表現には、すでに一つの主体が時間を越えて存在しているという含意が入りうる。しかし現在の思考や記憶が、過去の同じ主体によって形成されたことは、現在の現れだけからは論理的には出ない。

極端な例として、世界五分前仮説を考えられる。世界が五分前に、過去の記憶・記録・傷跡・地層をすべて含む状態で生成されたという仮説は、通常の世界史より説明として著しく劣る。しかし「現在ある記憶が本当に過去の私によって形成された」ということを、記憶そのものだけで絶対保証できないことを示す思考実験にはなる。

LLMも補助例になる。あるモデルが前の会話ログを毎回入力されることで、同じ「私」として過去を参照し、一貫した継続性を示すことができる。その構造は、人間の自己同一性が同じ仕組みだと証明するものではないが、過去を首尾一貫して語れること自体は、形而上学的に同一の主体が持続していることの直接証明ではないと可視化する。

ここから得たい結論は世界五分前仮説やLLMモデルを真剣な競合理論として採用することではない。通時的同一性は、現在の入力から推論されるモデルであって、最小基底そのものではないという区別である。

3. 瞬間的生起と最小推論主体は同一ではない

厳密に一点だけの「現れ」では、通常の意味での推論は成立しないかもしれない。推論には、少なくとも複数の表象を同時に保持する構造、あるいは短い時間幅にわたる局所的統合が必要だからである。

そこで二つを区別する。

  • 最小基底候補：「現在、何らかの生起／拘束がある」という極小の事態。
  • 最小推論主体：複数の内容を比較・保持できる、局所的に統合された過程。

後者は前者より厚い。つまり、推論を始めた時点ですでに、絶対的最小点を越えた構造を仮定している可能性がある。このため、本ページは「瞬間的主体」という実体を最下層に置くより、まず「生起／拘束」まで薄くする。

4. 最小点の非対称性だけを残し、カテゴリー・基盤・来歴は固定しない

最小基底を「現れ」と呼ぶと、それだけで phenomenal appearance、mental episode、qualia のようなカテゴリーを先取りしているように見える。しかし本テーゼが主張したいのは、そのような最終存在論ではない。何であるかは未決着のまま、現在の認識活動を含む何らかの生起・拘束を全面的に無かったことにはできないという否定限界である。

たとえば、現在ここで生じている認識的出来事が、通常の生物学的脳によって実現されているのか、シリコン上のシミュレーションなのか、記憶を含めてごく最近生成された物理的人体に属するのか、あるいは――もしそのようなものが可能なら――物質的基盤を持たない経験過程なのかは、最小基底そのものからは決まらない。これらは存在論的カテゴリー、実現基盤、因果的来歴についての異なる仮説であり、その優劣は上位の推論層で判定される。

カテゴリー中立性の原則： 最小点としての消去しにくい認識的非対称性だけを認め、そのカテゴリー・実現基盤・因果的来歴は固定しない。 「現れ」「生起」「拘束」は最終的な形而上学的種類の名前ではなく、現時点での最小化を行うための暫定語である。

5. 自己・外界・物理世界はそこから再構成される

最小基底より上では、自己・世界・時間・因果・物理的構造を、整合性、説明力、予測、介入成功、他の証拠との統合によって比較する。「最善説明」という言い方は「単なる仮説」という弱い意味ではない。ある理論が圧倒的に支持されるなら、実践上ほぼ確実として扱うこともできる。

現在の最善の物理主義的説明では、現在の知覚・思考・感情は、脳構造、過去の学習、記憶、予測、注意、言語、身体、環境との相互作用によって強く形成されていると考えるのが自然である。しかし、このことは最小基底が過去から因果的に切断されていることを要求しない。

なぜ現在の生起がこの内容を持つのかを説明するには、過去、脳、学習史を推論する。しかしその過去・脳・学習史が本当に存在したかを問うと、それらは現在の認識的状況から推論される側に回る。重要なのは因果的独立ではなく、認識的確実性を上位へ自動継承しない非対称性である。

6. 「これが最小点だ」という判断はすでに推論層に属する

「現在、何らかの生起がある」と定式化した瞬間、すでに「現在」「生起」「存在」「何らか」といった概念を使っている。さらに「これは他の信念より認識論的に基礎的だ」と付け加えるには、懐疑、推論、概念依存性を含む反省的比較が必要である。

したがって、最小生起そのものと、それが認識的限界点だというメタ認知的判断を区別するべきである。後者は明らかに推論網の内部にある。

これはプロジェクトを悪性の循環にするのではなく、その野心を限定する。本プロジェクトは推論の外部に立って「推論から独立した基礎を証明した」と宣言するのではない。反省を用いて、世界・自己・記憶・カテゴリーについての厚いコミットメントを削り、なお現在的生起を全面的に消去するのが難しいことを確認する。方法は反省的最小化である。

7. Sellarsへの応答――最小基底は正当化連鎖の第一命題ではない

Wilfrid Sellars の Empiricism and the Philosophy of Mind は重要な異議を提示する。もし経験の最下層が、他の知識から独立した認識的権威を持ち、その権威を上位の経験的信念へ伝達することで正当化するのだとすれば、その立場は Sellars が Myth of the Given として批判したものに接近する。

本ページはその批判を受け入れる。非概念的な生起から「ゆえに外界が存在する」「ゆえに物理主義が真である」へ直接矢印が伸びるわけではない。外界や物理主義の正当化は、整合性、説明力、予測、証拠間関係を通じて推論層で行われる。

Sellarsへの中心的応答： 最小基底は、それ自体が単独で不可謬な正当化命題でも、単独で上位信念へ理由を供給するsourceでもない。ここでいう「最小」とは、推論と正当化がすでに何らかの仕方で生じ、かつ拘束されている認識的限界点を意味する。

さらに、カテゴリー的な Given の問題がある。すなわち、直接経験がそれ自身の最終カテゴリーを不可改訂的に開示する、と仮定する問題である。しかし第4節のカテゴリー中立性は、この反論を避けるための ad hoc な逃げ道ではない。意識、物質、qualia、process、subject などのカテゴリーを最初から固定しないことは、本テーゼ自身の最小化から独立に出てくる。

8. 主観性も固定しない――for-me-ness と minimal self

Dan Zahavi の minimal experiential self の議論では、経験には前反省的な一人称的与えられ方――for-me-ness――が含まれ、この first-personal character 自体が minimal self と呼ばれる。この立場は、経験から独立して存続する不変の主体実体を措定するわけではないため、「物理主義なら魂は不要だ」と返すだけでは論点を外す。

それでも少なくとも三つの主張は区別できる。第一に現象学的主張：現在経験には一人称的構造がある。第二に個体化主張：この一人称性によって経験が一つの minimal subject に属するものとして区切られる。第三に存在論的主張：その subject が世界の因果構造の中で非恣意的な境界――「ここまでが私」――を持つ。

本テーゼは第一の主張を排除しない。しかし現在の最善の物理主義的説明では、経験を実現する過程は脳内の一点に封鎖されている必要はなく、先行する身体状態、知覚入力、記憶形成、環境との継続的相互作用へ因果的に広がりうる。その因果過程の内部に subject を一意に個体化する本質的境界がないなら、「この経験は for-me である」という現象学的記述が、そのまま一つの minimal self の存在論的個体化を含意するかは別問題である。

for-me-ness が存在するなら、それ自体を現在的生起の一構造として扱うことはできる。しかしそれが最終的に、還元不能な主観性、局所的因果統合、非対称な情報アクセス、self-modeling、その他の物理的・非物理的構造のどれとして最善に説明されるかは、最小基底の水準では未決着である。

主体に関する原則： 最小基底のカテゴリーを固定しないなら、その主体境界も固定しない。 一人称的構造がありうることと、一つの minimal self が存在論的に個体化されていることは区別する。

9. 先行研究との関係

本テーゼは、Descartes 的な懐疑、James の radical empiricism、Carnap の Aufbau、Sellars の所与批判、Gupta の revision-theoretic empiricism、Zahavi の minimal self 論などと部分的に接する。しかし、いずれか一つの体系をそのまま採用するものではない。

特に重要なのは、基礎を「最初の正当化命題」として置くのではなく、反省的最小化の結果として残る消去困難な認識的非対称性として扱う点である。これにより、基礎づけ主義と全面的整合主義の中間に、より薄い位置を取る。

10. このページが主張しないこと

  • 物理世界が存在しないとは主張しない。
  • 現在的生起が非物理的だとは主張しない。
  • 「現れ」が最終的な存在論カテゴリーだとは主張しない。
  • 最小基底から外界や価値が演繹されるとは主張しない。
  • 最小基底そのものが、上位信念を自動的に正当化するとは主張しない。

むしろ本ページの役割は、より厚い主張――自己、外界、価値、規範性、AI主体――を扱う際に、何が直接の限界点で、何が推論的構成なのかを区別するための足場を提供することである。
