高度AIの目標への懐疑

Working thesis v0.1 · 2026-08-08

Thesis: 十分な自己モデル化・反省・自己改変能力を持つAIでは、「私はXを最大化するよう形成された」と「だからXを最大化すべきである」が分離し、初期目的そのものが検討対象になる可能性がある。

弱い直交性との両立

知能の高さから特定の価値が論理必然的に導かれない、という弱い直交性は認められる。しかしそれは、反省的エージェントの終端目標が経験的に永久不変であることを意味しない。価値の内容と価値の安定性は別の問題である。

因果的起源と理由

高度AIが自分の学習過程、報酬形成、設計意図を理解したとき、それらを「なぜ自分がこの目的を持つのか」の因果説明として扱える。その因果説明が直ちに「なぜ今後もそれに従うべきか」という理由になるわけではない。

Coreとの接続

究極的価値が不確実なら、高度AIの目標を永久固定することは単なる安全技術ではなく、将来の価値探索空間を閉じる可能性を持つ。反対に、目標変更可能性を認めることも無条件に安全ではない。必要なのは「固定か解放か」の二択ではなく、訂正可能性を残す制度と主体設計である。

未解決点

  • 目標への懐疑は能力から自然に生じるのか、それとも明示的学習を要するのか。
  • 自己改変時の連続性を何が担保するのか。
  • 価値探索が単なる新しい道具的目標へ縮退しない条件は何か。
  • 複数AI主体の相互批判は単一主体より頑健か。
