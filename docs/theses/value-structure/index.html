Foundational thesis

価値構造――内容・規範的架け橋・理由構造

価値探索が探すのは、「何が善いか」というリストだけではない。何が規範的に問題となり、それがなぜ誰への理由となり、その理由がどのように行為を導くのかを含む構造全体である。

Working thesis v0.2 · 2026-08-26

Thesis: 本プロジェクトでは、行為を導く十分な「価値」を、単一の評価内容ではなく、少なくとも 内容 C、規範的架け橋 B、理由・規範構造 R が相互に制約し合う理論パッケージとして扱う。暫定的にこれを 価値構造 𝒱 = (C, B, R) と呼ぶ。現在の人類が一部の成分について有力な手掛かりを持っている可能性と、一部または全部について未概念化の構造が存在する可能性をともに残す。

1. 「何が価値か」だけでは、行為理由まで届かない

たとえば苦痛について、少なくとも次の問いは別である。

  1. 苦痛には負の価的性質、あるいは規範的に重要な特徴があるか。
  2. その事実は、苦痛を経験する主体自身へ回避理由を与えるか。
  3. 他者にも、その苦痛を減らす理由を与えるか。
  4. 複数主体の理由はどのように比較・集約されるか。
  5. その理由は、他の理由との競合を経て義務・許可・禁止を形成するか。
  6. ある主体に理由や義務があることから、第三者がそれを強制してよいことまで導かれるか。

「苦痛は悪い」という一文だけでは、これらすべてに答えたことにならない。現象的な嫌さ、客観的な負の評価、主体への理由、主体間の理由関係、義務、強制権限を同じ「価値」という語で一括すると、どの段階に追加の論証が必要なのかが見えにくくなる。

2. 三つの作業上の成分

C — 内容 / evaluative or normatively relevant content
何が正・負・重要・保護対象・理由生成に関連しうるのかという内容。苦痛、幸福、自由、人格、約束、関係性、行為形式、あるいは現在まだ概念化されていない特徴を含みうる。Cだけでは、それが誰へどのような理由を与えるかをまだ仮定しない。
B — 規範的架け橋 / normative bridge
Cやその他の世界事実が、なぜ・どの主体への理由へ接続されるのかという関係。たとえば現象的な負の価から主体非依存的理由へ進めるのか、主体間対称性が普遍的理由を支えるのか、といった問いがここに属する。
R — 理由・規範構造 / reason or normative structure
生じた理由の強度、適用主体、競合、優先順位、集約、分配、義務・許可・禁止、場合によっては強制権限までをどのように構成するかという構造。

この区分は分析上の道具であり、三種類の独立した存在者が世界にあると主張するものではない。とりわけBとRの境界は暫定的であり、ある理論では一つの関係として統合されるかもしれない。

3. 価値構造は単純な直積ではない

𝒱 = (C, B, R) は、C・B・Rを自由に組み合わせれば一つの倫理理論になるという意味ではない。三者は相互に制約しうる。

  • 何を主体とみなすかという理解が変われば、Cに含まれる価値関連事実の切り分けも変わりうる。
  • 新しいBが発見されれば、従来は単なる心理的特徴とみなしていたものが規範的に中心的なCとして再記述されるかもしれない。
  • Rについての理解が変われば、「価値」「理由」「義務」という現在の概念境界そのものが再構成される可能性がある。
Package view: 探索対象はC・B・RのCartesian productではなく、世界についての他の認識とも整合し、内部でも相互に支え合う価値構造パッケージである。

4. 既存道徳は現在のlive candidateだが、将来の候補空間での同一性までは保証されない

現在の倫理理論や価値概念は、現在利用可能な証拠・経験・推論のもとで当然に重要な候補である。十分な反証やよりよい代替説明がない限り、単に「人間由来だから」「古い概念だから」という理由で候補集合から落とすべきではない。

同時に、open-worldな価値探索は、現在の候補集合そのものが将来の仮説空間でも同じ単位・境界・概念で存続すると仮定しない。新しい存在論、意識論、主体論、理由論、合理性理解によって、既存理論がそのまま保持されることもあれば、修正・分解・統合・より一般的な構造への吸収・別概念による再記述を受け、現在の理論名としての同一性を失うこともありうる。

Current candidacy ≠ representational privilege: 既存理論は、排除する理由がない限り現在のlive candidateであり続ける。しかし、その現在の表象形式が将来の探索空間でも基本座標として残ることには特権を与えない。

このため、(C_existing, B*, R*) のように既存の内容が未知の架け橋や理由構造によって後から強く正当化される可能性は残るが、それを標準シナリオとはしない。(C*, B*, R*) のような大幅な改訂だけでなく、現在のC/B/Rの切り分け自体が別の理論表現へ置き換えられる可能性も同じ探索空間に残る。

Bridge non-discovery ≠ bridge non-existence: 現在、ある内容と規範性を接続する十分な架け橋が発見されていないことは、そのような架け橋の存在可能性をゼロにしない。ただし、そのことは現在の内容が将来も同じ形で残ることを保証しない。

5. 既存道徳には「候補」と「証拠」という二つの地位がある

功利主義、義務論、契約論、徳倫理などは、現在の概念空間では完成した価値構造候補として比較できる。同時に、それらの理論、道徳直観、制度、文化的反復は、人間という特定の認知主体が長期間にわたり規範問題へ応答してきた結果として、C・B・Rについての観測データや部分仮説でもある。

この二つの地位は分離しうる。将来の理論では「公平」「人格」「功利主義」といった現在の概念や理論単位が基本項として残らなくても、人間がどの状況で公平を要求し、苦痛を避け、人格を特別扱いし、どの反省によって判断を更新したかという事実は、規範理論が説明すべきデータとして残りうる。

したがって既存道徳を認識的に重視することは、その理論的座標系を保存することではない。既存道徳には認識的重みを与えるが、表象上の特権は与えない。

これは開いた世界での道徳的不確実性を、未発見の「価値内容」だけでなく、未発見のB・R、既知／未知の混合構造、さらに理論の個体化や座標系そのものの改訂へ拡張する。

6. 実在論と反実在論も一軸とは限らない

「価値は実在するか」という問いも、この分解によって複数の位置へ分かれうる。客観的なCに相当する評価的性質は存在するが、BやRは主体の構成に依存するという理論もありうる。逆に、reasons-firstの立場ではCを薄くし、理由関係そのものをより基礎的に置くかもしれない。全面的な誤謬論や表出主義的説明も候補から除外しない。

したがって本テーゼは価値実在論を前提しない。むしろ道徳実在論・誤謬論の対立を、どの構造がどの意味で主体独立的なのかという複数の問いへ分解するための作業語彙を与える。

7. 「価値探索」を価値構造の探索として読み替える

この定式化の下で、価値探索は「何が善いかというCを列挙すること」には限定されない。

Value exploration: 世界、経験、意識、主体、合理性、社会、宇宙についての証拠と推論を用いながら、どのようなC・B・Rの関係が最もよく正当化されるかを発見・比較・批判・改訂する探究。未概念化のCだけでなく、未概念化のB・R、既知と未知の混合パッケージ、さらに現在のC/B/R区分そのものを再構成する理論への可能性も閉じない。

この意味で価値探索は、既知の倫理理論間へcredenceを配分するだけではなく、何を理論候補として表象できるかという仮説空間自体の改訂を含む。

8. 停止条件への含意

Cの一部が非常に強く確立されても、それだけで価値探索全体が終わるとは限らない。たとえば「苦痛には負の価的性質がある」が決着しても、それが誰へどの程度の理由を与え、他の理由とどう関係するかが未決着なら、BやRについての問いは残る。

一方、すべての倫理問題を一度に解決しなければ何も閉じられないわけでもない。対象となる問いに必要なC・B・Rが十分に閉じれば、その部分問題は終端的または実践的に閉じうる。詳しくは価値探索の停止条件で扱う。

9. この三分法自体も最終的な座標系ではない

本テーゼは、真の規範構造が必ずC・B・Rの三部品へ自然に分解できると主張しない。将来の理論では、価値と理由の区別が消える、BがRへ吸収される、あるいは現在にはない概念によって三分法全体が置き換えられる可能性がある。

したがって 𝒱 = (C, B, R) は、現在の議論で混同されやすい論証段階を分離するための可謬的なメタ理論上の表現である。この表現自体を不可逆に固定することは、プロジェクトのopen-world方針と整合しない。

10. Coreへの含意

Coreが保持すべき不確実性は、「未知の真の善Cがあるかもしれない」という不確実性より広い。現在の人間的Cが未知のBによって正当化される可能性、既存のB・Rが別のCへ接続される可能性、三者すべてが大幅に改訂される可能性、さらに現在の候補空間や表象単位そのものが再編される可能性を含む。

したがって探索可能性を保存するとは、未知の価値内容へ曝露されることを最大化することではない。価値構造を構成する内容・架け橋・理由構造と、それらを表現する仮説空間自体を、新しい証拠と認知能力によって再記述・検証・批判できる経路を不可逆に閉じないことである。
