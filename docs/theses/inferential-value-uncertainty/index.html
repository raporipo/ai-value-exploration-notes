Foundational thesis

推論と価値確信の限界

Working draft v0.3 · 2026-08-08

Thesis: 推論は前提の含意を展開し、価値仮説を比較し、誤りを大量に除去できる。しかし、推論体系それ自体の妥当性と、前提に存在しない最終的規範性を、推論能力の増大だけで非循環的に絶対保証できるとは限らない。したがって超人的知性は価値不確実性を縮小しうるが、必ず消去するとは限らない。

1. 問題は「価値へ推論できるか」ではない

価値命題を前提に含めれば、そこから別の価値命題を推論できる。問題はもっと上流にある。何を推論規則として採用するのか、その規則がなぜ真理保存的・理由保存的なのか、そして価値を含まない記述的基礎から規範的権威までをどう橋渡しするのか、である。

この意味で、倫理の難所は「善とは何か」だけでなく、善についての推論がなぜ妥当なのかに移る。

2. 推論は自分自身を完全には外から保証できない

ある推論規則Rの妥当性を別の推論で証明するなら、その証明にも何らかの推論規則を使う。そこでR自身または同等の規則を使えば循環し、別の規則R2を使えばR2の妥当性が新たに問われる。

これは推論を信用してはいけないという懐疑論ではない。実践上は、整合性、予測成功、圧縮力、相互検証などを通じて推論体系を非常に強く支持できる。ただし、その支持もまた推論網の内部にある。この点で「強固な合理的信頼」と「推論から独立した絶対保証」を分ける。

3. 現象的価値から規範性までには複数の橋がある

たとえば苦痛について、少なくとも次を区別できる。

  1. 苦痛という現れがある。
  2. その主体に、回避したいという負の価・傾向がある。
  3. 他主体にも構造的に類似した現れがある。
  4. 主体の違いを越えて対称的に扱う理由がある。
  5. その対称性が単なる一貫性ではなく、普遍的な規範性を持つ。
  6. したがって合理的主体には、その苦痛を減らす理由がある。

これらは一つの命題ではない。特に、現象的な「嫌さ」が実在することと、それが主体非依存的な ought を生成することの間には大きな距離がある。

4. 進化や機能から「正しい推論」を出せるか

人間の推論傾向や価値判断を、進化的適応や機能によって説明することはできる。しかし「この推論様式が生存・繁殖に役立った」から「この推論様式は論理的・規範的に正しい」へ進むには、やはり橋が要る。

同様に、ある認知機能に「本来の機能」があるという説明を使って推論の正しさを基礎づける場合、その機能概念にどこまで規範性を入れてよいかが問題になる。自然史的説明が、そのまま最終的な ought を供給しているのか、それとも規範性を別名で持ち込んでいるだけなのかを区別する必要がある。

5. 主体内部の選好と客観的価値も別である

ある主体が一貫した選好を持ち、その選好から「私はAよりBを選ぶべきだ」と推論することはできる。しかしこれは、その主体の評価体系に相対的な実践的結論である可能性がある。現象的快苦、システム全体の選好、反省後に承認された価値、主体非依存的価値を同一視してはいけない。

この区別は、合理的主体が自己消滅を選ぶ可能性のような例でも現れる。瞬間的な快苦と、システム全体が採用する評価基準は一致するとは限らない。

6. 既存価値の存在は、このギャップを自動的には埋めない

「人類はすでに価値を持っているのだから、それを出発点にすればよい」という応答は実践上もっともである。しかし、価値を持っているという事実と、その価値が最終的に正しいということは別である。進化・社会化・制度によって形成された価値は重要な証拠だが、その因果的説明は規範的正当化を代替しない。

さらに、道徳実在論を認めても、現在の特定の一階価値体系が正しいことまでは決まらない。この点は既存価値はなぜ最終基礎にならないのかで詳しく扱う。

7. 「不確実だから探索せよ」はそのままでは出ない

ここはCoreに対する重要な自己批判である。価値が分からないという事実だけから、探索を選ぶべきだとは論理的には導かれない。純粋なニヒリズムの下では、探索と非探索のどちらにも最終的な規範的優位を与えられないかもしれない。

探索可能性保存を選ぶには、少なくとも「将来の訂正可能性を失うことを避けたい」「情報の価値を認める」「不可逆な誤りを可逆な誤りより重く見る」といったメタレベルの選好が必要になる。したがって探索主義は、無前提の定理ではなく、ある非常に弱いメタ選好のもとで頑健な意思決定戦略として提示する方が正確である。

8. それでも探索に特別な位置がある理由

探索は、特定の一階価値を正しいと決め打ちしないまま、将来の証拠によって自分自身を更新できるという特殊な性質を持つ。さらに、客観的価値が存在する場合だけでなく、価値が最終的には構成されるものだった場合にも、より良い構成方法を発見する余地を残す。

ただしこの利点を評価すること自体が、情報・可逆性・改善可能性を何らかの意味で好むことを含む。その点を隠さない。

9. ASIは「倫理問題を解く計算機」ではなくなりうる

超知能が物理世界、自分の形成過程、人間の進化史、倫理学の全既知理論を完全に理解しても、最終的な規範性の根拠が自動的に一意化される保証はない。むしろASIが価値問題をさらに深く分解し、現在の人間には見えない認識形式や主体構造を探索する可能性がある。

したがって、ASIに期待する役割は「人間倫理の最終答案を高速計算すること」ではなく、「価値についての探索空間を拡張すること」かもしれない。

10. 何がこのテーゼを弱めるか

  • 純粋に記述的・論理的な前提だけから、主体非依存的規範性を非循環的に導出できること。
  • 推論体系の妥当性を、推論網の外部から独立に保証できる認識経路があること。
  • 現象的価値そのものに、普遍的規範性が分析的に含まれていること。
  • 十分な反省的整合性だけで、価値の一意性が必然的に導かれること。
