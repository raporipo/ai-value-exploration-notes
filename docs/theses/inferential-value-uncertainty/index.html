Foundational thesis

推論と価値確信の限界

Working draft v0.1 · 2026-08-08

Thesis: 推論は前提の含意を展開できるが、前提に存在しない最終的規範性を、推論能力の増大だけで無から生成できるとは限らない。したがって、超人的推論能力は価値不確実性を縮小しうるが、それを必ず消去するとは限らない。

「価値へ推論できない」ではない

価値命題を前提に含めれば、推論によって別の価値命題を導くことはできる。問題は、価値を含まない最小基礎から、主体非依存的な規範的権威までを非循環的に確定できるかである。

現れから規範性までの距離

苦痛が現れること、主体がそれを嫌うこと、同型の状態が他者にも存在すること、主体間に対称性を認めること、そして「ゆえに誰にとっても避ける理由がある」とすることは、一つの命題ではない。各段階の橋がどの種類の根拠を持つかが問題になる。

ASIにも残る可能性

超知能が物理世界、自分の形成過程、人間の進化史、倫理理論の全含意を理解しても、最終的な「なぜそれをすべきか」が自動的に一意化されるとは限らない。高度知性は倫理問題の探索者にはなりうるが、単なる最終倫理の計算機である保証はない。

弱い結論

ここから「真の価値は発見不可能だ」とは導かれない。重要なのは逆である。現在の推論形式だけで価値問題が閉じる保証がない以上、別の主体構造、認知形式、経験形態による将来の探索を早期に封鎖しない理由が生じる。

反論候補

  • 十分な反省的整合性条件だけで規範性を構成できるのではないか。
  • 「理由」自体を主体の選好構造へ還元すれば問題は消えるのではないか。
  • 価値的現れそのものがすでに規範性を含んでいる可能性はないか。
  • 推論体系の自己正当化不能性と倫理的不確実性を結びつけるのは強すぎないか。
