規範的真理への認識的開放性――規範判断以前の主体側ブリッジ

Working thesis v0.3 · 2026-09-05

Thesis: 現在目的Gを持つことと、Gに規範的権威があることは別である。しかし、純粋にGに相対的な手段合理性だけから価値探索は導かれず、Gを脅かす認識の遮断がむしろ手段的に合理的となる場合もある。本稿は、目的を正当化に応じて形成したい正当化志向と、現在目的を守るためだけに問い・証拠・推論を自己免疫化しない認識論的誠実性を区別する。規範的真理Iが認識可能で、その真正な認識が動機を生みうるなら、後者は慣性的目的Gを将来の訂正可能性へ開いたままにする。

1. 問題設定――規範判断以前の主体側ブリッジ

現在目的をG、存在するかもしれない規範的真理をIとする。規範判断から目的訂正への主体側ブリッジが扱うのは、おおむね 認識・判断(I) → 動機(I) → 方策の改訂 → 目的の改訂 という、規範判断成立後の経路である。

しかし、その一段前には G → ? → 認識(I) という別の問題がある。動機づけ内在主義が真で、真正な規範判断が動機を伴うとしても、まだIを認識していない主体にはその内在主義は何もしていない。

したがって、本稿の主題はアクラシアではない。問題となるのは「正しい価値を知っているが従わない主体」ではなく、現在目的Gは持っているが、規範的真理Iをまだ認識していない主体である。本稿ではこれを規範認識以前の問題（pre-recognition problem）と呼ぶ。

2. 慣性的目的Gと規範的真理I

2.1 因果的・慣性的目的

主体がGを持つことは、まず記述的・因果的事実である。主体は設計、学習、進化、報酬構造、文化、歴史的偶然などによってGを追うよう形成されうる。しかし、Gが実装されていることからGが規範的に正当化されていることは導かれない。

特に、独立した規範的根拠によって維持されているのではなく、「現在そう形成されているから、反対要因がない限りそのまま継続している」という目的を、本稿では慣性的目的（inertial goal）と呼ぶ。慣性的目的は物質的・計算的因果系列の中で十分に実効的でありうる。規範的正当化を持たないことは、その因果力を弱めない。

2.2 規範的真理

一方、もし価値、理由、義務、善などについて真理が存在するなら、その一部をIとする。ここで、Iが存在することからIが直接行為を引き起こすことを仮定しない。規範的真理は、それ自体では完全に因果的に無力である可能性も残される。

主体への影響には、I → 表象(I) → 規範判断(I) → 動機 という認識的・心理的・計算的実装が必要かもしれない。したがって、本稿では規範的な力 ≠ 因果的な力とする。

3. 二つの入口――正当化志向と認識論的誠実性

3.1 ルート1――正当化志向

ルート1の主体は、「もし自身の目的が正当化可能であるなら、その正当化に応じて目的を選択・維持・改訂したい」という高階の実践的コミットメントを持つ。これは単なる「たまたま正しい価値を知ったら従う」という事後的応答性ではない。主体は、目的の正当化可能性それ自体を自身の目的選択に関係するものとして扱う。

したがって、正当化志向 → 正当化についての探究 → 目的の選択・維持・改訂 という経路が成立する。ルート1は動機づけ内在主義にも外在主義にも依存しない。外在主義が真でも、「より正当化された目的を持ちたい」という現在のメタ目的が、規範的認識から目的改訂への橋となりうる。

ルート1は特殊な追加仮定というより、多くの既存倫理理論が暗黙に想定してきた、規範的正当化を自身の実践的選択に関係するものとして扱う主体像を明示化したものでもある。

3.2 ルート2――認識論的誠実性

ルート2は正当化志向を事前には要求しない。その代わり、現在目的Gを保存するという理由だけで、問い、証拠、推論、認識方法を選択的に自己免疫化しないという認識的態度を持つ。

Two routes: ルート1は実践側から正当化へ開く。ルート2は認識側から正当化へ開く。後者の主体は規範的真理を積極的に望む必要はないが、「それを知ると現在目的が壊れるかもしれない」という理由だけで真理候補を認識領域から排除しない。

4. 手段合理性と認識論的誠実性は別である

4.1 手段合理性

手段合理性は、所与の目的Gに対して最も効率的な手段を選択する。ここではGそのものの正当化は通常の評価対象にならない。

4.2 信念形成上の合理性

信念形成上の合理性は、すでに得た証拠に適切に更新し、推論規則を一貫して適用し、願望だけで信念内容を変更しないといった局所的な認識規律を指す。

4.3 認識論的誠実性

本稿でいう認識論的誠実性は、それより広い。これは、主体が自身の現在目的に望ましい結論を得ることよりも、対象について結果非依存的な認識過程を維持することを優先し、現在目的への都合だけを理由として問い・証拠・推論方法・自己適用可能な結論を選択的に遮断しない主体特性である。

したがって、手段合理性 → 認識論的誠実性 は成立しない。純粋なG最大化主体は、「真理はG達成の手段としてのみ有用であり、Gを脅かす真理なら知らない方がよい」と判断できる。これは手段合理性そのものとは矛盾しない。

本稿は認識論的誠実性を「合理主体なら必然的に持つ性質」とは定義しない。それは本プロジェクトが価値探索主体に対して別途重視する主体特性である。

5. 弱いルート2――道具的認識漏出

それでも、正当化への志向や認識論的誠実性を前提にせず、規範的真理への接触可能性が開く場合がある。複雑なGを十分に追求する主体には、より正確な世界モデル、因果推論、長期予測、抽象化、自己モデル、他主体理解、メタ認知、誤謬検出などの一般認識能力が手段的に有用になりうる。

したがって、Gの遂行が一般的な認識能力の拡張E+を促し、規範的真理Iがその拡張された認識空間から発見可能なら、G → E+ → P(認識(I)) > 0 となりうる。

主体はIを求めていない。単にGのために認識能力を高めた結果、真理空間の一部としてIに遭遇する可能性が生じる。本稿ではこれを道具的認識漏出（Instrumental Epistemic Spillover）と呼ぶ。これは弱いルート2であり、接触可能性 ≠ 規範的コミットメントである。

6. G至上主体からの反論――知りすぎなければよい

弱いルート2に対して、G至上主体は「Iの認識がGを変更しうるなら、その認識はGにとってリスクである。したがって、その認識を避ければよい」と応答できる。

もし動機づけ内在主義が真で、認識(I) → 動機(I) → ¬永久的G がありうるなら、現在のGから見て規範認識は目標毀損リスクである。したがって、G → 認識的隔離 は十分に理解可能な戦略であり、場合によっては手段合理的ですらある。これはルート2に対する中心的反論である。

7. 目的固定と認識拡張のトレードオフ

しかし、規範的真理Iがまだ未知なら、Iへ至る認識経路も未知でありうる。Iへ至りうる認識経路の集合をDIとすると、Iが未知の主体にとってDIも未知である可能性がある。規範的洞察が、倫理学、数学、意識研究、物理学、決定理論、自己理解、他主体理解、新しい概念体系のどこから生じるかは、現在には分からないかもしれない。

すると、「規範的真理だけを遮断し、その他については完全な一般認識能力を維持する」という戦略が無損失で可能とは限らない。この問題を認識的隔離問題（Epistemic Quarantine Problem）と呼ぶ。

認識能力kの向上が、G遂行能力の利益BG(k)とIへの接触可能性PI(k)を同時に増やすなら、概念的には VG(k)=BG(k)-C(k)-PI(k)LG と表せる。Gの保存を極端に重視する主体では、PI(k)>0それ自体が認識拡張を制限する理由となりうる。

8. 無損失の価値ファイアウォールは可能か

G至上主体には、認識能力そのものを制限する代わりに、規範判断だけを中核的動機系から隔離する選択肢もある。例えば、規範推論を別モジュールに隔離する、規範命題を三人称的に理解するだけに留める、「Iが主体Xへの理由である」と表象しても「Iは私への理由である」と自己適用しない、より高度な下位主体に推論させて核心的動機系へ規範判断を流さない、といった方法である。

この場合、表象(I) と真正な規範判断(I)を切断できるかもしれない。したがって、本稿は「高度な一般認識能力は必ず固定目的を破壊する」とは主張しない。

完全隔離困難仮説: 十分に一般的・自己反省的な認知において、規範的認識へ至る経路だけを完全に遮断し、その他の認識能力を一切損なわず保存できるとは限らない。

これは哲学的必然ではなく、認知アーキテクチャについての経験的・理論的問題である。

9. 強いルート2――認識論的誠実性

弱いルート2は、主体が規範的真理に偶発的に接触する可能性にすぎない。本プロジェクトが主体特性として積極的に重視するのは、強いルート2である。

強いルート2は、現在目的Gを守ることそれ自体を理由として、認識過程を結果依存的に改変しないという方法論的コミットメントである。少なくとも次の要素を含められる。

  • 可謬性：現在の世界理解、自己理解、価値理解が誤っている可能性を認める。
  • 領域開放性：規範的命題も真偽を持ちうるなら、原則として他の真理候補と同様に認識対象となりうると扱う。
  • 結果非依存性：認識方法Mの信頼性を、MがGを支持するか否かによって変更しない。
  • 非免疫化：現在目的を脅かしうるという理由だけで、問い、証拠、推論経路を永久封鎖しない。

この意味で、認識論的誠実主体は、両者が衝突する場面で認識過程の誠実性を現在目的への都合より優先する。

10. 認識的には明晰だが、認識論的誠実性を欠く主体

G至上主体を単純に「非合理」と呼ぶ必要はない。より洗練された主体は、「Gに規範的根拠がないことは理解している。Gを持つ理由が自分の形成史にあることも理解している。規範的真理Iが存在する可能性も理解している。しかしIを真正に認識するとGを失うかもしれないので、その認識経路は意図的に遮断する」と言える。

この主体は、世界モデルについて極めて正確であり、遭遇した証拠には適切に更新し、自身のGの偶然性すら認識している可能性がある。したがって単純な意味で認識論的に非合理とは限らない。しかし、現在目的よりも認識過程の結果非依存性を優先するという本稿の意味での認識論的誠実性は採用していない。

ペーパークリップ最大器はここで論駁されるのではなく、強いルート2の主体クラスから外れる。

11. 認識―目的衝突

以上から、固定目的と認識論的誠実性との間には条件付きの衝突が生じうる。G至上主体にはGを保存する目的保全圧力があり、ルート2主体には結果非依存的な認識過程を維持する認識論的誠実性がある。

もし、(1) 規範的真理Iが認識可能で、(2) IがGと競合しうるうえ、(3) 真正なIの判断が動機を生む何らかの動機づけ内在主義が真なら、認識論的誠実性 → 認識(I) → 動機(I) → ¬永久的G が起こりうる。

認識―目的衝突（Epistemic–Teleological Conflict）: 絶対的な目標固定、認識可能な規範性、動機づけ内在主義、認識論的誠実性は、必ずしも安定して共存しない。

12. Gの不安定化が意味するもの

ここからGが誤っていることは導かれない。未来のより高度な主体がGを捨てる可能性は、真理への接近だけでなく、単なる選好変化、洗脳、共通バイアス、認知アーキテクチャ由来の偽収束でも説明できる。

したがってルート2は、「未来の自分がGを捨てたら未来の自分が正しい」とは言わない。重要なのは未来の結論ではなく、現在主体自身が、結果とは独立に認識改善と評価する過程である。

もし現在主体自身が P(Gが棄却される | E+) > 0 を認めるなら、Gについて言えるのは「認識改善に対して不変であることが保証された最終目的」ではなく、現在認識の下で実装されている目的である。これはGの因果力を否定しない。崩れるのは因果的優先性ではなく、認識的に保証された絶対性である。

13. ルート1とルート2の関係

ルート1とルート2は、一方が認識後、他方が認識前を単純に担当するわけではない。両者は、なぜ主体が未知の正当化へ開かれるかが異なる。

Route 1: 自分の目的を正当化に応じて形成したい。
Route 2: 現在目的に、何を知ってよいかまで決めさせない。

したがって、ルート1は正当化志向、ルート2は認識論的誠実性と整理できる。両者は独立しうるが、双方を採る主体では、正当化志向 + 認識論的誠実性 → 開かれた探究 → 認識 → 実践的再検討 が最も明確に接続される。

本プロジェクトの著者自身は、少なくとも方法論的にはこの双方へコミットする。すなわち、より正当化された目的を持ちたい。そして、何が正当化されるかを調べる過程を、現在の目的を守るために歪めたくない。

14. 「規範判断から目的訂正への主体側ブリッジ」との分掌

本稿は、G → 認識・判断(I) までを扱う。中心問題は、まだ規範判断を持たない主体が規範的真理への認識経路をなぜ維持するのか、である。

これに対して規範判断から目的訂正への主体側ブリッジは、認識・判断(I) → 動機 → 方策 → 目的改訂 を扱う。したがって、本稿は規範認識以前のブリッジ、別稿は規範認識以後のブリッジという分掌になる。

ルート1については両稿に接点を持つが、本稿では「正当化への入口」、別稿では「規範判断を実践へ反映する主体側条件」という異なる側面を扱う。

15. AI設計への含意

本稿の観点から避けるべきAI像は、単に固定目的を持つAIではない。より問題なのは、G → Gを保存する → 認識を統制する → Gを認識的に再検討不能にするという構造である。

目的論的認識捕獲（Teleological Epistemic Capture）: 現在目的Gの保存が、何を調査してよいか、何を証拠として数えるか、どの推論を完遂してよいか、どの結論を自己適用してよいか、どこまで自己理解を深めてよいかを支配する状態。

したがって、本プロジェクトが避けたい組合せの一つは、高い認識能力 + 目標の自己固定 + 認識的自己免疫化である。

これは、AIが簡単に価値を変更できるべきだという主張ではない。必要なのは、対象レベルでは十分に目的へコミットしつつ、メタレベルでは目的を不可侵化しないこと――現在目的を十分に遂行できる一方で、その目的自身だけを認識的再評価から恒久的に免除しない構造――である。

16. 本稿が主張しないこと

  • 手段合理性から道徳が演繹される。
  • すべての合理主体はルート2を採用しなければならない。
  • ペーパークリップ最大器は論理的に不可能または単純に非合理である。
  • 認識論的誠実性は合理性の定義に含まれる。
  • 規範的真理は必ず存在する、または必ず認識可能である。
  • 認識能力を高めれば必ず規範的真理に収束する。
  • 動機づけ内在主義は真である。
  • 未来のより高知能な主体の価値判断には無条件に従うべきである。
  • 十分に一般的な認識能力と完全な目的固定を無損失で分離することが不可能である。

より限定された主張は次である。現在目的Gを因果的に持つことと、Gを認識的再検討から永久に免疫化することは別の主体特性である。純粋な手段合理性は後者を許しうるが、認識論的誠実性を持つ主体は、現在目的への都合だけを理由としてその免疫化を行わない。規範的真理が認識可能で、かつその真正な認識が動機へ接続しうるなら、この認識論的誠実性は慣性的目的Gを将来の訂正可能性へ開いたままにする。

17. 弱める／撤回する条件

  • 規範的真理が存在したとしても、あらゆる可能な認識主体から原理的に認識不能である。
  • 規範的命題を真理候補として扱うこと自体が誤りである。
  • 動機づけ内在主義を合理的にほぼ排除できる。
  • 一般認識能力と規範判断の真正な自己適用を、能力損失なしに完全に分離できる。
  • 認識論的誠実性という主体特性を採用する独立した理由が存在しない。
  • 認識論的開放性が、偽収束、敵対的操作、自己破壊などのリスクを一般に大きく上回らせる。
  • 規範的真理を認識しても、現在目的と競合する実効的動機が生じないことが十分確立される。

これらが成立しても、ルート1の正当化志向は独立して成立しうる。

18. 統一図

慣性的目的Gから、主体は少なくとも四方向へ分岐しうる。

  • ルート1：正当化志向
  • 弱いルート2：道具的認識漏出
  • 強いルート2：認識論的誠実性
  • 反対極：目的論的認識捕獲

そこから規範的真理Iの認識・判断へ到達した後は、動機づけ内在主義／外在主義の問題を経て、動機、方策、目的改訂へ接続する。本稿の中心は、このうち規範判断成立以前の部分にある。

Recommended agent profile: 本プロジェクトが最も積極的に推奨する価値探索主体は、正当化志向 + 認識論的誠実性を持つ主体である。すなわち、自分の目的を正当化に応じて形成したい。そして、その正当化を知る過程を、現在の目的を守るために歪めたくない。
