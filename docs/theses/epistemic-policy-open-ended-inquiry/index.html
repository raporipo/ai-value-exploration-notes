認識論的方針――最善説明と開かれた探究

Working draft v0.2 · 2026-09-06

Thesis: 本プロジェクトは、現在利用可能な証拠に対して、説明的比較が適用可能な領域では最善説明へ強く暫定コミットする。しかし、そのコミットメントを、現在の仮説空間・概念枠・対象分節・認識方法そのものの最終性とは同一視しない。したがって、高い現在的確信と、将来の訂正可能性・仮説空間拡張・方法論的改訂は両立する。これは包括的な独自認識論ではなく、本プロジェクトが科学・哲学・価値探索で用いる一般的な認識運用方針である。

1. 射程――「何を知識と呼ぶか」より、「どう探究するか」

本稿は、knowledge、justification、truthの必要十分条件を一から定義することを目的としない。より限定的に、有限の認識主体が不完全な証拠・概念・候補集合のもとで、どの世界像を暫定採用し、どのように批判・更新し、どのような意味で探究を開いたままにするかを整理する。したがって中心にあるのは、静止した信念状態の分類よりも、探究を運用するための方針である。

この意味で、本稿は近年の探究的認識論（zetetic epistemology）と問題設定を共有する。認識論の対象をある時点のbeliefだけに限定せず、問いの形成、証拠収集、代替案生成、評価、暫定的判断、探究の休止、再開までを含む時間的な過程として捉える。信念形成が合理的でも、その問いを永久に閉じることが合理的とは限らない。

ただし、本プロジェクトは「よい探究」「真理追求」「開放性」といった語に含まれる規範性を、そのまま究極的前提として採用しない。これらは、現在の主体が真偽の識別、誤り訂正、予測、介入、自己訂正などを目的として持つ限りで有効な認識方針としてまず扱えるが、探究すること自体に独立した客観的規範価値があるかは別問題である。探究規範そのものの規範的地位も、価値探索の対象から除外しない。

2. 出発点――現在的認識には非対称性があるが、存在論的特権は与えない

瞬間的最小基礎では、通時的自己・外界・脳・物理法則を最小基底に置かず、せいぜい「現在、何らかの認識的生起／拘束がある」という極薄い否定限界を出発点候補とした。この非対称性は、心を第二の実体として保存する二元論を意味しない。

ここで特別なのは「心」という存在者ではなく、現在の認識が世界についてのモデル形成の入口になっているというアクセス上の非対称性である。記憶、人格、通時的自己同一性、「mental」「phenomenal」といったカテゴリーまで最小基底へ含める必要はない。これらはすでに、現在の生起をどのように分類し、どのような因果的来歴へ置くかについての上位仮説である。

Asymmetry rule: epistemic priority ⇏ ontological priority。認識の出発点として非対称であることは、宇宙の基本構成要素として特権的であることを意味しない。

現在の最善世界像では、その認識的生起も脳・身体・環境を含む物理過程として扱うのが最善説明である。したがって現在の立場は、存在論的には暫定的な物理的一元論、認識論的には現在的認識アクセスに非対称性を認めるものとして表現できる。ただし、この物理的一元論は認識方針そのものから演繹されるのではなく、後述する方針を現在の証拠へ適用した結果として採用される。

3. デフォルトは最善説明への推論である

最小基底より上では、説明的比較が適切な領域において、本プロジェクトはInference to the Best Explanation（IBE）をデフォルトのモデル選択方針として採る。これは論理・数学・概念分析・規範性の認識可能性まで、あらゆる問いを一つの説明スコアへ還元するという主張ではない。とりわけ、何が規範的証拠として数えられるかをIBE自体が先に決めるわけではない。

候補モデルは、少なくとも次のような観点から比較される。

  • 観測・経験との適合
  • 予測力と新規予測の成功
  • 介入・操作の成功
  • 説明範囲と統合力
  • 単純性とアドホックな補助仮定の少なさ
  • 他のよく支持された知識との整合性
  • 独立した測定・方法・モデルにまたがる頑健性

これらは固定された単一の「説明点数」へ機械的に還元されるとは限らない。単純性とデータ適合、広い説明範囲と局所的精度、統合力と新しい概念導入などは互いに緊張しうる。したがってIBEは argmax ExplanationScore(H) のような完成済み関数というより、複数の認識的成功基準を比較し、最もよく全体を説明する候補を選ぶ可謬的な選択方針として理解する。

また、van Fraassenなどが指摘するように、説明力の高さから観測不能な構造の真理へどこまで進めるか自体が科学哲学上の争点である。本プロジェクトはIBEをアプリオリな真理追跡原理として基礎づけない。むしろ、説明・予測・介入・統合の実績を持つ現在の科学的探究で有力に機能している方法として暫定採用する。言い換えれば、IBEそのものもこの認識方針の例外ではない。

ここでいう「認識的コミットメント」は、主として高いcredenceと作業モデルとしてのacceptanceを意味する。それ自体は不可逆な実践行為や制度的ロックインを含意しない。証拠差が大きければ、一つの世界像へ極めて高い確信を置いてよい。可謬主義は中立主義ではない。

Operational rule: best-supported available explanation → strong provisional epistemic commitment。ただし、epistemic commitment ≠ practical lock-in かつ provisional commitment ≠ irreversible epistemic closure。

4. 整合性だけでは足りない――Haackのクロスワードと外部拘束

Susan Haackのfoundherentismは、認識的支持をクロスワード・パズルにたとえる。答えは、交差する他の答えと整合するだけでなく、ヒントにも合わなければならない。本プロジェクトでは、この比喩を「内部整合性＋外部からの拘束」として利用できる。

完全に整合的な世界像でも、経験・測定・予測・介入から切断されていれば十分ではない。一方、個々の感覚入力を自己解釈的で不可謬な基礎命題として扱う必要もない。外部拘束と信念網は相互に校正される。

ただし、ここでいう「外部拘束」は、理論から完全に独立した生データが透明に与えられるという意味でもない。科学的観測は、測定装置、校正法、統計処理、分類体系、背景理論などを介して成立する。観測がtheory-ladenでありうることは、外部世界の抵抗が消えることを意味しないが、何が反例であり、何を測定したのかの解釈自体が改訂可能であることを意味する。

Duhem–Quine型の問題もここに関わる。予測は通常、中心仮説Hだけでなく補助仮説A、測定仮定M、初期条件Iなどの束から導かれるため、H + A + M + I → E が失敗しても、直ちにHだけが偽だとは決まらない。したがって本プロジェクトが要求する外部拘束は、単純な「一回の観測による理論の機械的反証」ではなく、複数の測定・補助仮説・再現・介入を横断した持続的な抵抗として理解する。

5. 最善説明は、批判とエラー検出に晒されなければならない

説明力だけを評価すると、魅力的な物語や柔軟すぎる理論を過大評価する危険がある。そこでIBEには、Popper/Bartley的な批判可能性、厳しいテスト、再現、robustness analysisを補助原理として組み合わせる。

ただし、反証も理論選択を自動化しない。前節の通り、実際のテストには補助仮説、測定誤差、近似、統計的ノイズが介在するため、一つの失敗からどの要素を捨てるべきかは一意に決まらない。Lakatos的にいえば、単発の反例だけでなく、研究プログラムが新しい予測・説明・問題解決を生み続けているか、それとも事後的な保護修正だけを積み重ねているかという時間的評価も重要になる。

Deborah Mayoのsevere testingからは、単に「テストに通った」ことより、もし仮説が重要な点で誤っていたなら、そのテストで露見しやすかったかを見る発想を借りられる。誤った理論でも容易に通過できる確認は弱く、失敗を検出する能力の高い検査を耐えた方が強い。ここでの狙いは特定の統計哲学への全面コミットではなく、説明の魅力とエラー検出能力を分離することにある。

役割を分ければ、IBEは何を暫定採用するかを、批判的合理主義は採用したものをどう訂正可能に保つかを主に担う。Bartleyの汎批判的合理主義からは、とりわけ「認識方法それ自体を批判の例外にしない」というメタ原則を借りる。ただし、批判可能性だけでは競合理論の積極的な順位づけは十分に与えられないため、IBEや経験的テストを別に必要とする。

6. 現在の採用と将来の訂正は両立する――Isaac Leviから借りるもの

Isaac Leviのプラグマティスト的認識論は、現在の信念の「血統」を再正当化するより、信念集合をどのように改訂するかを認識論の中心課題に置く。また、現在のfull beliefを強く受け入れることと、その信念が将来訂正されうることを区別する。

本プロジェクトはLeviのinfallibilismまで採用しない。現在強く信じながら、同時に正のcredenceを持つ競合仮説を認める状態は普通にありうる。しかし、current acceptanceとfuture corrigibilityを分離するという構造は重要である。

この区別を本プロジェクト用に整理すると、少なくとも三つの層を分けられる。第一に、証拠に応じたgraded credence。第二に、計算・予測・研究を進める際に一つのモデルを通常の前提として使うworking acceptance。第三に、そのモデルを前提として資源・制度・将来能力を不可逆に変えるpractical commitmentである。たとえば P(H)=0.97 でHを作業モデルとして採用することは、H以外を将来検討不能にすることを意味しない。

Commitment distinction: credence ≠ working acceptance ≠ irreversible practical commitment。

Leviのserious possibility概念も有用である。ただし本プロジェクトでは、現在すでに表象されているserious alternativesと、まだ表象できていないunconceived alternativesを区別する。この区別は、次節で「確率を付けられる未知」と「まだ確率空間に入っていない未知」を分けるために重要になる。

7. 仮説空間は閉じていない――悲観的帰納法、未構想の代替案、Bayes

科学史上、かつて成功していた理論が後に大きく修正・置換されたという悲観的帰納法は、現在理論が偽だと直接証明するものではない。現在の理論が過去より多くの証拠・精密測定・理論統合を持つこともありうる。しかし少なくとも、現在の成功をそのまま最終性へ変換することへの警告にはなる。

P. Kyle Stanfordのunconceived alternatives問題はさらに直接的である。既知の競合理論に勝ったことは、まだ誰も構想していない代替理論にも勝ったことを意味しない。したがって、認識状態を少なくとも (A) 現在採用している理論、(B) 現在表象されている競合理論、(C) 現在はまだ表象されていない代替可能性 に区別する必要がある。

Open-space rule: best among currently represented alternatives ≠ necessarily best among all possible alternatives.

このCは、通常の意味で単に「低い確率を与えられた仮説」ではない場合がある。仮説の内容自体がまだ表象されていなければ、その仮説に対するcredenceも尤度も現在の確率空間では未定義である。この意味で、未知の可能性を認めることと、未知に任意の数値確率を割り当てることは別である。

ベイズ更新と開いた仮説空間では、この問題を詳しく扱う。現在の候補を H1,…,Hn とし、その外側を H* = ¬(H1∨…∨Hn) というcatch-allで表現すれば、「現在のどれでもない何か」へ確率質量を残すことはできる。しかし、そのときも P(E|H*) を何によって定めるか、H*内部の未知の構造をどう表すかという問題は残る。catch-allは未知を0へ潰さないための容器にはなっても、未知を十分にモデル化する理論ではない。

したがって、本プロジェクトはBayesianismを拒否するのではなく、適用範囲を二層に分ける。表象済み仮説空間の内部ではBayesian updatingを中心的な局所更新法として使い、仮説空間そのものについてはopen-worldな生成・再分節・再開を別に保持する。 「現在の候補集合の内部で合理的に更新できる」ことと、「その候補集合が世界の可能性を網羅する」ことを混同しない。

8. 概念・測定・モデルは反復的に改訂される――Hasok Chang

Hasok Changのepistemic iterationは、完全に基礎づけられた測定法や概念体系を待ってから科学を始めるのではなく、現在利用できる不完全な体系から出発し、それを用いて得られた成果によって出発点自身を改良する科学的進歩を捉える。

ここには一種のbootstrap問題がある。適切な理論を検証するには信頼できる測定法が必要だが、何をどのように測定すべきかを決めるには理論や概念が必要になる。もし完全に独立して正当化された出発点を要求すれば、探究は始められない。しかし実際の科学では、暫定的な測定・概念・理論の組を使い、その成功と失敗によって次の組を校正することができる。

Iterative structure: M₀ → inquiry/evidence → M₁ → further inquiry → M₂ → …。出発点が可謬的であることは、反復的改善が不可能であることを意味しない。

この考えは本プロジェクトの世界像・主体像・価値像の関係によく合う。現在の概念枠を使わなければ探索は始められないが、その概念枠は探索結果によって書き換えられうる。さらに、world model ↔ conceptual scheme ↔ inquiry method は一方向ではなく相互に更新される。新しい測定技術が新しい対象分類を可能にし、新しい対象分類が新しい理論を作り、その理論が次の測定を変える、といった循環は必ずしも悪循環ではない。

したがって「現在のカテゴリーを使うこと」と「そのカテゴリーを世界の最終的な切れ目とみなすこと」を分ける。価値探索においても、現在の「欲求」「理由」「主体」「経験」といった語彙が将来の探索で再構成される可能性を残す。

9. 多元主義は相対主義ではなく、誤り訂正と探索のための制度である

複数のモデル、研究プログラム、測定法、研究共同体を保持することには認識的価値がありうる。しかしこれは、すべての立場へ同じ信念度を配ることではない。

Pluralism rule: epistemic pluralism ≠ equal credence。現在の最善理論を明確に順位づけながら、合理的な代替経路を保存できる。

Lakatos的な研究プログラム、Longino的な相互批判、異なる方法からの独立収束は、それぞれ異なるかたちで共通モードの誤りを減らす。複数の方法が異なる補助仮定から同じ結果へ収束するなら、単一モデル固有の人工物である可能性は下がる。また異論を保持する主体は、主流理論が共有する盲点を発見する探索装置として機能しうる。

ただし多元主義にもコストがある。資源の分散、低品質な仮説の長期温存、合意形成の遅延、反証後も対抗理論を維持し続けるための機会費用は無視できない。したがって本稿は「すべての代替案を永久に保存せよ」とは主張しない。保持すべきなのは、残存不確実性、代替案の生成可能性、誤り訂正上の便益に比して維持コストが合理的な探索多様性である。その具体的配分は意思決定論へ委ねる。

10. この方針の現在的な存在論への適用――「物」と暫定的物理的一元論

本プロジェクトでは、「物」「主体」「過程」「関係」のような存在論的カテゴリーを認識的最小点に置かない。ある対象への存在論的コミットメントは、その対象を含む世界モデルが説明・予測・介入・独立検証でどれだけ成功するかによって強められる。

したがって、物は世界モデルの中で個体化されるが、そこから「モデルが物を存在させる」という観念論は導かれない。台風、生物個体、企業のような対象は、基礎物理学のprimitive entityではなくても、予測・追跡・因果説明の安定した単位になりうる。この意味で、あるものを実在的対象として扱うことは、それが究極的にfundamentalであると主張することとは異なる。

Ontological cautions: model-relative individuation ⇏ model-dependent existence、かつ real ⇏ fundamental。

現在は、認識主体から独立した実在と、一つの因果的に統合された物理世界を、現在の証拠に対する最善説明として強く採用する。心・認知・意識も、その世界内の過程として説明するのが現在のデフォルトである。しかしこれはこの認識方針の公理ではなく、epistemic policy + current evidence → provisional physical monism という現在的な出力である。

したがって、将来より良い説明が成立すれば、物理主義を改訂しても本稿の基本方針は維持できる。同様に、究極的な世界構造がobjects、processes、relations、structures、あるいは現在まだ持たないカテゴリーのどれによって最もよく記述されるかは閉じない。

11. 信念合理性と探究合理性を分ける――zetetic turn

ある仮説Hへの信念度が非常に高いことと、Hについての探究を永久に終了すべきことは同じではない。Jane Friedmanらのzetetic turnが強調するように、beliefの合理性とinquiryの合理性は別の評価対象になりうる。

Zetetic distinction: high confidence ⇏ inquiry closure。

ここで「探究を閉じない」は、すべての問いを常時activeに考え続けるという意味ではない。十分な証拠が得られた問いは、日常的には作業上settledとして扱い、計算や行為を進めてよい。重要なのは、その暫定的settlementを、再検討不能なterminal closureへ変換しないことである。

したがって探究状態は、単純な「継続／終了」の二値より、たとえば active inquiry → provisional settlement → dormant monitoring → reopening のように捉えた方がよい。新しい証拠、説明不能な異常、強い競合理論、新しい測定能力、前提概念への重大な批判などをreopening triggerとして保持できる。これなら、高確信の理論について毎日ゼロから議論し直すコストを払わず、将来の訂正可能性も失わない。

たとえば物理主義を現在ほぼ確実な作業世界像として用いることと、将来それと異なる説明を検討できる認識能力を不可逆に破壊することは別である。ただし本プロジェクトは、探究継続そのものが無条件の義務だとはしない。探索コスト、他の目的、停止条件、再開可能性の保存価値をどう比較するかは、次の意思決定層の問題である。

12. 認識方針自身も改訂可能である

IBE、Bayesianism、批判的合理主義、現在の統計的方法、現在の科学的方法、さらには「説明」「証拠」「対象」といった概念も、この方針の例外ではない。

Meta-epistemic rule: No epistemic method employed by this project is exempt from revision.

この原則自身も、自己正当化的な最終原理として例外扱いされない。「すべての方法は改訂可能でなければならない」という命題を絶対的・不可謬な基礎として置けば、まさにその命題だけを批判から免除することになる。本プロジェクトはむしろ、このメタ原則も科学史・誤り訂正の実績・自己修正の必要性に照らして現在有力な方針として採用する。

これは、あらゆる改訂規則を採用する前に、その改訂規則を正当化するさらに上位の規則を無限に要求することでもない。Bartley的に重要なのは究極的なjustificationよりもcriticizabilityである。現在の規則Rを使いながら、それへの批判や新しい認知能力によって Rₜ → criticism / new evidence → Rₜ₊₁ と移行できればよい。

したがって、これは方法論的懐疑主義ではない。現在もっとも成功している方法は現在もっとも強く使う。それでも、将来の認知拡張、新しい証拠形式、現在とは異なる推論能力によってより良い認識方法が成立したなら、その比較可能性を最初から閉じない。強く使うことと、永久に固定することを分離するという原則は、認識方法そのものにも自己適用される。

13. 意思決定論との境界

本稿が扱うのは主として、何をどの程度信じ、何を作業上採用し、何を批判・再検討可能な状態として保持するかである。そこから先の「追加探索へどれだけ資源を割くか」「不可逆な選択を延期するか」「option valueやvalue of informationをどう評価するか」「Knightian uncertaintyやimprecise probabilityをどう行為へ写像するか」は、意思決定論の問題として分ける。

したがって、価値を意思決定論の後ろに置くのではなく、世界についての認識と価値についての探索を、意思決定への別々の入力として扱う方が正確である。

Epistemic minimum → Epistemic policy → { world inquiry / value inquiry }
{ world model, value state, uncertainty, available actions } → Decision policy → Action

さらに行為・実験は新しい証拠を生み、認識方針へフィードバックするため、これは一方向の階段ではなくループである。価値探索は一般的探究構造の一つの特殊領域であり、同時に意思決定へ必要な入力でもある。現在価値への強い実践的コミットメントを永久的な価値ロックインと同一視しないのと同様、現在世界像への強い認識的コミットメントを永久的な認識ロックインと同一視しない。

14. 本稿が主張しないこと

  • IBEがあらゆる認識領域へ同じ形で適用できること、またはアプリオリに不可謬な真理追跡原理であること。
  • 現在の科学的実在論や物理主義が最終的に確定したこと。
  • 未構想の代替案があるというだけで、現在理論への信念度を大きく下げるべきこと。
  • すべての代替研究プログラムを無期限に保存すべきこと。
  • Bayesianismが無効であること。むしろ、表象済み空間内では中心的な道具として用いる。
  • 探究、真理、認識的開放性が、それ自体で究極的な客観的善であること。
  • 「心」「物」「対象」「主体」といった現在のカテゴリーが世界の究極的分節であること。
