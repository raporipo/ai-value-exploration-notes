テーゼ

Coreを支える基礎命題と、そこからAIへ派生する作業仮説。各ページは、認識論的地位・実践上の強さ・不可逆ロックインの閾値を分けて記述する。

瞬間的最小基礎通時的自己・外界・物理世界を「推論によって導かれる最善説明」として区別し、基礎層に何がありうるかを検討する。 推論と価値確信の限界客観的価値の推論的発見を認めつつ、最善説明と絶対基礎を区別する。 価値探索の停止条件基礎的規範性を完全停止の強い候補、推論的最善説明を強い実践採用＋再検討経路保存として区別する。 既存価値はなぜ最終基礎にならないのか現在価値を証拠・最善実践として強く用いつつ、永久固定の最終回答にはしない理由。 未来価値と現在行為の規範的ブリッジ未知の未来価値の可能性から現在の許可・義務・強制へ進む各段階に、追加の規範的正当化を要求する。 高度AIの目標への懐疑一階目標へ強くコミットしながら、推論的根拠である限りメタレベルの再検討能力を保持するAIの可能性。
